## 1. 序幕 · prologue.ks

- **场景**:空白之地——墨色平面、白色细线、永不熄灭的红色刻度。
- **参与者**:旁白(世界观之声)、疾 / 跃 / 逆 / 圆(四声线立)。
- **信息差**:玩家与角色都不知道刻度是谁画的、从哪来;角色不知「刻度用完会怎样」(旁白明示"没有留下答案")。
- **伏笔增减**:➕"它量过很多次终点"(→第五幕第四层真相);➕"每一次重拼消耗一段红色刻度"(→肉鸽 5 段刻度 / 第五幕代价);➕专属终点门(玩法规则叙事化);➖无。
- **弧光节拍**:空白 → 降临 → 相认 → 规则 → 缺口 → 约定 → 出发(卷五序幕之问"我是谁?"——四声线各自作答)。
- **演出要点**:对话框 1/4 屏、名字构成红、打字机标点停顿、Esc 整段跳;世界暂停但背景呼吸不停(story.md §5)。

## 2. 第一幕开演 · act1.ks

- **场景**:虚空立起的巨构——门厅 / 桥 / 柱 / 梁,"没有观众的剧场"。
- **参与者**:全员五声。
- **信息差**:角色不知巨构从何而来;玩家可从"像是早就知道你们各不相同"读出设计者的存在(角色不能)。
- **伏笔增减**:➕"像是早就知道,你们各不相同"(【草案】设计者的手迹,bible 卷六);➕红色刻度"像一条提词的线"(【草案】刻度的观众性);确立**分位出生 / 分位归门**规则。
- **弧光节拍**:巨构降临 → 分位规则 → 各自出发(卷五第一幕之问"我们必须一样地走吗?"——答:分位即个性)。
- **演出要点**:三拍短剧(28 行),首进幕自动播;四声线各亮一遍,收在"第一幕开演"。

## 3. 尾声 · epilogue.ks

- **场景**:四扇门先后亮起又安静——第一幕终的回声。
- **参与者**:全员五声。
- **信息差**:角色听到了"回声";只有玩家被引导注意回声里"多了一道很轻的、第五个形状的刻度"。
- **伏笔增减**:➕"第五个形状的刻度"(v0.8 埋,重跑序说育,第二幕收);➕"这块不存在的地方,第一次有了回声"(【草案】回声,→落幕"回声=世界在重演");➕"下次换我当台阶"(承载关系互换的种子)。
- **弧光节拍**:四门归位 → 各自一句总结(疾:终点是到齐的那一刻 / 逆:哪里都一样 / 圆:路记得速度)→ 全员归位。
- **演出要点**:通关画面自动播;"全员归位"独占一拍收束。**正式落幕幕(§1.5)将重写本章,现版本保留为第一幕终演**。

## 4. 重跑序说 · rogue_intro.ks

- **场景**:正戏之外的"另一种演法"——单人重跑的规则说明场。
- **参与者**:全员五声(对重跑的态度即性格:疾"快我最熟"/跃"看能带走什么"/逆陈述/圆"正好")。
- **信息差**:角色知道刻度残留 / 残段 / 五段刻度规则(=玩法教学);**无人知道**第五刻度为何闪现(玩家已知它是伏笔)。
- **伏笔增减**:育"第五个形状的刻度,又轻轻闪了一下"(序幕埋→此处闪现→第二幕收);➕"落幕的时候,考的可是你一个人带着什么走过来的"(精英考预告);规则叙事化:刻度残留=词条、五段刻度=死亡结算、残段=结算货币。
- **弧光节拍**:另一种演法 → 刻度残留 → 红色刻度与落幕 → 第五刻度闪现。
- **演出要点**:首进重跑自动播;末句"选一个人。重跑,开始。"直接接选体弹层。

## 5–8. 个人单章 · rogue_{dash,spring,fall,roll}.ks

- **场景**:各自的独演路——疾在起跑线 / 跃在高台与谷底 / 逆在天花板 / 圆在长坡。
- **参与者**:旁白 + 主角独角(**重跑=单人独演**的叙事执行)。
- **信息差**:玩家与主角共享"无同伴"的处境;四段独白互相不知情(单章之间无交流)。
- **伏笔增减**:➕四段"单章题眼"=第三幕个人幕间的底稿(story.md §4c:独白变对话);➕疾之章"怕停下来连个说话的人都没有"(第四幕"疾学会停"的种子);➕跃之章"为自己折一次"(第四幕直连);无收割(全部育中)。
- **弧光节拍**(三拍同构):无同伴的处境 → 与自身特性的独处 → 一句收束的宣告——
  | 章 | 题眼宣告 | 卷五之问的回响 |
  |---|---|---|
  | 疾 | "原来我一直跑,不是怕孤独追上我" | 第三幕"独自一人时,我还算什么?" |
  | 跃 | "以前我为别人折叠坠落,这一次,为自己折一次" | 同上 |
  | 逆 | "你们管这叫孤独,我管这叫安静" | 同上 |
  | 圆 | "一个人滚,更快" | 同上 |
- **演出要点**:首被选为主角时播(旗标 seen_rogue_<slug>);声线规范照 story.md §2(疾破折号 / 跃不示弱 / 逆说"两个面" / 圆禁疑问句);末拍"X之章,开演"统一收束。
