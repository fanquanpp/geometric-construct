# 玩法系统设计总案 · GAMEPLAY MASTER PLAN

> 状态:**v1.0(2026-09-12 定稿)** · 本文是玩法侧唯一总纲,与叙事侧
> `bible.md`(剧情圣经)平级;数值权威仍在 `characters.md`,机关行为权威在
> `structures.md` §7,重跑口径在 `roguelike.md`——本文只做**系统划分、
> 判定与生产规则**,不复制它们的正典内容。
> 效力边界:**纸面总纲先行**;2026-09-10「机制优先」决策下,试炼道是唯一的
> 玩法实装场;正式关卡/剧情实装仍按 ROADMAP 立项 + 逐项拍板。

## 卷〇 · 核心定义(游戏到底是什么)

**五层核心(自下而上,缺一不立):**

```
第五层 · 剧情意义     —— 为什么值得再来一次
第四层 · 重跑变化     —— 同一空间的每一次重新理解
第三层 · 多角色协作   —— 差异的组合,不是数值的叠加
第二层 · 空间构成     —— 玩家在"构成"空间,不只在高跳
第一层 · 角色能力差异 —— 形状即性格,动词即身份
```

- 一切新玩法必须**挂得上这五层之一**;挂不上的方向 = 不属于本作
  (敌人和战斗不属于任何一层,因此永不立项)。
- **玩法陷阱黑名单(永久)**:敌人 / 战斗 / 装备系统 / 大地图开放世界 /
  大规模随机内容。它们会把项目变成另一个游戏;本作的深度来自
  **小空间里的机制组合**与**可控变化**(roguelike.md §4 手工排法纪律)。
- **成长观**:不做数值成长与技能树——角色能力本身基本固定,
  成长的是**玩家对角色的理解**(卷六 理解成长五阶),以及剧情里角色的
  自我认识(bible 卷三)。魅力来自能力不同,不是数值越来越大。

## 卷一 · 十大玩法系统

### 01 核心移动系统(第一层 · 冻结精修)

- 现状【正典】:加速度 / 摩擦 / 跳跃 / 二段跳 / 冲刺 / 反弹 / 三段重力 /
  置换 / 爬墙 / 曲面切线 / 纯滚动 / 承载与刚性携带 / 土狼时间 / 输入缓冲 /
  终端速度——全部在 `player.gd` 手感公约数,characters.md §2。
- **冻结新增移动技能**。下一阶段只做**标准化**:
  1. 每项机制独立可测(headless 单项校验,像 trait_check 那样逐个立);
  2. 参数全部数据化(常量集中,禁止散落在流程代码);
  3. 移动=全游戏的地基,它的稳定优先级高于一切新内容。
- 判定:**保留(冻结精修)**。

### 02 几何能力系统(能力登记与预算)

- **能力预算(每人)**:主动词 ×1(characters.md §0.1,唯一且不与
  冲/弹/翻/滚/隔重叠)+ 副动词受限(登记制,预算封顶)+ 标尺数值边界
  (常规域 -1.0–3.0,形状可读纪律)。预算花完 = 该角色**永远封笔**,
  新想法只能给别的角色或做成机关。
- 新建**能力登记表**(本文附录 A):每个能力一条——
  `名称 / 归属 / 触发 / 输入 / 对环境的改变 / 反制(谁能破解) /
  机制族 / 组合矩阵行 / 测试项 / 状态`。新能力 = 先填表后写码,
  **不再直接往 player.gd 里塞**。
- 判定:五动词全部**保留**;爬墙(疾·副)/ 推动(圆·副)/ 顶弹(跃·副)/
  穿磁界(逆·身份扣)全部**保留**,登记在册。

### 03 空间构成系统(第二层 · 最值得深挖)

- 现状(v0.45 原生换代):空间载体 = TileMapLayer 图位 + 机关场景实例
  (场景壳所见即所得)——**已经是空间构成的雏形**,缺的是把它当玩法第一公民。
- 升级方向:**平台 → 构成组件**。每个组件除几何与碰撞外,逐渐拥有
  **空间语义**:`分隔了谁 / 归属谁 / 状态如何翻转 / 与谁构成回路`。
  语义的代码落点 = `Comp.tags` 通路(flat StringName,structures.md §7 纪律)。
- 构成玩法三轴:面(faces)/ 归属(who)/ 空间状态
  (动态组件的实 ↔ 虚、开 ↔ 关)。五幕 26 关正戏已在检验这三轴。
- 判定:**保留并升级**(方向性投入最高的系统)。

### 04 机关系统(按机制族分类,不再按物件名堆)

机关族**四分法**(新机关必须自报族别):

| 族 | 定义 | 现有成员 |
|---|---|---|
| **触发族** | 状态被"事件"翻转 | 踩踏开关 + 开关门板、推箱(顶入) |
| **状态族** | 自身有两态并可预读 | 传送对(A/B)、加速门(常态/强化) |
| **时间族** | 状态被"时钟"驱动 | 限时桥、移动平台(周期/相位) |
| **物理族** | 状态被"力学"驱动 | 曲面板、弹射板、滑雪带、推箱的滑动 |

- 时间族深挖方向:周期 / 相位 / 节拍对齐已具备——继续做
  **相位编排**(多机关相位差 = 空间节拍谱),不做单纯反应速度。
- 物理族深挖方向:动量守恒的传递链(圆推箱 → 箱压开关 → 门放行圆)
  = 真正的组合谜题。

### 05 多角色协作系统(第三层)

- **协作关系矩阵(定稿,关卡出题的查表依据)**:

| 协作 \ 几何体 | 疾 | 跃 | 逆 | 圆 | 伍 |
|---|---|---|---|---|---|
| 承载(驮) | ○ | **核心** | ○ | ○(载) | — |
| 踩头 / 顶弹 | ○ | **核心** | ○ | ○ | ○ |
| 加速(门/冲刺借力) | **核心** | ○ | ○ | **核心** | ○ |
| 重力(置换配合) | ○ | ○ | **核心** | ○ | ○ |
| 磁界(隔/穿/收放) | ○ | ○ | **核心·破解** | ○ | **核心** |
| 动能(推动/切线/弹射) | **核心** | ○ | ○ | **核心** | ○ |
| 同步归门 | ○ | ○ | ○ | ○ | **核心** |

- **组合协作的定义**(达标线):`A 改变环境 → B 利用环境 → B 再次改变
  环境 → A 继续前进`。只有 A 站 B 头上跳一下不算协作,只是位移。
  推箱(任何人顶)→ 滑雪带(滑行入位)→ 弹射(圆的切线接续)已经
  构成第一条三段组合链(试炼场 v5)。
- 判定:**保留并升级**;协作矩阵新增行 = 新协作动词立项。

### 06 关卡挑战系统

- 保留正典纪律:**一关只教一个新概念,组合放到后续关**。
- 正式关卡增加**六类职责**(每关登记,不止考试):
  教学(新概念)/ 练习(组合)/ 呼吸(演出与探索,不出题)/
  考试(章节收束)/ 剧情节点(幕间戏依附)/ 自由(多解沙盒)。
  **幕内节奏 = 教学→练习→呼吸→考试循环**,玩家不再时刻感觉在被出题。
- **多解法体系**:正式关卡的高台/缺口登记每种几何体的解——
  跃:顶弹直上 / 疾:冲刺跳远 / 逆:置换走另一面 / 圆:坡道切线飞越 /
  伍:磁界隔出第三条路。**角色能力 = 解谜语言**,一题多解是差异的证明。

### 07 重跑系统(第四层 · 固定空间 + 可变规则)

- **不做传统 Roguelike**(随机地图 / 战斗构建 / 局外数值)。正典方向
  (roguelike.md §4 手工排法)升级为:**同一空间的多次重新理解**——
  固定管道空间不变,变的是规则与身份:

| 次序 | 玩家获得的不是新地图,是新的眼睛 |
|---|---|
| 第一次 | 这条路长什么样(通行) |
| 第二次 | 换一个几何体,路变成另一条路(差异) |
| 第三次 | 带上词条,路出现没见过的走法(规则变奏) |
| 第四次 | 发现上次没看见的门/刻度(信息差) |
| 第五次 | 明白这条路被走过很多次(第四层真相,卷二 bible) |

- **词条四分类**(重组现有池):物理(现属性钩子)/ 空间(改 layer·faces·
  who 的读法——新增方向)/ 角色(专属强化,现池)/ **叙事**(携带
  记忆:某词条让旁白引用你上一局的死亡地点——bible 卷七落地件)。
- 判定:5 段红刻度 / 残段 / 精英考 / 手工排法全部**保留**;
  随机地图生成**废弃**(正典已判,本卷复核确认)。

### 08 角色成长系统(理解成长,五阶)

能力数值冻结,成长的度量 = 玩家操作熵的下降。以疾为例:

| 阶段 | 玩家状态 | 对应叙事 |
|---|---|---|
| 一 | 会按冲刺键 | "他相信跑得够快,孤独就追不上他" |
| 二 | 会冲刺+二段跳的组合距离 | 第一幕「引力排练」 |
| 三 | 会用爬墙副动词改写路线 | 第三幕单章「不是怕孤独追上我」 |
| 四 | 会**不按**冲刺——把停当作招式 | 第四幕「疾学会停」 |
| 五 | 无招:任何空间里知道疾该在哪 | 落幕之后 |

- 五阶与七幕一一锚定(bible 卷三弧光)——**玩法与剧情同步成长**,
  这是"理解成长"的验收方式:每一幕的考试关,考的就是该阶的操作。

### 09 探索系统(环境发现,不做开放世界)

- 探索 = **对同一环境的重复注视产生的信息增量**(与 bible 卷九信控
  同构)。同一扇终点门:第一次是装饰 → 后来发现门框上有刻度 → 再后来
  刻度与某形对应 → 最终那扇门属于"第七形"的记号。
- 载体:档案几何(五页签)渐进解锁条目 + 场景内可再注视物(不做
  采集清单)。判定:**保留方向,暂缓实装**(P4)。

### 10 剧情玩法系统(第五层)

- **剧情机制**:世界记住角色的经历并反馈为规则——
  角色记忆(同一角色第 N 次死亡,重生旁白逐次变化,第 4 次起台词
  开始怀疑"重拼的代价")/ 重生点漂移(某次重生,出生点不在原处
  = 剧情事件,不是 bug)。
- **叙事型机关**:普通机关=永远同一行为;叙事机关=**行为携带剧情
  状态**(例:限时桥在某幕后相位永久偏移半拍——玩家可感、可证,
  且只此一段)。登记制:每个叙事机关必须挂 bible 卷六伏笔账本条目。
- **角色专属路线**:大型关卡为每形留一条专属支路(不强制全走)——
  换角色重走 = 重新理解同一空间(与卷七重跑同构)。
- 判定:全部**暂缓至 P5**,但本文先立概念占位。

## 卷六 · 内容生产链与生命周期

**生产链(新内容的唯一入口,替代"想到就加"):**

```
提案(填组合矩阵行 + 能力预算检查)
 → 原型(试炼场新分区,机器验收)
 → 测试(双端手感 + 五门禁 + 真机)
 → 判定(保留观察 / 重构 / 废弃)
 → 登记(附录 A 能力表 + structures.md §7 + 图鉴)
 → 关卡应用(七维表正式关)
```

**生命周期状态机**:提案 → 原型 → 观察期 → 正式 / 重构 / 废弃。

## 卷七 · 异常系统(P5 占位 · 概念冻结)

异常不是 bug,是**被设计出来的世界现象**——世界在重演时留下的误差
(bible 卷七 玩家=隐藏变量的游戏化)。首例(冻结待拍板):某次重跑,
滑雪带的红刻度方向反了 / 推箱多了一箱——玩家开始调查,调查的尽头
是第七形。登记制:每个异常必须挂伏笔账本条目,并有一次"官方确认"
演出(异常被世界承认的那一刻 = 剧情节拍)。
