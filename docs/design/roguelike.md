# 肉鸽系统设计 · ROGUELIKE

> 状态:现行(v0.12 实装 · 技术方案见 `docs/ROADMAP.md` §4;本档是**设计侧**唯一权威)
> 一句话:一局制肉鸽 = **单人独立几何体**(选一位主角跑完全程)× 随机路线 ×
> 局内词条 × 局外解锁;死亡即结算。
> 实装:`scripts/modes/rogue/`(RunState / RogueDirector)+
> `scripts/data/run_modifiers.gd`(词条表)+ `scripts/data/rogue_fragments.gd`(片段库)。

## 1. 一局结构(定稿 · 单人制)

```
入口(选择本局主角几何体 · 单人独立成局)
  └─ 第一章:选路事件(二选一)→ 关卡 → 奖励三选一 ×2
	   └─ 第二章:同上
			└─ 第三章:同上
				 └─ 章末精英关(词条组合考)→ 结算
```

- **重跑没有同伴**:一局从头到尾只操控选定的那一位几何体;
  关卡里没有队友的头顶可踩,也没有别人的门可归——每个人的重跑,
  都是他自己的单章刻画(叙事见 `docs/design/story.md` §4c)。
- 单局 15–25 分钟;三章节各 2 关;死亡即结算,无中途复活。
- 选路事件:两张路线卡(构成主义大数字卡),标注"风险 / 收益"一句话,
  **两条路线是同一章节母题的快 / 稳两种排法**(例:
  「疾风断桥 · 快——缺口更宽,没有慢路」vs「疾风断桥 · 稳——缺口平缓,地面全程贯通」)。

## 2. 局内词条(RUN MODIFIERS,数据驱动 · 围绕几何体特性)

- 词条 = 属性钩子覆盖层:`RunState.modified(def, "base_speed" | "bounce" |
  "jump_units" | "weight" | "carry" | "buff_sprint_speed" | …)`,**不改 Player 逻辑**。
- 数值纪律:单词条幅度 ±0.5 以内,且覆盖后不突破 0.0–2.0 标尺(形状可读性)。
- **词条池 = 通用词条 + 本局主角的专属词条**——没有多人阵容加权,
  池直接按主角过滤:疾池不出置换词条,圆池不出攀爬词条;
  专属词条只强化该主角的核心机制(疾 = 冲刺 / 跳 / 爬;跃 = 弹性 /
  二段跳;逆 = 置换;圆 = 滚动 / 加速门)。

| 词条(示例池) | 归属 | 效果 | 稀有度 | 风险侧写 |
|---|---|---|---|---|
| 短拍节奏 | 通用 | 土狼时间 +0.04s | 常规 | 纯增益(手感词条) |
| 失重镀层 | 通用 | 重量 −0.3 | 常规 | 起步快、惯性变弱 |
| 玻璃疾走 | 通用 | 速度 +0.5,重落地即碎 | 危险 | 高风险高移速 |
| 高频踏点 | 疾 | 跳高 +0.3 格 | 稀有 | 跳跃系强化 |
| 云梯踏 | 跃 | 空中跳 +1(三段跳) | 稀有 | 跃的独门 |
| 琉璃跳 | 跃 | 跳高 +0.4,重落地即碎 | 危险 | 跃的高风险跳 |
| 逆行钟摆 | 逆 | 置换冷却 ×0.6 | 稀有 | 逆专属 |
| 无锚 | 逆 | 置换冷却 ×0.5,土狼 −0.04s | 危险 | 翻转更自由,落地窗口更小 |
| 润滑刻度 | 圆 | 摩擦 ×0.85(滑更远) | 常规 | 圆球更强 |
| 双倍门 | 圆 | 加速门效果翻倍(钳 3.75×) | 稀有 | 依赖关卡门密度 |
| 惯性核心 | 圆 | 摩擦 ×0.7 | 危险 | 极端滑行,极端失控 |

- 三选一保证:1 常规 + 1 稀有 + 1 危险,且**全部来自主角池**。

## 3. 局外解锁( meta )

- 货币:**刻度残段**(每局按最远章节 + 到站数结算)。
- 解锁内容 = 新词条入池 / 结算页装饰版式;**不解锁数值强度**
  (保证速度榜公平,如果做计时榜)。
- 存档:SaveManager 加 `rogue` 区段,`SAVE_VERSION` MINOR+1 迁移。

## 4. 随机性设计原则

1. 关卡随机 = **手工关卡片段 × 接口对齐**,不做纯程序生成 ——
   构成主义海报是"排"出来的,不是"长"出来的。
   单人制下片段**按主角分组设计**:每个片段只为一种几何体铺设
   (疾的缺口冲刺、跃的反弹攀高、逆的双面走廊、圆的坡道连滑),
   接口对齐 = 左端单一出生带、尾部单一归门、单场 1.5–3 分钟。
   选路二选一 = 同一章节母题的手工快 / 稳两种排法(手工参数变体,
   不是程序拼装)。
2. 词条三选一保证:1 常规 + 1 稀有 + 1 危险,全部来自主角池(§2)。
3. 精英关 = **每位主角一场专属大考**(当局已拿词条会在开场卡与考题
   措辞里点名——拿词条多的周目,考题更"针对")。
4. **片段引用组件语义**(v0.13 起协调项,levels.md §7):手工片段从
   "裸 Rect2 拼排"升级为"组件拼装"后,片段即可使用 lane / faces / who
   ——单人制下尤其顺理成章:逆片段的"双面走廊"就是 `faces=bottom`,
   `who` 专属件在单人局里天然只有主角一种读法。**原则不变**:片段仍
   手工排、接口对齐(左端出生带 / 尾部归门),组件语义库(levels.md §7)
   只是让拼排更快、语义更准,不是程序生成。

## 5. UI 组件复用

选路卡 / 词条卡 / 结算页全部复用构成主义组件(`scripts/ui/rogue_layer.gd`,
`Ui.poster_label / tag / rule`),
词条卡 = 大号数字编号 + 词条名 + 一句效果 + 稀有度色条(红=危险,黄=稀有,白=常规)。

## 6. 实装定稿补充(v0.12,与代码互为权威)

以下为规划未细化、实装时定稿的口径(改代码先改此处):

1. **单人独立几何体**:一局 roster = [主角] 一个几何体、一扇门;
   入口选择即"本局主角",四个主角各有一条专属片段链与专属词条池,
   剧情为该主角的单章刻画(story.md §4c)。
2. **红色刻度**:一局携带 **5 段**;死亡重生照常发生,每次重拼消耗 1 段;
   第 6 次死亡(刻度已尽)本局落幕 → 结算。序幕 §4 的伏笔即此规则。
3. **刻度残段**(局外货币)= 最远章节×3 + 到站数×1 + 精英考×3 + 全通加成 6
   (到站数 = 归门次数:单人每场 1 次,一局 9 场)。整局全通约 33,
   单章失利约 8–15;词条兑换价:常规 10 / 危险 12 / 稀有 15
   (外加结算页装饰版式 25)。
4. **词条池**:通用 4 条(短拍节奏 / 失重镀层 / 顺风格 / 沉稳底盘)+
   主角专属 8 条(疾:高频踏点;跃:云梯踏 / 琉璃跳;逆:逆行钟摆 /
   无锚;圆:润滑刻度 / 双倍门 / 惯性核心)+ 通用向危险 1 条(玻璃疾走)。
   初始入池 = 通用 2 + 各主角专属的常规 1 条(圆为润滑刻度)+
   玻璃疾走;其余用残段在结算页兑换入池。
5. **属性钩子键**:六项标尺属性(base_speed / bounce / jump_units / weight /
   carry / buff_sprint_speed)覆盖后钳制回 0.0–2.0;另有
   friction(摩擦倍率)/ coyote(土狼 +s)/ swap_cooldown(置换冷却)/
   air_jumps(空中跳次数,跃专属「云梯踏」)/ gate_mult(双倍门,
   加速门强化后的上限 ×2、全局钳 3.75×)/ glass(重落地冲击 >620 即碎)。
6. **精英考**:每位主角一场专属大考(疾 = 天隙试炼 / 跃 = 无桥天空 /
   逆 = 深渊回廊 / 圆 = 终末过山车);当局词条写在考题措辞里。
7. **选路随机**:每章 = 该主角本章母题的快 / 稳两种手工排法,二选一;
   随机性落在词条三选一与玩家的路线取舍上。
