# 肉鸽系统设计 · ROGUELIKE

> 状态:规划(技术方案见 `docs/ROADMAP.md` §4;本档是**设计侧**唯一权威)
> 一句话:一局制肉鸽 = 随机路线 × 局内词条 × 局外解锁;死亡即结算。

## 1. 一局结构(定稿)

```
入口(选择初始几何体)
  └─ 第一章:选路事件(二选一)→ 关卡 → 奖励三选一 ×2
       └─ 第二章:同上
            └─ 第三章:同上
                 └─ 章末精英关(词条组合考)→ 结算
```

- 单局 25–35 分钟;三章节各 2 关;死亡即结算,无中途复活。
- 选路事件:两张路线卡(构成主义大数字卡),标注"风险 / 收益"一句话。
  例:「加速门密道(快,门后无补给)」vs「承重长梯(慢,奖励+1 词条池)」。

## 2. 局内词条(RUN MODIFIERS,数据驱动)

- 词条 = 属性钩子覆盖层:`RunState.modified(def, "base_speed" | "bounce" |
  "jump_units" | "weight" | "carry" | "buff_sprint_speed")`,**不改 Player 逻辑**。
- 数值纪律:单词条幅度 ±0.5 以内,且覆盖后不突破 0.0–2.0 标尺(形状可读性)。

| 词条(示例池) | 效果 | 稀有度 | 风险侧写 |
|---|---|---|---|
| 润滑刻度 | 摩擦 ×0.85(滑更远) | 常规 | 圆球更强,方块更难停 |
| 红色弹簧 | 落地反弹 +0.3 | 常规 | 跃近神,疾需适应 |
| 短拍节奏 | 土狼时间 +0.04s | 常规 | 纯增益(手感词条) |
| 失重镀层 | 重量 −0.3 | 常规 | 起步快、承载判定变弱 |
| 双倍门 | 加速门效果翻倍 | 稀有 | 依赖关卡门密度 |
| 超载许可 | 负重力 +0.5 | 稀有 | 堆叠流派核心 |
| 玻璃疾走 | 速度 +0.5,受击即死 | 危险 | 高风险高移速 |
| 逆行钟摆 | 置换冷却 −0.1s | 稀有 | 逆专属 |

- 词条池按"队伍当前几何体"加权:没带圆就不出滚动专属词条。

## 3. 局外解锁( meta )

- 货币:**刻度残段**(每局按最远章节 + 到站数结算)。
- 解锁内容 = 新词条入池 / 新几何体 / 结算页装饰版式;**不解锁数值强度**
  (保证速度榜公平,如果做计时榜)。
- 存档:SaveManager 加 `rogue` 区段,`SAVE_VERSION` MINOR+1 迁移。

## 4. 随机性设计原则

1. 关卡随机 = **手工关卡片段 × 接口对齐**(片段出入口高度标准化),
   不做纯程序生成 —— 构成主义海报是"排"出来的,不是"长"出来的。
2. 词条三选一保证:1 常规 + 1 稀有 + 1 危险(至少一张与队伍相关)。
3. 精英关 = 当局已拿词条的组合考试(拿词条多的周目,考题更"针对")。

## 5. UI 组件复用

选路卡 / 词条卡 / 结算页全部复用构成主义组件:`Ui.poster_label / tag / rule`,
词条卡 = 大号数字编号 + 词条名 + 一句效果 + 稀有度色条(红=危险,黄=稀有,白=常规)。
