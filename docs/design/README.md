# 设计总纲 · GEOMETRIC CONSTRUCT

> **几何构成**(英文名 **GEOMETRIC CONSTRUCT**)· 构成主义几何肉鸽游戏
> 美术锚定:**构成主义 + 几何棱角分明 + 极简主义 + 动态感**。
>
> 本目录是策划侧设计信息的分类档案库;技术结构见 `docs/ARCHITECTURE.md`,
> 后续规划见 `docs/ROADMAP.md`。**改设计先改这里的文档,再改代码。**

## 设计三支柱

1. **形状即性格,属性即命运** —— 每个几何体的玩法能力、叙事性格、视觉形态三位一体。
2. **一切构成,皆有动态** —— 构成主义不只是静态海报:背景呼吸、平台律动、UI 弹入,
   画面里没有一块"死"色块;但所有运动都走直线、折角、硬停顿,拒绝柔滑弹簧。
3. **一米一格的诚实** —— 1 格 = 100 px,属性标尺 v2:常规域 -1.0–3.0
   (基准 2.0,-1.0 = 关闭,硬顶 5.0,肉鸽不设限);关卡里能看见的
   高度差,就一定是能力表里读得出来的数值。名词定义见 `glossary.md`。
