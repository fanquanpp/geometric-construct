> (手感公约数)——不一致时以代码为准并回改本文。
> 相关文档:属性标尺 `docs/DESIGN.md` §2;关卡数值规范 `design/levels.md` §1;
> 词条 `design/roguelike.md` §2;图层语义 `design/levels.md` §7;声线 `design/story.md`。

## 0. 角色设计原则

1. **主动词唯一,副动词受限**:每角色绑定**一个**"别的角色做不到"的主动词
   (疾=冲、跃=弹、逆=翻、圆=滚);疾的爬墙是**副动词**——预算受限
   (单次离地 2.0 格),只服务主动词(墙上不断速),不得作为独立解谜轴
   出题。副动词登记制:新角色增设副动词须在 §10 立项。
2. **部分不对称**(业界验证的结构):四人**共享同一物理基座**(§2 手感公约数),
   差异只落在七项标尺属性 + 动词开关——平衡杠杆是**互依赖**
   (每个人的短板由别人的动词或系统补偿补齐),不是拉平数值。
3. **性格 = 物理手感的叙事化**:加速慢的必然台词沉稳;反弹猛的必然性格张扬。
   手感先于台词定稿,台词是手感的翻译。
4. **形体可读 = 数值可读**:形状轮廓剪影即可辨认;颜色按"黄>红>橙>蓝"
   递减重量,与属性表严格一致(承载判定直觉化);"形状可读"纪律同样约束
   词条与成长——覆盖后不突破 0.0–2.0 标尺。

## 1. 属性总标尺与利用率(数值健康度)

全部属性 0.0–2.0:1.0 = 标准基准,0.0 = 不具备,2.0 = 上限。
1.0 属性单位 = 100 px(1 格)。跳高(格)= `jump_units`,与弹性解耦;
可跳台阶高度必须比 jump_units 低 0.1(留 10% 手感余量)。

| 角色 | 形态 | 大小(px) | 速度 | 冲刺 | 加速门 | 弹性 | 跳高 | 重量 | 负重力 | 动词 |
|---|---|---|---|---|---|---|---|---|---|---|
| 疾 | 红色正方形 | 56×56 | 1.0 | 1.5 | 1.5 | 0.5 | 2.0 | 1.0 | 1.0 | 冲(副:爬) |
| 跃 | 黄色竖长方形 | 48×100 | 1.0 | — | — | **2.0** | 2.0 | **1.5** | **1.5** | 弹 / 承载 |
| 逆 | 蓝色镜像正方形 | 36×40 | 0.5 | 1.2 | 2.0 | 0.5 | —(置换) | 0.2 | 0.5 | 翻 |
| 圆 | 橙色圆球形 | 52×52 | **1.5 固定** | — | 2.5 | 0.5 | —(不可跳) | 0.5 | 0.0 | 滚 |

**标尺利用率**(v0.13 分析):区分度主要靠**动词开关 + 速度轴**,
弹 / 跳轴是"身份标记"而非梯度——少即是可读,健康:

| 轴 | 实际使用区间 | 读法 |
|---|---|---|
| 速度 | 基础 0.5–1.5;门后 1.0–2.5 | 全员轴;圆 2.5 是唯一超标尺例外(竞速身份) |
| 弹性 | 两点 {0.5, 2.0} | 跃独占 2.0 = 身份标记 |
| 跳高 | 两点 {0, 2.0} | 可跳者统一 2.0:跳高不区分,**射程**才区分(§3) |
| 重量 | 0.2–1.5 连续 | 利用最充分的真梯度(加速度 / 摩擦 / 承载三处生效) |
| 负重力 | 0.0–1.5 | 圆 0.0 = "头顶站人即超载"的性格数值 |

- 重量序:跃 1.5 > 疾 1.0 > 圆 0.5 > 逆 0.2(黄>红>橙>蓝)。
- 承载:任何几何体都可站上同伴头顶;头顶总重 > 负重力 → 跳高减半
  (`OVERLOAD_JUMP_RATIO 0.5`,不禁止)。组合表见 §4。

## 2. 手感公约数(全员共享的宽容数值 · v0.13 新章)

> 对齐 Celeste 的"宽容优先"哲学(Maddy Makes Games《Celeste & Forgiveness》:
> 土狼时间 / 输入缓冲 / 数字在模糊处静默偏袒玩家)。以下参数出自
> `player.gd`,**四人不分彼此**——角色差异只在 §1 标尺,不在手感。

| 公约数 | 值 | 效果 |
|---|---|---|
| 重力 | 1500 px/s² | 全员同一 |
| 三段重力 | 下落 ×1.24 / 顶点 ×0.86 | 下落利落、顶点微悬停(跳-落曲线不对称) |
| 土狼时间 | 离地短暂窗口内仍可起跳 | 边缘起跳宽容 |
| 跳跃缓冲 | 0.12s | 落地前按跳,落地帧自动起跳 |
| 低速站稳 | 落地速度 <240 不反弹 | 微跌不弹手 |
| 落地收敛 | 未按跳的反弹 ×0.8 衰减 | 自然站稳 |
| 载具携带 | 站立者继承平台速度 | 电梯 / 移动板全员可用 |
| 终端速度 | 1150 px/s | 二次空气阻力渐近 |

派生公式(档案页 `stat_rows()` 展示的读数换算):
速度 → v = 倍率 × 300 px/s(3 格/秒);跳高 → h = v₀²/2g;
反弹率 e = bounce × 0.5;摩擦减速度 a = μ·g(标准 μ ≈ 1.27)。

## 3. 射程矩阵:角色 × 缺口宽度(v0.13 新章,与 levels.md §1 互锁)

水平射程 ∝ 水平速度 × 滞空时间——**速度是射程的乘数**,
这就是"跳高全员统一、区分度在速度"的推论:

| 手段 | 覆盖缺口 | 归属 |
|---|---|---|
| 普通跳(速度 1.0) | 1.2–1.9 格 | 疾 / 跃 |
| 二段跳(两连跳 4.0 格高) | ≤2.6 格 | 疾 / 跃 |
| 冲刺 + 二段跳(疾 1.5×) | 3.5+ 格 | 疾 |
| 踩头接力(借跃 1.0 格头高) | +约 1 格 | 跃 × 任意 |
| 置换翻面(越不可跳障碍) | 竖直维度 | 逆 |
| 加速门 2.5× + 曲面 1.5× | 7.5–7.8 格 | 圆(证明射程,04 / 05 场同参数) |
| 电梯 / Express | 任意高差(慢路) | 全员(双线法则,levels.md §6.3) |

**速度-效用权衡表**(互依赖即平衡):

| 角色 | 付出的代价 | 系统级补偿 |
|---|---|---|
| 逆 | 基础速度 0.5 全场最慢;无跳 | 门后 2.0×(弱者翻身的补偿曲线);置换独占竖直第三维 |
| 圆 | 不可跳;负重力 0.0 | 固定极速 1.5 + 门后 2.5 超标尺;曲面切线飞跃 |
| 跃 | 全程 1.0 无加速手段 | 承载 1.5 全场最佳驮手;弹性 2.0 反弹即再起跳 |
| 疾 | 无(基准角色) | —(新人第一角色的锚点,全部数值 = 1.0 基准) |

## 4. 承载与重量链(v0.13 新章)

驮手负重力 vs 头顶总重(超载 = 跳高减半,不禁止):

| 驮手 ↓ / 头顶 → | 疾(1.0) | 跃(1.5) | 逆(0.2) | 圆(0.5) |
|---|---|---|---|---|
| **跃**(负重 1.5) | ✓ | ✗ 超载(3.0) | ✓ | ✓ |
| **疾**(负重 1.0) | — | ✗ | ✓ | ✓ |
| **逆**(负重 0.5) | ✗ | ✗ | — | ✓ 贴线 |
| **圆**(负重 0.0) | ✗ 即超载 | ✗ | ✗ | — |

- 双人叠载:跃可同时驮 疾+逆(1.2 < 1.5)✓;疾驮 逆+圆(0.7 < 1.0)✓。
- 设计含义:**跃是唯一的"全自动驮手"**,圆是永远的乘客——
  承载关(06 承接天桥)的分工由此表唯一确定,出题时先查此表。

## 5. 角色档案

### 疾 · 红色正方形 · 速度型

- **剪影**:等边正方形,左上 40% 宽硬高光条;活跃时白色取景框 + 呼吸角块。
- **手感**:标准加速 / 摩擦;冲刺 1.5×;速度越快跳得越远(跳远 ∝ 速度)。
- **爬墙(副动词)**:贴墙按住朝墙方向缓降 55 px/s;按住跳跃 150 px/s 攀升,
  单次离地 2.0 格预算;贴墙点按跳跃 = 沿墙上蹭(消耗一次空中跳);
  翻过墙顶水平动量自然上台。
- **数值理由**:全部 1.0 = 新人锚点;他的存在让其他三人的"偏离"可被感知。
- **系统配合**:图层系统 `who={疾}` 专属墙(§6)= 爬墙即通行证。
- **性格**:急躁、怕停。台词围绕"速度 = 安全"。
- **代表台词**:"疾。他相信只要跑得够快,孤独就追不上他。"

### 跃 · 黄色竖长方形 · 弹性型

- **剪影**:1:2 竖长方形,全场最高(1.0 格),天然"活台阶"。
- **手感**:弹性 2.0 固定,反弹率 100%,落地瞬间按住跳跃主动发力更高;
  二段跳每次 2.0 格、两连跳 4.0 格;负重力 1.5,最佳驮手(§4)。
- **数值理由**:速度 1.0 且无加速 = 全场位移最慢梯队,由"会走路的台阶"
  定位补偿——她的价值不在自己到得多快,在把别人送到多高。
- **系统配合**:承载链(§4)+ `who={跃}` 专属弹面(立项候选,见 §6)。
- **性格**:沉稳可靠、以托举为荣。台词围绕"高度与接住"。
- **代表台词**:"跃。把坠落折叠成上升,她从不害怕高度。"

### 逆 · 蓝色镜像正方形 · 置换型

- **剪影**:最小几何体(0.36×0.40 格),躯干上下双向箭头刻度;置换后天空在脚下。
- **手感**:速度仅 0.5;跳跃键 = 置换(重力翻转,水平惯性完整保留,
  落地缓冲 ×0.55 防上下平台乒乓);过加速门上限 2.0×。
- **数值理由**:重量 0.2 = 加速度全场最快(BASE_ACCEL ÷ 0.2),
  "轻"是手感的浮与飘;门后 2.0 是"弱者翻身"的补偿曲线。
- **系统配合**:图层系统 `faces=bottom` 专属面(§6)= 置换目标过滤的
  唯一受益者,天花板即他的路网。
- **性格**:冷淡、超然。台词把"上下"说成"两个面"。
- **代表台词**:"逆。对你们是天与地,对他只是两个可以落脚的面。"

### 圆 · 橙色圆球形 · 滚动型

- **剪影**:双色调半球 + 4 枚轮辐刻度 + 单指针辐条 + 纸白轮毂;滚动按 v/r
  纯滚动,空中保留角动量;高速轮辐自动减淡(防频闪);挤压在屏幕空间、
  与旋转解耦。
- **手感**:固定极速 1.5× 起步即全速;滚动摩擦 0.43(惯性长滑);不可跳;
  坡面贴角 60°,曲面板上速度对齐切线、滑出即飞跃;滚动轰鸣音随速度调制。
- **数值理由**:四无(冲/跳/翻/爬全无)+ 双超标尺(速度 1.5、门后 2.5)
  = "被动能力换主动权"的极端样本——他的操作全是时机,不是按键。
- **系统配合**:动态构件 TimedBridge / 加速门链(§6)= 速度即他的通行证。
- **性格**:沉默向前、从不回头。台词只有肯定句。
- **代表台词**:"圆。他不会跳,所以他从不回头。"

## 6. 角色 × 系统配合矩阵(v0.13 新章)

> 角色设计不是孤立数值表——每个动词都在其他系统里有"放大器"。
> 新角色立项必须填满本表每一行,填不满 = 动词与系统脱钩,不立项。

| 系统 | 疾 | 跃 | 逆 | 圆 |
|---|---|---|---|---|
| **图层系统** who/faces(levels.md §7) | `who={疾}` 专属墙:爬墙即通行证 | (候选)`who={跃}` 专属弹面:弹性起跳再+50% 高 | `faces=bottom` 天花板面:置换目标过滤唯一受益者 | 无需专属件:速度即通行证(门链 + 限时桥的时机客) |
| **肉鸽词条**(roguelike.md §2) | 高频踏点(跳高+0.3)/ 玻璃疾走 | 云梯踏(三段跳)/ 琉璃跳 | 逆行钟摆(冷却×0.6)/ 无锚 | 润滑刻度 / 双倍门 / 惯性核心 |
| **动态构件**(structures.md §5) | 爬墙 + LeverGate 高墙绕行 | LeverGate 的"驻板人"(站开关) | TimedBridge 虚化期置换穿层 | TimedBridge 实心窗冲刺穿越 |
| **编辑器**(editor.md) | who 预设「疾专属」一键 | 承载点摆放 + 配对医生验承载路 | who 预设「逆的天花板」 | 路径医生按 2.5× 射程验缺口 |
| **UI 档案页**(geometry_panel) | stat_rows 全派生公式 | 同左 | 同左 | 同左 |
| **音乐**(audio.md §4) | 冲刺跳 = 切分跳音 | 高反弹 = 同音颤音 | 天花砖对答(低音问高音答) | 滚过 = 连续琶音 |
| **叙事**(story.md) | 速度=安全 | 高度与接住 | 两个可以落脚的面 | 从不回头 |

## 7. 视觉规范(实体绘制)

- 本体:StyleBoxFlat 纯色直角色块(圆球除外);左上硬高光条 40% 宽 × 3px。
- 活跃指示:白色取景框(1.6px)+ 角色色呼吸角块(周期约 1.9s,符合 M5)。
- 特性刻度:爬墙握点(白色横刻度 ×3)、置换双向箭头、反重力向上箭头。
- 高速残影:>1.2× 速度后 6 帧拖尾,透明度 0.16 递进;颜色 = 角色色。
- 挤压拉伸:起跳(0.78, 1.24)落地(0.72, 1.3),恢复速率 3.2/s;圆球屏幕空间解耦。

## 9. 成长与肉鸽(局内满级形态)

- 肉鸽词条直接覆盖属性标尺(`RunState.modified(def, "xxx")`),
  幅度 ±0.5 以内,禁止突破 0.0–2.0 标尺——保持"形状可读"。
- **各角色满级形态**(词条 × 叠乘系统,规划上限):

| 角色 | 局内满级形态 | 上限来源 |
|---|---|---|
| 疾 | 速度 2.0 / 跳高 2.5 格 / 土狼 +0.04s | 词条钳制;玻璃疾走自缚条款 |
| 跃 | 三段跳(空中跳 +1)→ 两连跳 6.0 格 | 云梯踏;跳高轴不破 2.0 |
| 逆 | 置换冷却 ×0.6 ≈ 3.3 次/10s(无锚 ×0.5 减土狼) | 词条钩子 swap_cooldown |
| 圆 | 门后 3.75×(双倍门钳制) | `MOD_SPEED_CAP 3.75` 全局钳 |

- 新角色(规划):梯形(分身)、菱形(斜向冲刺)…… 数据表只能尾部追加,
  立项约束见 §10,数据模板见 `docs/UPDATE.md` 内容包章节。

## 10. 新角色立项约束(v0.13 扩充)

1. **动词登记**:主动词一个(不得与 冲/弹/翻/滚 语义重叠),副动词受限
   (§0 原则 1);梯形"分身"与菱形"斜向冲刺"暂占候选位。
2. **标尺预留检查**:速度轴基础段 0.5–1.5 已被四人占满三个锚点
   (0.5 / 1.0 / 1.5)——新角色要么复用锚点(差异化靠动词),要么开辟
   新轴,禁止在速度轴硬挤第四值。
3. **配合矩阵填空**(§6):六个系统逐一填,填不满不立项。
4. **内容量级**:新 GeometryDef + SVG 素材 + 单人片段链(roguelike.md)
   + 专属词条池 + 编辑器 who 预设 + 档案页适配——完整版本量,
   按 ROADMAP 立项流程走。
