## 卷〇 · 总纲:三层铁律与一体化体系

**三层铁律(本方案第一原则):**

```
Architecture 建筑 —— "这个世界是什么样的地方?"(只管身份与外观)
Structure 结构    —— "玩家站在哪里、走在哪里?"(只管碰撞与通行)
Mechanism 机关    —— "空间为什么会改变?"(只管状态与规则)
```

- 一个实体**不得**同时负责 外观+碰撞+状态+玩法+剧情 五事;
- 跨层行为用**行为标签**表达(§四 四层模型),不新增混合实体类;
- 判据:删掉它的外观,玩法是否不变?不变 = 它首先是 Structure。

**一体化体系(最终形态):**

> 形状 → 结构 → 空间 → 机关 → 角色 → 玩法 → 剧情

|---|---|---|---|

| A08 | Bridge 桥面 | 跨缺薄板 | Walkable(常配机关) |
| A09 | Frame 框架 | 柱+梁+洞口 | 构图骨架 |
| A10 | Ring 环 | 环形构件 | 空间回路 |
| A11 | Tower 塔 | 竖直高构件组 | 垂直关卡核 |
| A12 | Hall 厅 | 大跨度空间 | 尺度演出 |
| A13 | Corridor 回廊 | 狭长通道 | 压迫/对答 |

每个构件登记十二项:`ID / 名称 / 几何原型 / 尺寸 / 比例 / 材质 /
视觉层 / 碰撞 / 可否交互 / 可否移动 / 所属建筑类型 / 所属章节`。

### 建筑组合语法(用语言写关卡)

```
FRAME  = Pillar + Beam + Opening
HALL   = Floor + Wall + Pillar + Gate
BRIDGE = Support + Span + Exit
TOWER  = Shaft + Platform×n + Wall + TopGate
TUBE   = Floor + Ceiling + Wall×n        ← 试炼场 v5 即 TUBE 语法
```

- 组合语法 = 关卡的"句法";量尺表(levels.md §8)= 语法中的"词法";
- 新正式关卡 = 从 Kit 取件、按语法组句,**不再逐块手捏**。

## 卷三 · 实体四层模型(一个实体,四张脸)

```
Entity
├── Geometry  形状 / 尺寸 / 比例
├── Function  Walkable / Blocking / Climbable / Interactive
├── Visual    材质 / 颜色 / 风格(八语言,art-audio 卷二)/ Animation
└── Narrative 含义 / 章节 / Lore / Foreshadowing
```

- **一形多皮**:同一 Pillar 可有 Constructivist / Industrial / Theatre /
  Archive / Anomaly 五种 Visual 皮——**碰撞、尺寸、空间语义、玩法属性
  保持一致**(八语言融合矩阵领地规则,art-audio 卷二)。
- 四层数据落点:Geometry/Function 进 LevelDef 组件字典(现有
  rect/id/layer/faces/who/tags 即前两层);Visual 走风格层;Narrative
  走 bible 伏笔账本引用(related 机制)。

## 卷六 · 机关八族与等级(gameplay.md 四族升格)

| 族 | 定义 | 现有成员(迁移) |
|---|---|---|
| **Trigger** | 玩家做了什么 → 世界响应 | 踩踏开关、记录点信标;推箱顶入(兼) |
| **State** | 世界当前状态(开/关/实/虚/A/B) | 开关门板、传送对 |
| **Time** | 世界什么时候改变 | 限时桥、移动平台(周期/相位/节拍) |
| **Motion** | 空间怎么运动 | 移动平台/电梯(摆渡) |
| **Space** | **改变空间本身**(翻转/重构/开闭) | 磁界(可达性)、终点门(归位规则) |
| **Physics** | 改变物理规则 | 弹射板、滑雪带、加速门、曲面板(增益) |
| **Character** | 角色能力×空间结构 | 充电桩(伍,暂缓) |
| **Combination** | 机关链(多机关编排) | 现无独立成员;组合句见卷七矩阵 |

- **Character 族纪律**:角色专属机关必须满足
  `角色能力 + 空间结构 = 机关玩法`,禁止做成"只有某角色能碰的普通门"。
- **机关等级 M0–M6**(关卡复杂度控制):M0 反馈(琴键)→ M1 单机制
  (加速门/桥/坡)→ M2 机制组合(气闸/推箱)→ M3 角色机制
  (磁界/置换配合)→ M4 多角色机制(承载链/双落点门)→ M5 空间重构
  (传送对/规划中的空间翻转)→ M6 世界级(归门规则/终点门体系)。
  正式关的机关配比按 M 级阶梯排布,不许全程 M2。

## 卷七 · 组合矩阵(机制 × 几何 × 机关链)

**单组合(正典 + v0.27,节选):** 疾×开关=高速触发 / 跃×移动平台=垂直
运输 / 逆×重力门=空间翻转 / 圆×坡=惯性加速 / 伍×磁界=双体协作 /
逆×磁界=唯一穿越 / 圆×曲面=切线飞越 / 跃×顶=全员翻倍跳。

**链组合(M2+):** 疾冲刺→撞开关→桥现→跃过桥→到高处→启逆的重力
结构 = **机关链**(Combination 族的玩法形态)。链条登记制:每条链
`触发者→机关序列→受益者` 三元组入关卡七维表。

## 卷八 · 特殊建筑与地标(SP / L)

**特殊建筑五重身份(缺一不立项):**
`空间身份 / 玩法身份 / 视觉身份 / 听觉身份 / 叙事身份`。

例·速度圣殿(SP03,第一幕正典场次):空间=长距离高速通道 / 玩法=
疾·圆 / 视觉=高速线与轴线 / 听觉=高 BPM 连续节奏 / 叙事=疾对
"停下"的理解。

**地标(L)**:红色刻度(全游戏唯一恒在地标,视觉/导航/章节/剧情/
听觉五识别统一);后续候选:大风琴 / 第七形遗迹(均冻结至对应幕)。
地标纪律:地标是**空间导航锚**,不做装饰背景;每个地标必须在
atmosphere 剪影层与 audio 动机库各有一个识别条目。

## 卷九 · GEOMETRY LANGUAGE(几何即世界语法)

五形的身份语言反向定义建筑与 UI:

| 形 | 空间语言 | 建筑映射 | 音乐映射 |
|---|---|---|---|
| 疾 | 锐角 / 长轴 / 前进 | 疾之建筑:锐角+长轴 | 切分跳音 |
| 跃 | 垂直 / 升降 | 跃之建筑:垂直结构 | 上行音+高八度 |
| 逆 | 双面 / 镜像 | 逆之建筑:镜像空间 | 八度对答 |
| 圆 | 曲线 / 环 | 圆之建筑:圆环与曲线 | 连续琶音 |
| 伍 | 双体 / 关系 | 伍之建筑:双柱双通道 | sol/la 双声部 |

- 世界观升格:**整个世界由几何关系构成**——特殊建筑可以是
  "巨型几何体"(SP 速度圣殿=疾之建筑的 Tier3 形态)。
- 与 art-audio 卷三母条目、audio.md 角色画像三向互锁:
  形(视觉)/音(听觉)/性(玩法)一致性检查 = 实体立项必过。

## 卷十 · 实体设计矩阵与组合矩阵

**设计矩阵**(每实体必填,附录活表):`ID / 类型 / 几何 / 玩法 / 视觉 /
音频 / 剧情 / 角色 / 状态`。

**组合矩阵**(机制×几何×机关链,节选正典+v0.27):
疾×开关=高速触发 / 跃×移动平台=垂直运输 / 逆×重力门=翻转 /
圆×坡=惯性加速 / 伍×磁界=双体协作 / 疾×跃×限时桥=接力 /
逆×圆×曲面=反重力惯性 / 伍×机关×双门=分离重聚 /
推箱×滑雪带=急滑入位 / 弹射×传送=抛物接折叠空间。
新实体不进矩阵 = 不合入(与 gameplay.md 卷三准入表并轨)。

## 卷十一 · 生产流水线(三线)

```
新增建筑:概念→几何定义→空间语义→玩法定义→视觉→音频→剧情意义
         →Prototype→机制试炼道→Level Integration→Archive→QA
新增机关:Concept→Trigger→State→Input→Output→Combination
         →Visual→Audio→Level→Archive
新增几何体:Shape→Physics→Movement→Ability→Interaction→Visual
          →Audio→Story→Level→Rerun
```

三线共用**准入三表**:实体设计矩阵(卷十)/ 组合矩阵(卷七)/
能力预算(characters.md §0)。流水线终点 = ArchiveData 条目 +
图鉴 PNG(glossary §2 登记)。

## 卷十二 · 设计禁区(15 条,全量正典化)

1. 禁止无玩法意义的建筑;2. 禁止无限增机关;3. 禁止单机关承载过多
互异规则;4. 禁止每章重发明建筑语言;5. 禁止用"给角色加技能"解决
设计问题;6. 禁止同建筑因风格不同重实现逻辑;7. 禁止机关逻辑写死
具体关卡;8. 禁止建筑/机关/角色互相直接依赖;9. 禁止一次性系统;
10. 特殊建筑不得沦为巨型装饰;11. 机关不得只有"开门"一种反馈;
12. **不得仅靠颜色区分**(形状/位置/运动/关系/声音/节奏承担信息);
13. 特殊建筑不得仅靠剧情文本解释;14. 新实体必须进组合矩阵;
15. 新内容必须进 Archive/Data/QA 生命周期。

## 卷十四 · 与总体系的关系(收敛)

```
WORLD(本文:实体分类/语法/等级)
   ↓ 提供 SPACE
GAMEPLAY(gameplay.md:五层核心/组合矩阵)
   ↓ 承载
STORY(bible.md:真相/弧光/信控)
   ↓ 表现
ART-AUDIO(八语言/动机库/融合五联)
   ↓ 组织给玩家
UI(00-ui-master-plan:六空间/DetailPage/Related)
   ↓ 沉淀
ARCHIVE(玩家理解世界的第二套系统)
```

`Geometry → Relationship → Construction → Interaction → Meaning`——
建筑、机关、几何体、UI、音乐、剧情不再是六个设计部门,
而是同一体系的不同表现形态。
