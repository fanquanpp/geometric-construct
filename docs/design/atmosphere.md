# 氛围设计 · ATMOSPHERE(背景装饰 × 光影)

> 状态:现行(v0.12 实装底子 · 2026-09-09 背景迭代与光影规划定稿)
> 数据源:`scripts/world/backdrop.gd`(视差背景)+ `backdrop.gd` GridLayer
> (levels.md §8 网格);法则与禁令仍以 `art-style.md` 为唯一权威。
> 一句话:构成主义氛围 = **明度分级 + 剪影叙事**,不是真实光照——
> 光是平面色块抬亮,影是硬边直角暗多边形;禁柔光禁渐变在本档全文有效。

## 0. 氛围三件套

| 件 | 内容 | 现状 |
|---|---|---|
| 背景装饰 | 巨面 / 太阳 / 星阵 / 山脊 / 方尘(视差) | ✓ 实装(§1 迭代) |
| 结构剪影 | 本关巨构的远视剪影层 | **新增规划**(§1.2) |
| 光影 | 天光带 / 区域明度 / 章节光色 | **新增规划**(§2) |

## 1. 背景装饰迭代

### 1.1 视差分层规范(现状正式化)

| 带 | scroll_scale | 成员 | 亮度纪律 |
|---|---|---|---|
| 天体带 | 0.04–0.12 | 深空星野(银河带 + 十字亮星 + 8Hz 闪烁,v0.37)/ 几何太阳 / 方点星阵 | PAPER ≤14%(现状) |
| **剪影带(新)** | 0.20–0.35 | 本关巨构剪影(§1.2) | **PAPER ≤5%** |
| 山脊带 | 0.32 / 0.58 | 折线山脊 ×2 | 实色 INK 系(#1A1E26 / #14171E) |
| 方尘 | 屏幕空间 | CPUParticles 22+12 颗 | PAPER 9–15% |

- 分层判据:越远越静(慢 scroll / 低对比 / 无动效),方尘是唯一"活"层(M5 呼吸量级)。
- 与网格协调(levels.md §8):剪影带亮度压在网格线对比之下,远景网格
  LOD 点阵仍可读;剪影多边形边线避免与 5 格主线同频(防摩尔纹,
  `--tourshot` 远景帧校验)。

### 1.2 结构剪影层(新增,背景讲关卡的剧)

- **定义**:本关核心巨构的剪影多边形,置于天体与山脊之间——
  门厅关 = 巨柱与东塔剪影 / 大风琴关 = 四根音管剪影 / 穹顶关 = 放射曲面
  剪影 / 速度圣殿 = 高架长桥剪影。玩家还没进关,先在背景里"读到"本关的剧。
- **数据驱动**:`LevelDef` 新增 `backdrop_theme`(枚举:default / atrium /
  organ / dome / viaduct / …),backdrop 按 theme 实例化对应剪影组;
  **旧关缺省 default = 现状零迁移**;关卡属性字段可选(Comp 语义)。
- **来源两种**:a) 从 platforms 数据自动推导(取本关最大 2–3 个结构的
  外接多边形,缩放 0.6 + 降 5% 亮度——零手工);b) 手工多边形微调
  (关键关用)。首版走 a,验收不满意再手工。
- 红点缀:剪影层允许 ≤2 处红刻度块(5% 亮度剪影上的构成红小点,
  章节色密度规则不变)。

### 1.3 方尘与风(低优先规划)

方尘现状为全向漂浮;巨构关可给方向偏移( wind 向东),让"空气"也有
构成方向感。仅调 velocity,不加层。

## 2. 光影设计(构成主义光影语言)

### 2.1 语言定义

> 真实光照(径向衰减 / 柔光)违反 art-style §2 禁令。本作光影 = 三种
> **平面手段**,与硬投影同语言:

| 手段 | 定义 | 语言约束 |
|---|---|---|
| **天光带** | 巨构顶部开口 / 出音口向地面投下的**平行四边形亮带**(平行光投影的亮版) | 直角边界;PAPER·6–10%;落点 = 地面可走处 |
| **区域明度带** | 关卡按区域整体调明度(深谷 0.85 / 高台 1.0) | 分段常量 + 直线边界;区域间硬切换或 0.3s 切线过渡,**禁径向渐变** |
| **章节光色** | CanvasModulate 全局微调 | 序章中性 / 第一幕暖(红移 ≤3%)/ 第二幕冷(蓝移 ≤3%)——不破调色板 |

- 光源方向全案统一**左上**(实体高光条 40% 宽已确立,天光带投向下右;
  v0.19 起引擎光影 rig 同向实装:DirectionalLight2D rotation ≈ -40°,
  影投向右下——光与影讲同一个太阳,art-style §8)。

### 2.2 光影的玩法职责(不是装饰)

1. **视线引导**(levels.md §1.4 的光影版):天光带落在"该走的路"上——
   琴台出音口的光带照着穿洞落点,巨柱空腔的光带照着穿柱之路。
2. **可预读反馈**:LeverGate 开门 = 光带照入新路径(光即开关反馈);
   TimedBridge 实心窗口与光带脉冲同频(motion.md §3 可预读联动)。
3. **空间叙事**:深谷暗 / 高台亮 = 巨构的垂直叙事(爬得越高越接近天光,
   与"逆的门悬在天梁"的叙事互文)。

### 2.3 Godot 手段选型(零成本优先)

| 手段 | 用途 | 成本 / 约束 |
|---|---|---|
| **程序化多边形亮带**(首选) | 天光带 = Polygon2D 平行四边形,随关卡静态烘焙 | **零运行时成本**,LevelBuilder 画;首版全部用它 |
| CanvasModulate | 区域明度 / 章节光色 | 全局单节点,零成本;区域切换 = 分段 set |
| PointLight2D + 平色块纹理 | 动态亮区(开门照入的动态光带) | texture 用矩形/条形平色块(**禁默认径向衰减**);energy 阶梯化;**≤4 盏/屏** |
| LightOccluder2D | 硬边遮挡影 | **v0.19 已实装**:全局唯一 1 盏 DirectionalLight2D 开投影,`shadow_filter = NONE` 保直角;遮挡体随构件挂载(art-style §8) |
| Shader | —— | **默认不用**;分段色带类需求用多边形拼,禁渐变 shader |

**现状(v0.19)**:基础投影已由引擎光影 rig 承担(全局 1 盏平行光 +
构件遮挡体,art-style §8);天光带仍走静态多边形(零新增灯光),
章节光色沿用 CanvasModulate——氛围手段叠加在 rig 之上,不再新增光源。

### 2.4 与各系统配合

| 系统 | 配合点 |
|---|---|
| **图层系统**(levels.md §7) | 剪影带与 back lane 合并校准(背景结构压 8% 红线,剪影 ≤5%,两者不打架);天光带落在 front lane 上时跟随降透明度(motion.md §3 过渡 0.12–0.16s) |
| **动态构件** | §2.2 可预读反馈;光带边界 = 直角,与 M3 直线优先一致 |
| **钢琴砖**(audio.md §4) | 音符粒子颜色借用章节光色的暖/冷微差;琴关天光带 = 出音口的"声波带"变体(直角锯齿边) |
| **网格量尺**(levels.md §8) | 天光带内部网格线对比不降级(量尺职能优先);亮带透明度上限 10% 保证 |

## 3. 性能与移动端

- 首版方案(多边形 + CanvasModulate)零新增 draw call 压力;剪影层
  = 每关 ≤3 个多边形;方尘不增量。
- Light2D 已立项(v0.19,art-style §8):开阴影的光全局 1 盏
  (DirectionalLight2D);真机 profile 待测,吃紧先调 `max_distance` 剔远。
- 验收:`--tourshot` 巡航帧检查亮带落点 / 剪影对比 / 章节色相;
  art-style §5 审计清单追加本档 §4 项。

## 4. 氛围审计清单(追加进大改审计)

- [ ] 剪影层 ≤ PAPER·5%,边线不与网格主线同频
- [ ] 天光带直角平行四边形,无径向/线性渐变;透明度 ≤10%
- [ ] 光源方向全案左上(引擎 rig 影投向右下,art-style §8)
- [ ] 章节色相偏移 ≤3%,调色板未破坏
- [ ] 每条天光带落在至少一个可走面(玩法职责)
- [ ] Light2D(如有)≤4 盏/屏,阴影全局 ≤1 盏,texture 为平色块
