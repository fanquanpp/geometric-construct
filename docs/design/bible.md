## 卷〇 · 总纲:核心命题

**核心命题(全作唯一主问题):**

> **「如果世界告诉你,你是什么形状,你是否还能决定自己是谁?」**

- 主题词:**定义与自由**。
- 一句话故事(logline):几个被丢进"不存在的地方"的几何体,在一条量过
  很多次终点的红色刻度下,各自归位——然后开始怀疑:归位,是谁定的?
- 叙事公理(**任何新增剧情必须回答这三问**,答不出 = 不立项):
  1. 这段剧情**揭示或加深了哪一层真相**(卷二)?
  2. 它让哪个角色的**核心问题**(卷三)推进了几步?
  3. 它为什么**必须此刻**被玩家知道(卷九 信息控制)?
- 反面定义(本作**不做**的事):不做同人式拼贴(《作品A》性格+《作品B》
  世界观+《作品C》叙述方式);不直给真相;不破第四面墙;不让旁白俏皮。

## 卷一 · 方法论:六层文学来源体系

### 1.0 核心原则:拆机制,不搬作品

研究优秀作品,研究的不是"它讲了什么",而是**它为什么有效**——把
叙述视角 / 信息控制 / 角色塑造 / 人物关系 / 对话节奏 / 心理描写 /
伏笔设计 / 象征系统 / 世界观揭示 / 冲突设计 / 情绪曲线 / 章节结构 /
真相揭露方式 / 悲剧结构 / 喜剧缓冲 / 角色成长 / 多周目结构 /
**玩家与角色之间的信息差**这十八项机制逐一拆出,重新组合成
GEOMETRIC CONSTRUCT 自己的叙事语言。拆出来的永远是**方法**,不是台词、
不是桥段、不是设定。

### 1.1 六层来源体系

| 层 | 来源 | 主要拆取 | 对本作的落点 |
|---|---|---|---|
| 一 | **日本轻小说** | 人物关系的"第二层含义":同一句话,因关系史不同而意义不同 | 对白潜台词制度(卷四 §4.2);单章刻画→幕间正剧的铺垫链 |
| 二 | **视觉小说** | 信息差叙事:玩家不知道全部,角色也不知道全部,让信息慢慢碰撞 | 卷九 信息控制总表;真相分层揭示(卷二) |
| 三 | **ZATO 研究层(专层)** | 叙述语言与信息隐藏的时机——单独成层,见 §1.2 | 旁白文体、揭示节奏、空白的用法 |
| 四 | **平台跳跃游戏叙事**(Celeste / Thomas Was Alone / Inside) | 机制即叙事、环境叙事、宽容哲学 | 手感公约数即叙事(characters.md §2 已对标 Celeste);Thomas Was Alone 的形状拟人旁白是本作直系先祖(README 致敬);Inside 的"零台词世界揭示" |
| 五 | **戏剧与诗** | 悲剧结构、合唱(旁白=歌队)、留白与重复、格言体 | 旁白零度格言化的文体合法性;第四幕悲剧节拍;落幕的留白 |
| 六 | **哲学寓言**(存在主义 / 博尔赫斯式) | "被定义的存在"这一母题的提问方式 | 卷二第五层真相;卷七 重跑=命运机制 |

> 六层中一、二、三层为定稿;四~六层为【草案】,落地引用前逐项拍板。

### 1.2 ZATO 研究层(专层)

研究对象:《Z.A.T.O. // I Love the World and Everything In It》
(Nopanamaman,2025;线性无选项视觉小说,约 7–8 小时,第一人称,
闭合城市 Vorkuta-5 的失踪谜案;主题=视角、身份、存在——"学会爱世上
一切"的题眼与本作「定义与自由」同族)。研究与本作的关系:**它是线性
无选择叙事如何做到"信息掌控大师级"的活样本**——本作主线同样是
无分支叙事(分支不分裂主线,story.md §6),信息控制就是全部命门。

**研究什么:它怎么讲,不是它讲了什么。**

- 01 叙述语言八维:句子长度 / 停顿 / 空白 / 重复 / 断句 /
  **描述与对白的比例** / 信息密度 / 场景切换速度。
- 02 信息隐藏:**"作者什么时候告诉玩家一件事",而不是"告诉了什么"**——
  同一事实,早说一句是废话,晚说一句是反转;信息价值随揭示时机递增。
- 03 研究产出格式(矩阵,不写读后感):每次分析只填
  `场景 → 用了哪个机制 → 效果 → 本作可移植点 → 禁止照搬的边界`。

> 【草案·待拍板】ZATO 全文本细读拆解是否立项为独立文档
> (`docs/design/bible-zato.md`);本卷先立方法与占位。

### 1.3 参考作品矩阵(制度)

以后研究任何作品,一律填矩阵,禁止"感觉很好"式引用:

| 作品 | 拆出的机制 | 本作应用点 | 禁止照搬边界 |
|---|---|---|---|
| Thomas Was Alone | 旁白拟人:能力即性格,旁白比角色先爱上角色 | 旁白零度但温柔的总调;几何体以"形状"被介绍 | 不拟人成"萌系小人",不加表情贴图 |
| Celeste | 宽容手感=叙事关怀;挑战关=自我对话 | 手感公约数(characters.md §2);第四幕"不像自己的能力课" | 不做叙事高难自虐;死亡不留惩罚性文案 |
| Inside | 零台词世界观揭示:环境即旁白 | 测试关与巨构的"场景先说话" | 不引入惊悚压迫语汇 |
| 《Z.A.T.O.》 | 线性无选择的信控;叙述语言的空白与重复 | 卷九信息控制;旁白文体 | 不抄闭合城市/现实影射题材 |
| Sokoban / 愤怒的小鸟 | 机制原型(格逻辑推箱 / 抛物弹射) | v0.27 机制群(推箱 / 弹射板)——玩法机制,不携带叙事 | 不做图标化关卡皮肤 |

(矩阵为活表,新增研究追加行;旧例见 v0.27 机制群的调研记录。)

## 卷二 · 世界观:五层真相

世界真相分五层,**逐层揭示,顺序不可调换**。每层标注:玩家在此层
"以为世界是什么"、揭示载体、揭示时点。

### 第一层:这是一个奇怪的几何世界

- 玩家认知:被丢进来的四个形状,要各自归位。
- 载体:序幕七拍(空白→降临→相认→规则→缺口→约定→出发)。【正典】
- 关键正典句:"这里不存在天空,也不存在大地。""空白处甚至懒得给
  他们一个落点以外的解释。"

### 第二层:这个世界有固定规则

- 玩家认知:规则可依赖——**形状决定能力,门决定归位,死亡可以重拼,
  重拼消耗一段红色刻度**。
- 载体:序幕 §四(规则拍)+ 全部玩法实装。
- 关键正典句:"空白处会把碎掉的几何体,在起点重新拼好——像一句
  写错了就重写的话。""至于刻度用完了会怎样……这里没有留下答案。"

### 第三层:这些规则不是自然形成的——有人设计过它们

- 玩家认知升级:从"世界的物理"到"世界的作者"。
- 载体:第二幕「界与边」(第五刻度正式登场,磁力边界揭示"过往":
  空白处曾有第七形?)+ 第五幕收拢。
- 揭示纪律:**不出现"设计者"的形象与名字**。设计者只以痕迹存在
  (规则的整齐、巨构的"像是早就知道你们各不相同"——act1.ks 正典)。

### 第四层:红色刻度记录的不是距离——是这个世界上经历过多少次"终点"

- 玩家认知升级:度量衡即伤疤。正典锚点:序幕"它量过高,量过远,
  量过很多次——终点";重跑设定"死亡即结算""落幕";残段="走过的路
  化作的东西"。
- 载体:第五幕「刻度的真相」;"代价的真相"(重拼的代价)同幕收拢。
- 【草案】本层的完整表述:红色刻度不是尺,是**计数器**——每一次
  "终点被走到",刻度就续长一段;世界越老,刻度越长。几何体们的
  每一次重拼,都在替这个世界续写它"又熬过一次终点"的记录。

### 第五层:被定义的存在,能否自我定义

- 玩家认知升级:最终问题从"谁创造了这个世界"翻转为
  **"如果世界告诉你,你是什么形状,你是否还能决定自己是谁?"**
- 载体:落幕(开放式)+ 全收集追加"第五扇门"段 + 重跑模式的
  玩家-世界双重重演(卷七)。
- 揭示纪律:**这句话永远不出现在任何台词里**。它由玩家自己拼出;
  游戏只提供证据(卷七 三级暗示)。

## 卷三 · 角色圣经(八形)

> 模板:表面设定(正典)→ 形状即心理(倒推链)→ 核心问题 → 声线 →
> 弧光(跨七幕)→ 关键视觉事件 → 代表台词(【正典】/【草案】)。
> 原则:characters.md §0.3"性格=物理手感的叙事化,手感先于台词"——
> 心理层是这条公理的纵深化:**不是"他能做什么所以什么性格",
> 而是"他为什么必须这样做"。**

### 壹 · 疾(DASH)

- 表面【正典】:红色正方形;全读数 2.0 的新人锚点;冲刺+爬墙;
  "他相信只要跑得够快,孤独就追不上他。"
- 形状即心理(倒推链):他为什么必须一直跑?→ 因为停下来,就要面对
  "被落下"的可能 → 因为他曾经(或相信自己曾经)被落下过 → 于是把
  "速度=安全"写成了本能。
- **核心问题:「我为什么不能停下?」**
- 声线【正典】:急促、短句、破折号多;感叹与疑问;速度隐喻;禁忌
  长定语、书面语。
- 弧光:序幕"跑起来!"→ 单章"原来我一直跑,不是怕孤独追上我"
  (正典,认知松動)→ 第四幕**学会停**(把"停"从危险变成选择)→
  落幕:他能站在原地,看别人出发。
- 关键视觉事件:第四幕「疾的静止」——全游戏最快的几何体,整整
  一个场景不移动;镜头与红色刻度替他走。
- 【草案】新增示例台词(落地前拍板):"停下来的三秒里,世界没有塌。——原来塌掉的只是一直在我脑子里跑的那个东西。"

### 贰 · 跃(SPRING)

- 表面【正典】:黄色长方形;弹性 3.0、承载 2.5 的唯一全自动驮手;
  顶弹翻倍——"把坠落折叠成上升"的她,也把别人的起跳折叠一次。
- 形状即心理:她为什么永远愿意托住别人?→ 因为"被需要"是她确认
  自己位置的方式 → 因为她暗自相信:不托住别人的话,自己不知道
  为什么要在高处。
- **核心问题:「我为什么必须托住别人?」**
- 声线【正典】:沉稳、肯定句、高度与接住的意象、不示弱。
- 弧光:序幕"你可以踩上我的头顶——我托得住"→ 单章"以前我为别人
  折叠坠落,这一次,为自己折一次"(正典)→ 第四幕**为自己折一次**
  (把托举从义务变成本领的馈赠)→ 落幕:她第一次让别人托。
- 关键视觉事件:第四幕「跃的坠落」——她第一次不接住自己,被同伴接住。
- 【草案】示例台词:"接住你们的时候,我从来不看地面。今天我想看一眼——原来下面也有路。"

### 叁 · 逆(FALL)

- 表面【正典】:蓝色最小几何体;置换(重力翻转);全场最慢 1.5、
  门后 3.0 的弱者翻身曲线;**唯一能穿过磁力边界的几何体**——
  "对边界来说,他不算'另一侧'"。
- 形状即心理:他把"上下"说成"两个面"——不是修辞,是他真实的
  世界观:一切对立都是可选视角。他为何超然?因为他真的可以不选。
- **核心问题:「谁规定什么是上?」**
- 声线【正典】:冷淡、超然;禁忌情绪外露。
- 弧光:序幕"对我只是两个可以落脚的面"→ 单章"你们管这叫孤独,
  我管这叫安静"(正典)→ 他一直认为自己不受规则影响 → 第四幕
  **逆落地**:他发现"认为自己超脱规则"本身也是一种规则——落地,
  不是屈服,是他第一次**选择**一个面站定。
- 关键视觉事件:第四幕「逆落地」——置换键整幕禁用,他用自己的脚
  站在"正确方向"上。
- 【草案】示例台词:"我以为我不选,就不在规则里。原来'不选'也是他们写好的一行。"

### 肆 · 圆(ROLL)

- 表面【正典】:橙色圆球;四无(冲/跳/翻/爬)+ 双超标尺;固定极速、
  坡面切线飞跃、可被推动——"不会跳的他是大家的车";沉默、肯定句、
  禁疑问句与回头语;"他不会跳,所以他从不回头。"
- 形状即心理:圆的滚动没有"退挡"——向前是他的物理,也是他的
  债务。他拒绝解释(只说结论),因为解释需要停下来回望来路。
- **核心问题:「如果过去真的很重要,我是否有资格永远不回头?」**
- 声线【正典】:只说结论,不解释;禁忌疑问句。
- 弧光:序幕"少说话。多滚。"→ 单章"一个人滚,更快"(正典)→
  玩家逐渐发现他不是不想解释,是**害怕解释**(解释=回头)→
  第四幕**圆回头一次**:全游戏最重要的视觉事件之一——圆停止滚动,
  转过身,看一眼来路。只此一次,之后永不复用。
- 关键视觉事件:第四幕「回头」——镜头第一次转到圆的"背面"。
- 【草案】示例台词:"我看过来了。……就一次。现在,继续。"

### 伍 · 界 / 边(TWIN · 第五形)

- 表面【正典】:紫色双三角,必定同时存在,各自独立操控;磁力边界
  (动词「隔」)随两半伸缩;逆是唯一穿透者;音乐=sol/la 五度和声;
  "界。我在上,量天的高度。"/"边。我在下,量地的厚度。"
- 形状即心理:他们不是"第五个可操作角色",而是**世界边界的拟人化**——
  他们的动词就是世界运行的方式(隔开、度量)。最初他们相信:边界
  保护世界 → 逐渐发现:边界也**限制**世界 → 最终问题:
  "如果没有边界,世界还是世界吗?"
- 核心问题:界——**「什么是边界?」**;边——**「边界保护了谁?」**
- 声线【正典】:对称、克制、互为答句;禁忌单独出现、抢话。
- 弧光:第二幕登场(第五刻度伏笔收)→ 第三/四幕:对称的裂缝
  (【草案】第一次出现"界与边意见不合"的一对非对称台词——此前
  全部成对)→ 第四幕:边界从"职责"变"选择"→ 落幕:他们的磁界
  第一次为一个**非任务理由**张开。
- 关键视觉事件:第四幕「非对称台词」与落幕「自愿张开的界」。
- 【草案】示例台词(裂缝拍):界:"我们要隔住谁?" 边:"……你以前从不问这个。"

### 陆 / 柒 · 第七形(占位 · **不解释纪律**)

- 正典边界:名册预留两位(陆=si,柒=高音 do);候选:梯形(分身)/
  菱形(斜向冲刺);落幕只给"空白深处一闪"。
- **不解释纪律**:前期(第一至四幕)绝不让任何角色"解释"陆柒;
  玩家长期无法确定三者哪个为真——
  1. 他们是**尚未降临**的两个新同伴;
  2. 他们是**这个世界缺失的两块**(设计者没写完的部分);
  3. 【推荐】**"陆"与"柒"不是两个角色,而是某个曾经存在过的东西的
    两个版本**——与「重跑」互文:被重跑的不止路,还有"形"。
- 三种解读允许并存到落幕;真相只挂在第五层(卷二),且不给出唯一答案。
- 【草案】台词纪律:任何角色提及时只用疑问句或沉默——除圆外
  (圆用肯定句:"他们走过了。"——不解释,不展开)。

## 卷四 · 人物关系网

### 4.1 关系对表(核心八对)

| 对 | 关系机制 | 第二层含义的种子 |
|---|---|---|
| 疾 × 跃 | 跑与停 / 弹与落 | "你先走"——疾说这话时,跃知道他有多怕停 |
| 疾 × 圆 | 最快与不回头的两种"向前" | 互相视为同类,互不劝慰 |
| 逆 × 圆 | 两个面 / 不回头 | 全场最安静的两个,对话最少、信息最大 |
| 逆 × 伍 | 唯一穿越者 × 边界本身 | "对他不算另一侧"= 逆是世界规则的例外条款 |
| 跃 × 全员 | 托举者与被托举者 | 每一次踩头都是一次信任授出 |
| 界 × 边 | 一体两制 | 成对台词的对称性=世界的秩序感;裂缝=秩序动摇 |
| 圆 × 过去 | 拒绝回望 | 他的速度是回避的形状 |
| 全员 × 空白 | 被丢入者与场所 | "它像是早就知道,你们各不相同"(act1 正典) |

### 4.2 第二层含义的产生制度(轻小说层落地)

一句普通台词要长出第二层含义,按四步铺垫(以"你先走吧"为例):

1. 建立行为习惯(他总是主动离开);
2. 埋一次失去(他曾被留下 / 看着别人被留下);
3. 让**另一个角色**知道(1)与(2);
4. 重放台词——同句,新义:"我不想再一次被你留下。"

制度:**任何"潜台词台词"必须能在前文找到(1)(2)(3)的实锚**,
否则不写。对账工具=卷九信息控制总表。

## 卷七 · 重跑叙事结构:玩家是隐藏变量

- 正典地基:重跑="一个人,把一条路再走一遍"(rogue_intro);残段=
  "走过的路化作的东西";死亡即结算;第五刻度闪现。
- 升华一层:玩家以为自己在重玩游戏——**实际上世界也在重演**。
  肉鸽不是玩法包装,它是"关于重复、记忆、命运和选择"的叙事机制:
  路会记得(残段),刻度会累计(计数),而"重来一次"这件事本身,
  就是这个世界诞生以来一直在发生的事(L4:量过很多次终点)。
- **玩家=隐藏变量**(高级方向,后期启用):不破第四面墙,不出现
  "你好玩家"。三级暗示,逐级加压,全部只给证据不给结论:
  1. **一级(措辞)**:个别旁白的主语偶尔省略——"又重来了一次。
    ……'重来'的,是谁?"(不回答);
  2. **二级(机制对镜)**:重跑结算页的措辞从"她带着什么走到了这里"
    渐变为"你替她记着什么走到了这里"(一词之差,前后版本同屏可对比);
  3. **三级(静默事实)**:落幕之后,若玩家再次进入重跑,序幕旁白
    第一句变成一句新的话——世界知道有人回来了。仅此一处,永不复用。
- 纪律:三级暗示互相独立,错过任何一级不影响理解主线;真相
  "真正不断按下'再来一次'的,是玩家"**永不写成台词**。

## 卷八 · 台词圣经

### 8.1 声线规范(正典全表,story.md §2)

| 角色 | 声线 | 句式习惯 | 禁忌 |
|---|---|---|---|
| 疾 | 急促、短句、破折号多 | 感叹与疑问,速度隐喻 | 长定语、书面语 |
| 跃 | 沉稳、托举感 | 肯定句,高度与接住的意象 | 抱怨、示弱 |
| 逆 | 冷淡、超然 | 把"上下"说成"两个面" | 情绪外露 |
| 圆 | 沉默、肯定句 | 只说结论,不解释 | 疑问句、回头语 |
| 界 / 边 | 对称、克制 | 成对出现:界量天 / 边量地,互为答句 | 单独出现、抢话 |
| 旁白 | 零度、格言化 | 短句陈述世界的规则 | 俏皮话、打破第四面墙 |

### 8.2 写作流程(纪律)

1. 先定位**手感状态**(characters.md §0.3),台词是手感的翻译;
2. 情绪写状态不写情绪词——"写急躁不写'急',写'等等我'说不出口";
3. 每句 ≤2 行(对话框 1/4 屏约束);
4. 写完对照卷九:这句话此刻对玩家是新信息、旧信息还是情感回声?
   只允许后两者占 70%,新信息 30%;
5. 圆的台词写完删一半,直到只剩结论。

### 8.3 正典句库(节选 · 新台词的调音基准)

- 旁白:"它量过高,量过远,量过很多次——终点。"/"像一句写错了就
  重写的话。"/"红色刻度安静地亮着,像一个耐心的观众。"
- 疾:"……这是哪里?我停下来的时候,连风都没有。"
- 跃:"只要落点够高,恐惧就够不着。"/"看好了。这一次,我托住我自己。"
- 逆:"我不是小不点,我是你们没见过的方向。"
- 圆:"别问了。我不会跳,所以我从不回头。"/"少说话。多滚。"
- 伍(草案):"界。我在上,量天的高度。"/"边。我在下,量地的厚度。"
- 尾声:"原来终点不是一个地方——是四个人都到齐的那一刻。"(疾)

## 卷九 · 信息控制总表

> 三栏信息差:【世】世界/设计者知道的 · 【角】各角色知道的 ·
> 【玩】玩家知道的。揭示=把一格信息从右往左移动。
> 原则(ZATO 层):安排**揭示时机**优先于安排揭示内容;
> 信息价值随时机递增;让玩家先于角色知道=悬念,后于角色知道=反转,
> 与角色同时知道=共感——三种工具轮换,不连用同一种两次。

| 信息 | 世 | 角 | 玩 | 揭示时点(卷二) |
|---|---|---|---|---|
| 规则可依赖(形状/门/重拼) | ✓ | 部分 | ✓ L2 | 序幕起 |
| 规则有作者 | ✓ | ✗ | ✗→✓ L3 | 第二幕起萌芽,第五幕收 |
| 刻度=终点计数 | ✓ | ✗ | ✗→✓ L4 | 第五幕 |
| 陆柒的存在/本性 | ✓ | ✗ | ✗ | 不设唯一时点(卷三) |
| 重跑=世界在重演 | ✓ | ✗ | ✗(三级暗示) | 卷七,永不直说 |
| 界/边的来历 | ✓ | 伍自知 | 第二幕起 | 第二幕 |

## 卷十 · 创作守则(十戒)与文档体系

**十戒:**

1. 不拼贴——只拆机制,不搬台词桥段(卷一)。
2. 不直给——真相只揭示时机,不揭示结论(卷二/卷九)。
3. 不破声线——写前读 §8.1,写后对照正典句库。
4. 不解释陆柒——疑问句或沉默(卷三)。
5. 不破第四面墙——玩家=隐藏变量只给证据(卷七)。
6. 情绪=状态——演出与台词同向,不写不存在的状态(characters.md §0.5)。
7. 新剧情必答三问(卷〇 叙事公理),答不出不立项。
8. 动笔先对账伏笔账本(卷六);收割点冲突 = 改案不改账。
9. 分支不分裂主线——分支只改措辞与题词(story.md §6 正典)。
10. **机制优先**:实装文案(.ks/关卡剧本)在机制解锁前不动笔;
    本文一切【草案】落地须逐项拍板。

**剧情文档体系规划**(按需生长,不预建空文件):

```
docs/design/bible.md          # 本文:剧情圣经(总纲)
docs/design/story.md          # 七幕主纲与实装剧本档案(正典)
docs/design/characters.md     # 角色数值与手感权威(正典)
docs/design/bible-zato.md     # (草案)ZATO 文本细读拆解
docs/design/bible-matrix.md   # (草案)参考作品矩阵活表
story/*.ks                    # 实装剧本(正典台词)
```
