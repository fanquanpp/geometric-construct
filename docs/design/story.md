## 1. 世界观(定稿)

- **场所**:一个"不存在的地方" —— 没有天空与大地的墨色空白,只有平面、细线,
  和一条永不熄灭的**红色刻度**。红色刻度是这个世界唯一的度量衡:
  它标记高度、标记进度、标记命运(1 格 = 100 px 的世界观包装)。
- **居民**:四个几何体(疾 / 跃 / 逆 / 圆),某天被"丢"进此地,来处不明。
- **规则**:每扇终点门只接受专属形状;四门归位,空白处才会亮起下一章。
  死亡不是终结 —— 空白处会把摔碎的几何体在出生点重新"拼"出来(重生机制的叙事)。
- **主题**:形状即性格,属性即命运;唯有互相依靠,才能各自归位。

## 2. 角色声线(写作规范)

| 角色 | 声线 | 句式习惯 | 禁忌 |
|---|---|---|---|
| 疾 | 急促、短句、破折号多 | 感叹与疑问,速度隐喻 | 长定语、书面语 |
| 跃 | 沉稳、托举感 | 肯定句,高度与接住的意象 | 抱怨、示弱 |
| 逆 | 冷淡、超然 | 把"上下"说成"两个面" | 情绪外露 |
| 圆 | 沉默、肯定句 | 只说结论,不解释 | 疑问句、回头语 |
| 旁白 | 零度、格言化 | 短句陈述世界的规则 | 俏皮话、打破第四面墙 |

写新台词前先读现有关卡卡台词;每个角色每句不超过 2 行(对话框 1/4 屏约束)。

## 3. 序幕 PROLOGUE(v0.8 扩展版文本档案)

结构:七拍 —— **空白 → 降临 → 相认 → 规则 → 缺口 → 约定 → 出发**(剧本内以
注释分拍)。扩展要点:红色刻度的来历暗示("它量过很多次终点")、死亡与重生的
规则预告("重拼消耗一段红色刻度",为肉鸽"死亡即结算"铺垫)、四几何体相认
一场各自亮一遍声线、尾声钩子在 epilogue("第五个形状的刻度")。
当前定稿文本见 `story/prologue.ks`(改动剧本 = 改动此处描述,二者必须同步)。

## 4a. 第一幕开演剧 ACT1(v0.12 新增,`story/act1.ks`)

三拍——**巨构降临 → 分位规则 → 各自出发**:空白处第一次主动亮起,
立起门厅 / 桥 / 柱 / 梁的巨大影子("没有观众的剧场,布景已搭好");
巨构不给同一起点与同一扇门("它像是早就知道,你们各不相同")——
**分位出生 / 分位归门**的叙事化;四声线各亮一遍,以"第一幕开演"收束。
首次进入第一幕(巨构门厅)自动播放一次(存档旗标 `rogue/seen_act1`)。

## 4b. 重跑序说 ROGUE INTRO(v0.12 新增,`story/rogue_intro.ks`)

肉鸽模式的叙事包装(story.md §6 钩子落地):四拍——**另一种演法(重跑)→
刻度残留(词条)→ 红色刻度与落幕(死亡结算 / 残段)→ 第五刻度闪现**。
关键口径:**重跑是单人独演**——"一个人,把一条路再走一遍","选中谁,
这一局就是谁的重跑";残段 = "走过的路化作的东西";"落幕的时候,考的
可是你一个人带着什么走过来的"(精英考的预告)。
首次进入重跑模式自动播放一次(存档旗标 `rogue/seen_rogue`)。

## 4c. 重跑 · 个人单章刻画(v0.12 新增,`story/rogue_<slug>.ks`)

重跑的剧情定位是**个人几何体的单章刻画**:每位主角一段独白剧,
在他首次被选定重跑时播放(存档旗标 `rogue/seen_rogue_<slug>`)。
每段三拍——**无同伴的处境 → 与自身特性的独处 → 一句收束的宣告**:

| 剧本 | 主角 | 单章题眼 |
|---|---|---|
| `story/rogue_dash.ks` | 疾 | "原来我一直跑,不是怕孤独追上我" |
| `story/rogue_spring.ks` | 跃 | "以前我为别人折叠坠落,这一次,为自己折一次" |
| `story/rogue_fall.ks` | 逆 | "你们管这叫孤独,我管这叫安静" |
| `story/rogue_roll.ks` | 圆 | "一个人滚,更快" |

声线规范照 §2 执行(圆禁疑问句、逆说"两个面"、跃不示弱、疾破折号)。

## 5. 剧情演出规范(阅读体验)

- 对话框:可见区高度 1/4,墨色实心底 + 顶缘细线;名字 = 构成红;
  右上角"跳过 »"常驻。
- **过渡(v0.8)**:入场 = 压暗层先淡入(0.25s)→ 对话盒自底升入(0.3s CUBIC_OUT);
  退场反向;每句台词推进时盒体不做位移(阅读稳定),仅打字音打点。
- **打字机文本**:逐字显现,标点处停顿(TWA 式节奏);点击一次 = 立即补完整句,
  再点 = 下一句(标准视觉小说操作,绝不跳句)。
- 推进键:空格 / 回车 / 点击对话框;Esc 任何时候可整段跳过(StoryLayer 兜底)。
- 剧情期间世界暂停,但背景层保持呼吸动画(世界没有死,只是让位)。
