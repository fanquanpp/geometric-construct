## 1. 世界观(定稿)

- **场所**:一个"不存在的地方" —— 没有天空与大地的墨色空白,只有平面、细线,
  和一条永不熄灭的**红色刻度**。红色刻度是这个世界唯一的度量衡:
  它标记高度、标记进度、标记命运(1 格 = 100 px 的世界观包装)。
- **居民**:几何体,共七形。疾 / 跃 / 逆 / 圆最先"被丢"进此地,来处不明;
  **界 / 边**(第五形,双子)的存在被"第五个形状的刻度"伏笔暗示
  (v0.8 尾声起),正式登场在第二幕(§1.5);陆 / 柒两形留白(续章余地)。
- **规则**:每扇终点门只接受专属形状;几何体归位,空白处才会亮起下一章。
  死亡不是终结 —— 空白处会把摔碎的几何体在出生点重新"拼"出来(重生机制的叙事)。
- **主题**:形状即性格,属性即命运;唯有互相依靠,才能各自归位。

## 1.5 七幕总结构(v0.16 定稿 · 叙事主纲)

> 主线骨架:序幕 → 第一幕 → 第二幕 → 第三幕 → 第四幕 → 第五幕 → 落幕。
> 每幕绑定一组玩法课题与一个美术主题(art-style.md §8);肉鸽模式(重跑)
> 是**独立模式**,不与主线强绑定,只在第三幕被剧情轻度引入。
> 状态标记:✅ 已实装 / 🔨 部分实装 / 📋 规划(关卡与剧本未建)。

| 幕 | 叙事课题 | 玩法课题 | 美术主题 | 状态 |
|---|---|---|---|---|

## 2. 角色声线(写作规范)

| 角色 | 声线 | 句式习惯 | 禁忌 |
|---|---|---|---|
| 疾 | 急促、短句、破折号多 | 感叹与疑问,速度隐喻 | 长定语、书面语 |
| 跃 | 沉稳、托举感 | 肯定句,高度与接住的意象 | 抱怨、示弱 |
| 逆 | 冷淡、超然 | 把"上下"说成"两个面" | 情绪外露 |
| 圆 | 沉默、肯定句 | 只说结论,不解释 | 疑问句、回头语 |
| 界 / 边 | 对称、克制(草案) | 成对出现:界量天 / 边量地,互为答句 | 单独出现、抢话 |
| 旁白 | 零度、格言化 | 短句陈述世界的规则 | 俏皮话、打破第四面墙 |

写新台词前先读现有关卡台词;每个几何体每句不超过 2 行(对话框 1/4 屏约束)。
**情绪元素写作规范(v0.16 新增)**:台词说状态不说情绪词——"写急躁不写
'急',写'等等我'说不出口";演出层情绪(前倾 / 压扁 / 颤动)见
characters.md §0 原则 5,台词与演出必须同向。

## 4b. 重跑序说 ROGUE INTRO(v0.12 新增,`story/rogue_intro.ks`)

## 4c. 重跑 · 个人单章刻画(v0.12 新增,`story/rogue_<slug>.ks`)

重跑的剧情定位是**个人几何体的单章刻画**:每位主角一段独白剧,
在他首次被选定重跑时播放(存档旗标 `rogue/seen_rogue_<slug>`)。
每段三拍——**无同伴的处境 → 与自身特性的独处 → 一句收束的宣告**:

| `story/rogue_fall.ks` | 逆 | "你们管这叫孤独,我管这叫安静" |
| `story/rogue_roll.ks` | 圆 | "一个人滚,更快" |

## 5. 剧情演出规范(阅读体验)

- 对话框:可见区高度 1/4,墨色实心底 + 顶缘细线;名字 = 构成红;
  右上角"跳过 »"常驻。
- **过渡(v0.8)**:入场 = 压暗层先淡入(0.25s)→ 对话盒自底升入(0.3s CUBIC_OUT);
  退场反向;每句台词推进时盒体不做位移(阅读稳定),仅打字音打点。
- **打字机文本**:逐字显现,标点处停顿(TWA 式节奏);点击一次 = 立即补完整句,
  再点 = 下一句(标准视觉小说操作,绝不跳句)。
- 推进键:空格 / 回车 / 点击对话框;Esc 任何时候可整段跳过(StoryLayer 兜底)。
- 剧情期间世界暂停,但背景层保持呼吸动画(世界没有死,只是让位)。
