> 状态:**v1.0(2026-09-12 定稿)** · 本文是视觉与听觉的**融合总纲与生产
> 系统规划**;现行规范的正典出处不变——视觉规则 `art-style.md`、听觉规则
> `audio.md`、动效 `motion.md`、氛围 `atmosphere.md`,冲突时以它们为准。

## 卷〇 · 总原则

1. **L0 视觉母体永不推翻**:构成主义 + 极简主义是视觉 DNA,一切新语言
   **叠加在它之上**,不是替换。
2. **融合需答存在理由**:新风格加入必须回答"它承载哪层世界观/玩法
   语义"——"好看"不是理由。
3. **音乐一个调,丰富靠分层与动机**:C 大调统一 + 程序化合成 +
   音符零 jitter 的正典基础不变;丰富度来自**分层 BGM、角色动机、
   音色画像**,不来自转调。
4. **像素纪律(2026-09-15 用户拍板改向)**:~~正式关卡程序化绘制不变~~——
   作关改向**原生编辑器 + aseprite 素材摆放**(提案 `native-levels.md`,
   JSON 管线为迁移期现状);aseprite 升格为图块/素材正源,
   档案插图(art-style §6.1 孤本)与记录媒介用途不变。

## 卷二 · 八套艺术语言与融合矩阵

| 语言 | 强度 | 主用途 | 语义承载 | 禁止边界 |
|---|---|---|---|---|
| L0 构成主义 | 100% | 全游戏 | 世界骨架 | 永不推翻 |
| L0 极简主义 | 100% | 全游戏 | 留白即道路 | 不做装饰堆砌 |
| L0 几何抽象 | 100% | 全游戏 | 一切皆形状 | 不引入有机曲线 |
| 工业制图 | 70% | 机关 / 档案 / 标注 | 世界结构(编号/公差/图例) | 不变成蓝图滤镜 |
| 现代平面设计 | 70% | UI / 标题 / 剧目 | 秩序与版式 | 不破坏几何母体 |
| 舞台剧场 | 60% | 剧情 / 章节演出 | "演出"世界观 | 不做真实剧院具象 |
| 建筑主义 | 60% | 大型关卡(巨构) | 尺度与秩序 | 不做现实建筑仿型 |
| 纸张 / 印刷 | 40% | 档案 / 回忆 / 重跑记录 | 记忆的媒介 | 不做纸片人 |
| 像素艺术 | 20% | 档案插图 / 记录媒介 | 被记录的世界 | 不回退地图像素化 |
| 抽象表现主义 | 10% | 高潮 / 异常 | 秩序崩坏 | 不常驻、不进 UI |

- **融合核心规则**:新语言准入必须回答"它承载哪层语义";每种语言
  有明确**强度上限**与**领地**,越界即收回。
- **建筑构成库(Kit 制,Phase 落地)**:正式关卡不再零散做美术——
  建立 `门厅 / 桥 / 柱 / 梁 / 甲板 / 塔基` 等构成件库(act1 正典意象),
  正式关卡由 Kit 组合;试炼道测试件不入 Kit。
- **异常美术纪律**:世界出问题**不做故障风 glitch**——用**语义异常**:
  同一堵墙出现两套不同刻度 / 滑雪带的红刻度反向 / 限时桥相位漂移
  半拍。玩家"看见规则被违反"远胜"看见滤镜被打破"。

## 卷三 · 角色视觉母题(Shape → Personality → Motion → Motif)

| 形 | 关键词 | 视觉动作 | 母条目(正典 §7 基础上定型) |
|---|---|---|---|
| 疾 | 速度=安全 / 怕停 | 前倾·拖尾·骤停前倾加深 | 左上硬高光条 + 白取景框;停顿时高光条呼吸,拖尾反向收束 |
| 跃 | 托举 / 折叠坠落 | 压缩蓄力→释放拉长 | 1:2 竖长方;顶弹瞬间纵向双倍拉伸+纸白上行刻度 |
| 逆 | 两个面 / 超然 | 置换瞬间的镜像顿挫 | 双向箭头刻度;置换时上下刻度互换色序 |
| 圆 | 循环 / 不回头 | 纯滚动·轮辐频闪 | 双色半球+4 轮辐+指针;回头事件=指针第一次逆转(第四幕视觉锚) |
| 伍 | 一体两制 | 对称·镜像·伸缩 | 界量天/边量地;磁界线=关系的可见形态——**一个关系被拆成两个形状** |

- 陆 / 柒:**无母条目**(不解释纪律);视觉只在"空白深处一闪"级别。
- 判定:母条目表为动画与美术的对照基准,新增表现不得与母条目冲突。

## 卷四 · 动态艺术系统(动画语言)

motion.md 的档位 / 缓动白名单 / 直线优先正式收敛为**六种基础动作**:
`平移 · 缩放 · 旋转 · 透明度 · 位移截断 · 抖动(冲击)`。
一切高级演出 = 六者的**组合与编排**,不新增原语。

- 例:角色死亡 = 抖动(冲击)→ 碎块平移 + 透明度散场 → 空白处缩放重拼。
- 粒子白名单制:纸白碎屑 / 音符方块 / 归门吸入——白名单外不立项;
  禁:火焰 / 烟雾 / 光斑等自然系粒子。
- 光照:硬边投影正典继续;**光=空间语义**(天光带指示章节,区域明度
  指示 layer 层带)——不做装饰性光效。

## 卷五 · 音乐系统(一个调的丰富度方案)

C 大调统一 + 程序化合成正典保留。丰富度来自五件事:

### 5.1 BGM 五层分层(程序化动态音乐)

| 层 | 内容 | 场景 |
|---|---|---|
| L1 空拍层 | 极简脉冲(刻度呼吸同律) | 探索 / 留白 |
| L2 基础层 | 五音主题(五形音位循环) | 普通关卡 |
| L3 织体层 | 和声垫 + 对位 | 重要关卡 |
| L4 打击层 | 节拍驱动(限时桥对齐) | 高潮 / 考试 |
| L5 异常层 | 半音化偏移(si/C5 侵入) | 异常 / 剧情节点 |

分层开关由关卡与剧情状态驱动,不需要大量 BGM 文件——序列器编排。
> **现状(v0.37)**:深空圣咏序列器实装 ≈ L2(五音 motif)+ drone 铺底
> + 循环边界风涌(L1 的"呼吸"形态);L4 打击层、L3 织体、L5 异常层
> (si/C5 侵入,冻结至 P3)仍为规划,扩层即扩 `MOTIFS` 数据形态。

### 5.2 角色音乐画像(音色 × 节奏 × 音程 × 行为)

| 角色 | 音位(正典) | 音色 | 节奏 | 音程 | 行为 |
|---|---|---|---|---|---|
| 疾 | do(C) | Square(柔化后) | 快 | 跳进 | 追赶 |
| 跃 | re(D) | Triangle | 慢 | 上行 | 托举 |
| 逆 | mi(E) | Sine | 对答 | 八度(高低两面互为镜像) | 镜像 |
| 圆 | fa(F) | Tri+Sine | 连续 | 五度循环 | 循环 |
| 伍 | sol+la | 双音 | 交错 | 五度和声(正典;草案曾提三度,待拍板) | 关系 |

### 5.3 伍双声部(玩法×音乐统一)

磁界两端的 sol 与 la:**两半越近,双音越靠拢成纯和声;越远,拍频越明
显;归门瞬间,双音合为一声**。实现走既有节拍时钟 + 双 AudioStreamPlayer
音高微调——玩法距离直接可听。

### 5.4 钢琴砖 = 地图即乐谱

正典深化:音级=格 y 反向映射已是"地图即乐谱";下一步**关卡排布即
作曲**——琴键行的间距=节奏,高差=音程,五形演奏手法=音色。正式关
卡的琴键段按"乐句"设计(动机库取材),不再随机放砖。

### 5.5 机关音乐化(可听预读)

动态构件订阅节拍时钟(正典规划)扩展为全族:限时桥"听得见什么时候
实心"、开关门"听得见还有几拍"、摆渡"听得见到岸"。**可预读纪律的
听觉形态**。

### 5.6 音效四分类(现有音效库重新归档)

| 类 | 回答 | 例 |
|---|---|---|
| 玩法反馈音 | 玩家刚才做了什么? | 跳跃 / 冲刺 / 置换 / 归门 |
| 机制音 | 世界刚刚发生了什么? | 门板开合 / 桥实虚 / 推箱滑动 / 传送脉冲 |
| 角色音 | 谁做了这个动作? | 五形各异音色(motif 绑定) |
| 环境音 | 这里是什么地方? | 程序化 ambience(无真实录音) |

### 5.7 音乐动机库(Motif Library)

每个动机登记:`音列 / 音色 / 节奏型 / 承载语义 / 首次出现 / 变体规则`。
初始五条 = 五形音位动机;世界动机 = 红色刻度的"量"节奏型。

### 5.8 第七形的音乐(叙事音乐 · 冻结占位)

正典:陆=si(B)、柒=高音 do(C5)——**七音符体系里唯一从未被任何
角色/机关使用的两个音位**。设计:前期世界音乐严格只用 do–la 六音;
偶尔,环境层短暂飘过一句**落在 si 上不解决的半句**(si 是天然待解决
的主导音——"不完整的句子"有乐理实义);随剧情推进,半句越来越完整,
直到柒的高音 do 出现,句子第一次被解决。玩家最后意识到:**这个世界
一直有第七形的音乐,只是没人能听懂**。纪律:全程无台词点破,与
bible 陆柒不解释纪律绑定。

## 卷六 · 四套语言融合模型(验收样例)

**逆·置换重力**,一次按键,五联同步:

| 语言 | 表现 |
|---|---|
| 视觉 | 世界翻转,天花变地板(红色刻度恒在——世界的锚不动) |
| 玩法 | faces 过滤改变,可站立面集合互换 |
| 音乐 | 主题在其八度镜像重现(高面=低八度) |
| 音效 | 角色音=逆的 sine 对答句(上下句互换) |
| 叙事 | "对你们是天与地,对我只是两个可以落脚的面"(正典) |

**制度**:新玩法/新机关立项时,按此表填五联(允许某联为空但需说明)
——四套语言的融合度是玩法质量的度量衡之一。

## 卷八 · 禁止清单(硬约束复核确认)

美术:圆角 / 渐变 / 模糊阴影 / 非程序化地图 / 自然系粒子 / 有机曲线
造型;音频:转调 / 采样实录 BGM / 音符 jitter / 角色音位混用。
两份清单与 art-style.md、audio.md 正典完全一致,本文复核**继续有效**。

## 卷九 · 从"规范文档"到"艺术生产系统"

art-style.md 与 audio.md 已是高完成度规范;本计划的真正交付是把它们
升级为四个**生产系统**:

1. **Kit 系统**(建筑构成库):正式关卡美术 = Kit 组合,不再从零绘制;
2. **Motif 系统**(音乐动机库 + 角色母条目):新内容的声音/视觉自动
   继承语言体系;
3. **白名单系统**(粒子 / 动效 / 语义异常):表现层有准入制度;
4. **融合验收**(四套语言五联表):新玩法立项的最后一道关卡。

此后无论增加 10 个关卡、20 个机关、5 个角色还是新的重跑模式,
**都不再重新发明美术与声音**。
