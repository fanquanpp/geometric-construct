# 名词总表 · GLOSSARY

> 状态:现行(v0.16 规划定稿 · 2026-09-09)· 本文是**全项目信息名词的唯一权威**。
> 策划文档、代码注释、UI 文案、关卡教学牌一律使用本表的术语;新概念先入表再使用。
> 相关:几何体规格与属性 `characters.md`;机关物登记 `structures.md`;
> 关卡数据规范 `levels.md` §0;剧情名词 `story.md`。

## 0. 三大名词域

一切场景内对象归入三域,**域间不混用**:

| 名词域 | 定义 | 代码落点 |
|---|---|---|
| **几何体**(Geometry) | 自机可控角色。玩家直接操纵的、有性格与命运的形状 | `GeometryDef`(数据)/ `Player`(实体)/ `scripts/data/geometries.gd`(名册) |
| **建筑物**(Building) | 构成地图的静态结构:地面、墙壁、普通三角斜坡、梯形坡道、下凹坎等。不可交互、不可机关化,只提供地形 | `levels_native/*.tscn` 的 Solid/Decor TileMapLayer(引擎原生节点分层) |
| **机关物**(Mechanism) | 地图内嵌的机关或道具:移动平台、电梯平台、光电门、加速坡道、音符地板、跃迁门、压力感应器、反重力门等。改变规则或运动的构件 | `scenes/world/mechanisms/*.tscn` 场景实例(登记表见 structures.md) |

判定口诀:**能被操控的是几何体;踩上去只是站着的建筑物;改变规则或自己会动的机关物。**

编号用汉字数字(壹贰叁肆伍陆柒),单字代号用于排版;每个几何体绑定一种
音符(audio.md §1 七音符体系,几何体 ⇄ 音符一一对应)。

| 编号 | 代号 | 形态 | 大小(高×宽 px) | 音符(规划) | 状态 |

| 壹 | 疾 | 红色正方形 | 50 × 50 | do(C) | **实装**(v0.16 调整尺寸 56→50) |
| 贰 | 跃 | 黄色长方形(竖) | 80 × 40 | re(D) | **实装**(v0.16 调整尺寸 100×48→80×40) |
| 叁 | 逆 | 蓝色正方形 | 30 × 30 | mi(E) | **实装**(v0.16 调整尺寸 40×36→30×30) |
| 肆 | 圆 | 橙色圆球形 | 52 × 52 | fa(F) | **实装**(尺寸不变) |
| 伍 | 界 / 边 | 紫色倒三角(顶 · 挂 ceiling)/ 正三角(地)成对 | 30 × 30 | sol(G)·la(A) | **实装**(v0.16 试水关,磁力边界;见 characters.md §5) |
| 陆 | 待定 | 待定 | 待定 | si(B) | 待定(候选:梯形·分身 / 菱形·斜向冲刺) |
| 柒 | 待定 | 待定 | 待定 | 高音 do(C5) | 待定 |

- 伍是**双子**:「界」(上三角)与「边」(下三角)必定同时存在,**各自独立
  操控**(切换循环中各占一位),顶部由磁力线相连形成磁力边界——
  两个编号记一座几何体,占用 sol / la 两个音位。
- 尺寸一律 **高 × 宽** 记录;代码 `GeometryDef.size` 为 Vector2(宽, 高),换算勿反。

## 3. 坐标与单位约定

- **1 格 = 100 px**,一切数值(速度倍率、跳高、缺口、高差)以格为单位;
  代码里 `Geometries.UNIT_PX = 100`。
- **策划文档坐标以物体左下角为基准点**(读图基准);Godot 引擎内部以
  中心(实体)/ 左上(Rect2)为基准——落数据时换算:`左下 = 左上 + (0, 高)`。
- **坡度纪律(v0.16 新增)**:建筑物与机关物的**可行走/可滚行坡面**
  一律 ≤ 37°(≈3:4 坡;全员可爬,且距 Godot 默认 45° floor_max_angle 留 8° 余量)。
  曲面跳跃板的**发射段**是抛物轨道不是行走坡,不在此限(仍受
  "折角步进 ≤7°"与圆球 60° 贴角约束,structures.md §3)。
- **Dimensions 量尺表(v0.18 定稿,levels.md §8.1)**:行走净空 ≥1.0 格 /
  通行走道 ≥1.2 格 / 台阶 ≤0.9 格——全空间尺寸只准从量尺表推导;
  吸附 0.1 格、竖直件底缘嵌入承载面 ≥0.5 格,`--gridcheck` 将机器强制。
- 竖直向下为 +y(引擎约定);关卡相机四锁即世界(levels.md §0)。

## 4. 属性加成数值条(v3,v0.37.0 定稿;承标尺 v2)

- **基础值只属于几何体自己**(data/characters/*.tres 物理值 0.0–2.0,
  运行时禁改);局内修正统一走**加成数值条**(整数档位,默认 0):
  **0 = 无加成(任何几何体的条都从 0 起);+1..+4 = 基础 × (1 + 0.25×档)**
  (每档 +25%,满档 ×2);**−1 = 锁定**(能力被主动禁用);
  **状态−1 = 天生没有该能力**(基础 ≤ 0,不是锁定)。
- **锁定 与 状态−1 严格分立**:锁定 = 能力存在、被档位主动压制(条上
  锁定区红块);状态−1 = 数据上就没有此项能力(条区留白)。加成不能
  无中生有:`StatBonus.resolve` 对 base ≤ 0 恒返回 0。
- **解算序(v3 口径)**:有效物理值 = 基础经档位换算(`StatBonus.resolve`)
  → 微调层 add → mul → 加成键统一钳 [0, 4](读数 5.0 硬顶,承 v2
  "正常模式硬顶 5.0");非加成钩子(coyote / friction / swap_cooldown /
  air_jumps / gate_mult / gravity 双键)不钳,保持既有。物理公式
  (px/s、格、反弹率)一如既往不变——条是记法升级,不是数值重调。
- **基础读数记法(与 v2 存档/文档全兼容)**:读数 = 物理倍率 + 1.0
  (物理 0.0 → −1.0);**跳高例外**:读数 = 格数(标准跳 2.0 格 =
  基准 2.0)。展示规范:数值列 = 基础读数;条 = 加成档位
  (档案面板在肉鸽局内打开时实时叠加显示「基础 → 实际」)。
- **内容纪律**:禁止撰写"锁定重量"词条(重量 0 使加速度公式退化);
  攀墙(climb_units)暂无档位钩子(player 直读 MovementTuning),
  接钩子前不卖假档位(登记 REFACTOR §八 M-5)。
- **通用能力**(全几何体共享的能力维度):

| 能力 | 定义 | 公式/落点 |
|---|---|---|
| 跳跃 jump | 主动起跳能力(关 = -1:不可跳/置换型) | h = v₀²/2g;台阶可跳高 ≤ jump_units − 0.1 |
| 加速 sprint | 冲刺与门后速度上限 | v = 倍率 × 300 px/s |
| 重量 weight | 起步/滑行/承载判定的质量 | a = BASE_ACCEL × f(w) |
| 负载 carry | 头顶可承载的总重 | 超载跳高减半,不禁止 |
| 惯性 inertia | 动量保持程度(v0.16 显式化,先与重量同源耦合,解耦轴预留) | 空中阻力 ×0.28;滑行 a = μg |
| 摩擦系数 friction | 地面减速材质 | μ 标准 ≈ 1.27(读数 2.0);圆滚动 μ 0.43(读数 0.7) |

- 各几何体的逐项**基础读数**见 `characters.md` §1 属性总表(唯一数值权威);
  加成档位不改变基础表,局内实际读数 = 基础经加成条解算(glossary 本节)。

## 5. 命名纪律

- 玩家可见文案:**几何体 / 建筑物 / 机关物**三词统一;不用"角色""方块""道具""机关"混称
  (剧情与台词中允许角色拟人称谓,如"四位几何体")。
- 代码标识符维持英文(Geometry / Building 类语义留 platforms / Mechanism 落 entities);
  策划文档引用代码符号时用反引号。
- 新几何体、新机关物立项 = 本表 + characters.md / structures.md 对应章节同步登记。
