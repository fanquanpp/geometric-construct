# 关卡设计 · LEVELS

> 状态:现行(v0.12)· 数据源:`scripts/data/level_data.gd`(不一致时以代码为准)
> 方法论:Thomas Was Alone 关卡拆解(2026-09 调研)+ 构成主义排版语言
> v0.13 规划增补:§7 组件语义与图层系统 / §8 定位网格与量尺(2026-09-09 定稿);
> §9 官方关迭代实施方案(2026-09-09 定稿,M0 实装后的施工图)

## 0. 关卡数据规范

- **1 格 = 100 px**;一切坐标、尺寸、缺口、高差按格心算,再 ×100 落数据。
- 关卡边界由 CameraRig 四锁(`limit_left/top/right/bottom`)= `LevelDef.size` 推导,
  与 TWA 的"相机四锁即世界"一致;平台摆出界没有意义。
- `LevelDef` 字段:`name / focus / intro / size / roster / platforms / ramps / gates /
  exits / spawns / movers(v0.8)`。全部可 JSON 同构(编辑器分享码的前置条件)。
- 教学关铁律:**一关只教一个新概念**;能力组合放在该概念之后的第二关。

## 1. 关卡写作流程(从 TWA 学到的)

1. 先定教学段名(像 TWA 作者给段落命名 "Jump Up" / "Jump Gap with Rise"),
   写进 `intro` 字段:第一行教操作,第二行教原理。
2. 跳距公式化:满跳高度 h = v²/2g → 普通跳缺口 1.2–1.9 格,二段跳缺口 2.6 格,
   冲刺+二段跳 3.5+ 格;上升台阶 ≤1.9 格(2.0 格跳高 − 0.1 余量)。
3. **节奏三段式**:热身(安全,纯走)→ 教学点(安全网)→ 考验(失败惩罚轻,
   重生点近)→ 出口前缓冲(让玩家喘口气再看结算)。
4. 视线引导:用红色刻度块、门牌、曲面亮线把玩家视线"排"向前进方向;
   死路只用一次,且必须给视觉补偿(大号数字或装饰巨面)。

## 2. 现有关卡解析(v0.8 迭代后)

### 01 疾 · 跳跃(教学:跳跃 / 速度-跳远正比)
- 平面 + 三段渐宽断崖(1.2 / 1.9 / 2.6 格),末缺口必须二段跳(冲刺更稳)。
- 开局即 5.6 格长直道热身带,出口前有 2 格缓冲台;无运动构件(第一关保持静态)。

### 02 跃 · 攀高(教学:切换 / 踩头合作 / 二段跳)
- 台地 A(1.6 格)+ 高台 B(3.2 格);垫脚台 0.6 格供"跃上同伴头顶"教学。
- v0.8:高台 B 左缘新增**垂直移动平台**(振幅 2.4 格 / 周期 3.2s,可等待)——
  提供"不合作的慢路",踩头接力仍是快路(解法分层,难度可选)。

### 03 逆 · 突破(教学:置换 / 加速门)
- 上下双平台 + 0.6 格矮墙(不可跳,必须置换)+ 双侧断口;加速门后大弧线飞跃。
- v0.8:天花板断口内新增**水平接驳台**(行程 1.3 格 / 周期 2.8s)——
  置换失误不再直接坠亡,惩罚降级为"多等一个周期",教学关不劝退。

### 04 圆 · 过山车(教学:切线飞跃 / 极速)
- 两座曲面跳跃板 + 双断路(2.6 / 7.8 格);2.5× 飞跃 7.8 格。
- 本关刻意**不设运动构件**:速度考验路径里不放"可等待"要素,
  出手时机本身就是这关的时间维度(动态地图原则 §3.2 的反例保留)。

## 3. 动态地图原则(v0.8 起,"地图也可以是动态的")

1. **运动构件只做两件事**:连接(transport)与 变奏(variation)。
   连接 = 移动平台补断路;变奏 = 让静态谜题多一个时间维度。
2. **教学关的运动必须可等待**:移动平台慢速(≥3s/程)且不会把玩家推向死区。
3. **背景是活的,前景是稳的**:视差层缓慢漂移 / 呼吸(增量 ≤10%),
   平台本体保持预测性(踩上去之前就能算出落点)。
4. TWA 式动态平台参数:相对路径点 + 缓动 + `pause` 停顿 + 循环;
   本作简化为单轴往返(offset 向量 + period + phase),够用且可 JSON 化。

## 4. 配色与章节化(借鉴 TWA:平台色由背景推导)

- 平台基色 `#262B34` / 亮面 `#313845` 保持全局统一(可读性优先);
  章节感交给**背景巨面**与**门牌 / 刻度**的角色色密度表达:
  疾关红刻度密,跃关黄点缀多,逆关蓝,圆关橙。
- 背景亮度红线:任何背景元素 ≤ PAPER·8% 亮度(见 art-style.md §4)。

## 5. 正式关卡:第一幕「引力排练」(v0.11 起 · v0.12 六场全演)

序章四场各教一个几何体;第一幕起才是"真正的剧演"——四人合演,
每场都是**大型多几何体关卡(巨构主义)**:尺度 3 倍于序章(长 ≥90 格 /
高 ≥25 格),单一结构里并置多条能力路线。六场全部开演:

| 场次 | 剧名 | 组合题 | 核心句 |
|---|---|---|---|
| 01 | 巨构门厅(v0.11) | 天路 × 地路 × 分位归门 | "每个人走自己的路,在各自的门里归位" |
| 02 | 承接天桥(v0.12) | 承载接力:跃为梯 × 疾为腿 | "最快的腿,踩在最稳的肩上" |
| 03 | 双面回廊(v0.12) | 置换交叉:天路地路互换 | "一廊两面,梁上梁下都是路" |
| 04 | 速度圣殿(v0.12) | 加速门竞速:圆 × 长断路连飞 | "速度即跳跃" |
| 05 | 碎裂穹顶(v0.12) | 动能谜题:曲面板阵 × 移动接驳 | "出手时机即一切" |
| 06 | 幕间 · 大风琴(v0.12) | 幕终全组合 | "四能力齐奏,幕落" |

**分位出生 / 分位归门**(01 场确立的趣味原则):四个几何体不再共享出生点
与一排终点门,而是各自从巨构的不同角落出发、在属于自己的位置归位——
逆的门可以悬在天梁底面,圆的门立在飞跃的尽头。角色差异即路线差异,
路线差异即游玩差异。

### 05 · 巨构门厅(v0.11 实装解析)

- 尺度 96 × 32 格;地面 y28 全程贯通 = 安全网(坠落即回到中庭,
  `kill_y` 下移至 3300,大落差无惩罚)。
- **天路**(疾 / 跃):西翼五级浮田(步高 1.4 格,首级 2.6 格需二段跳)→
  空中踏石(缺口 1.8–2.6 格)→ 巨柱交替横杆(步高 2.6 格)→ 柱顶 → 高架连桥。
- **地路**(圆;逆亦可):浮田下方 1.4 格净空隧道 → 地面加速门 →
  **曲面冲柱**:3°→37° 渐陡曲面把圆送进柱心中空(离地 2 格、净高 2.4 格的
  穿柱之路),穿柱落地后直奔巨构电梯(行程 19.6 格 / 周期 20s)→ 连桥。
- **天堑**(连桥 7.5 格断路):圆走加速门 2.5× + 曲面 1.5× 全速飞跃(04 场
  证明射程);疾走浮石(双跳 2.2 / 1.6 / 1.7 格);逆置换上天梁从梁底越障。
- **天顶巨梁**(50 格整根,x44–94):逆的天路,两端挡缘防置换行走坠出;
  逆的门悬于梁底(y5.46 格),从梁顶置换翻到梁底走入。
- 四门分位:疾塔顶 / 跃柱巅 / 逆梁底 / 圆桥尾。

### 06 · 承接天桥(v0.12 实装解析)

- 尺度 92 × 30 格;地面 y26 全程贯通 = 安全网。
- **承载题**:断桥缺口 3.6 格——超出冲刺二段跳的稳射程;跃先登西引台
  (步高 1.6 格)站上断缘当"活台阶",疾踩跃头顶起跳,借 1 格头高
  + 高落点跃过天堑;踩头失误落地面 = 重爬(安全网轻惩罚)。
- **跃线**:三级塔肩(步高 2.8 格 ×3,二段跳逐级),门立塔肩之巅。
- **逆线**:桥下出生,一次置换翻上天桥底面(净空 0.8 格),沿梁底东行,
  门悬桥底(y25.66 格)。
- **圆线**:出生即过地面加速门(2.5×),冲 18° 出口曲面落桥东段,
  门在桥东尽头;桥下慢电梯(1.6 格 / 3.2s)供坠桥者恢复。

### 07 · 双面回廊(v0.12 实装解析)

- 尺度 96 × 28 格;完整天花板(y8)是逆的天路,地面缺口 3.0 格(x24–27)
  逼逆置换上行;两端挡缘防坠出。
- **夹层中板**(y16,x34–70):疾 / 跃的第二面天路——西端三级台阶
  (步高 ≤1.6 格)登廊,缺口 2.0 格二段跳,另配慢速水平接驳(2.8s/程)。
- **圆线**:地面加速门 + 起飞坡飞越 3 格缺口;门在廊中凸台(0.4 格)。
- 门位:疾东端高台 / 跃更高浮台 / 逆悬天花板底 / 圆廊中凸台——
  一廊四面,各归各位。

### 08 · 速度圣殿(v0.12 实装解析)

- 尺度 96 × 30 格;地面安全网;主赛道 = 三段「加速门 → 曲面 → 大断路」:
  37° / 37° / 45° 出口(2.5× + 曲面 1.5× = 1125 px/s),射程与落台
  逐段校核(落台 A y23 / 落台 B y22 / 终殿台 y19),圆从地面连飞到终殿。
- **高架天路**(y14.4,x18–52):疾 / 跃走高架,三连浮石缺口 2.0 格 ×3,
  东段缺口由 45° 抛物顶点(净空 >1 格)从下方穿过——轨迹互不穿插。
- **逆线**:双段置换——地面 → 落台 A 底 → 高架底,门悬高架底(y16.06)。
- Express 终殿电梯(7 格 / 7s)贴终殿台,失败者绕回终点。

### 09 · 碎裂穹顶(v0.12 实装解析)

- 尺度 92 × 30 格;地面安全网;四块放射曲面(0°→40°→43°→50°)逐级弹射,
  曲面之间全靠**移动接驳**:垂直接驳(行程 3 格 / 3.2s,台位对准抛物线下落点)
  → 水平接驳(行程 2.4 格 / 2.8s)→ 50° 大抛跃上终穹台(顶点 y10.4)。
- **跃线**:东侧五级梯田(步高 1.6 格),门在梯田之顶;
- **疾线**:观测台西壁交替横杆(步高 2.6 格),门在观测台;
- **逆线**:双段置换——贴终穹台底 → 脊梁底(y6),门悬脊梁底。

### 10 · 幕间 · 大风琴(v0.12 实装解析)

- 尺度 100 × 32 格;幕终巨构:一座管风琴,四根音管各考一种能力——
  管·疾 = 交替横杆井(步高 2.6 格 ×7)/ 管·跃 = 之字台阶井(1.6 格 ×10)/
  管·逆 = 置换井(井顶板 → 琴台底,双段置换)/ 管·圆 = 曲面冲天井
  (0°→45°,加速门 + 曲面从管口喷向归位台)。
- **琴台**(y8,x16–84)开两处**出音口**:疾 / 跃穿洞上台归位;
  逆的门悬琴台底面;圆的归位在管口喷台落点——分位归门的幕终变奏。
- Express 主电梯(20.2 格 / 20s)贴琴台东端 = 全员慢路;幕落即 WIN。

## 6. 巨构关卡规范(在 §0–§4 基础上的增量)

1. **尺度基准**:长 ≥90 格、结构高 ≥25 格;相机四锁仍即世界。
2. **安全网原则**:至少一条全程贯通的地面(或接驳网),`kill_y` 随之下移;
   巨构里"坠落"是绕路而不是死亡(失败惩罚 = 重爬,重生点近的自然等价物)。
3. **双线法则**:每段大结构至少两条能力路线——跳跃系快路 + 电梯 / 隧道
   慢路;慢路必须可等待、可恢复。
4. **巨构档构件**:教学关 mover 规范(§3)之外新增 Express 档——
   行程 10–20 格、周期 = 行程(格)×1s(峰值速度 ≈3.1 格/秒),
   只用于长距垂直连接,轨道线必须全程可见。
5. **门位叙事**:终点门位置讲角色的话(逆门悬空、圆门在速度尽头、
   跃门在最高处);门即奖赏风景位。

## 7. 组件语义与图层系统(v0.13 规划定稿 · 2026-09-09)

> 背景:当前全部平台在一个 StaticBody2D 里四面实心(`level_builder.gd`),
> 重叠组件互相封死——天梁穿过东塔处、琴台出音口、回廊天花板与登廊台阶
> 相交处,角色被"不该挡路的墙"挡住;逆的置换落点只按重力反向找面,
> 不感知哪面**应该**可站。本节定义"地图组件"的语义模型,是
> 编辑器(editor.md)与运行时编译(ROADMAP §1 M0)的共同依据。

### 7.1 三个"层"分开设计

| 层 | 问题 | 机制 |
|---|---|---|
| 物理层(谁碰谁) | 重叠组件封路 | `lane` 层级 + 碰撞位(§7.6) |
| 适用层(谁能用) | 路线归属不清 | `who` 集合 + `faces` 朝向(§7.3–7.4) |
| 渲染层(谁遮谁) | 前后景无语义 | `lane → z_index` + 降亮度规则(§7.7) |

### 7.2 组件四元组

地图组件(平台 / 瓦片地形 / 建筑构件)一律携带:

```
组件 = { 几何(位置/尺寸/折点), lane, faces, who, tags, … }
  lane  ∈ back | mid | front      # 层级:背景结构 / 主层 / 前景遮挡
  faces ∈ full | top | bottom | none
  who   = {疾,跃,逆,圆} 子集,空 = 全员
  tags  = ramp / mover / door / …  # 现有语义标签收编
```

### 7.3 faces 四档(定稿:首版不做"仅侧壁实心")

| faces | 语义 | 典型用途 |
|---|---|---|
| `full` | 四面实心(现状) | 主路面、巨构实体 |
| `top` | 仅顶面实心 = 单向薄板,可自下方穿过、上方可站 | 夹层中板、天桥桥面(防下落误撞) |
| `bottom` | 仅底面实心(顶面可穿) | **逆的天花板面**——置换目标专用 |
| `none` | 无碰撞纯装饰 | 背景巨面、出音口装饰 |

- 不做"仅侧壁实心":现有关卡里侧壁场景(挡缘、井壁、爬墙横杆)全部是
  完整矩形,无实装需求;真出现时再扩档,schema 不预留。

### 7.4 who:适用几何体(定稿:整体不碰撞)

- `who` 不含某几何体 = **该组件对此几何体完全不存在**:
  不能站、不能撞、**也不能爬**。
- 决策理由:① 语义单一,"视觉即机制"——不适用组件在对应几何体的
  视野里降透明度(§7.7),玩家一眼读懂"这跟我无关";
  ② "可站不可爬"是反直觉组合(站在墙上却爬不上去),禁止;
  ③ 疾的爬墙是核心机动,`who` 过滤它会让专属路线更清晰。
- 后续真有"可站不可爬"需求,再加独立 `climb` 开关字段,不动 `who` 语义。

### 7.5 置换(逆)的目标面规则

`_perform_swap` 的落点查询加语义过滤:**当前 lane 内、
`faces ∈ {full, bottom}` 且 `who` 含逆**的组件,按重力反向取最近可站面。
"置换落到被重叠结构堵死的位置"从机制上消除。

### 7.6 编译与渲染(实现概览;技术细节见 ROADMAP §1 M0)

- **碰撞位编译**:构建期把 (lane, who) 实际出现的组合分配 Godot 碰撞位
  (32 位预算,常用组合 < 10);玩家 `collision_mask` = 其适用组合位并集,
  **出生时算定一次,运行时零开销**。动态构件(§7.8 / editor.md §3)
  运行时 `set_collision_layer_value` 切换。
- **渲染映射**:lane → z_index(back=0 / mid=1 / front=2);
  `_rests_on` 投影裙角逻辑按 lane 分组重排。渲染为**双后端**
  (LaneRenderer `_draw` / TileRenderer 瓦片)消费同一语义,
  职责分工见 art-style.md §6.7。
- **兼容性**:默认值 `lane=mid / faces=full / who=全员` 与现状逐像素一致,
  序章 + 第一幕 10 关**零迁移**。

### 7.7 前后景视觉规则

- back 层:亮度压到背景红线内(≤ PAPER·8%,art-style.md §4.1),
  玩家可从其前/内部穿过(视 lane 物理位)。
- front 层:玩家在组件**背后**时该组件 modulate 降至 ≈55% 透明度
  (数值待调),保证角色可见;组件对 `who` 不适用的几何体常驻降透明度
  ("视觉即机制",§7.4)。
- 层级变体**不重画瓦片**:全部由引擎 modulate / 调色实现
  (art-style.md §6.6)。

### 7.8 巨构重构机会清单(图层系统落地后逐场择机执行)

> 重构全部是 `level_data.gd` **数据级改动**(给既有组件补 lane / faces / who
> 标注),与渲染后端无关、不被素材进度阻塞;逐场改完用
> `--tourshot --level=N` 巡航截图 + `--autotest` 回归验收。

| 场次 | 现状重叠点 | 图层方案 |
|---|---|---|
| 05 门厅 | 天顶巨梁 × 东塔 / 柱顶引桥交叉 | 梁改 `top` 或 `bottom`;塔身 back 化 |
| 06 天桥 | 桥面 × 曲面落点、桥底逆线净空 0.8 格 | 桥面 `top` 化,逆线净空放宽 |
| 07 回廊 | 天花板 × 登廊台阶相接 | 台阶 back 化,天花板独立 `bottom` |

## 8. 定位网格与量尺(v0.13 规划定稿 · 2026-09-09)

> 网格不再是纯装饰:它是**坐标系**(HUD 读数对齐)、**设计量尺**
> (数值规范的单位制)、**编辑器吸附基准**(editor.md §7)三位一体。

1. **三级 LOD**(密度随视距自适应,业界通行做法):
   - 近景(zoom > 0.9,初值待多端实测):次格 1 格细线 + 5 格主线(现状);
   - 中景:次格隐去,5 格主线常显;
   - 远景:切 10 格点阵(交点微点比线阵远看不糊)+ 坐标数字。
   阈值在桌面与 Android 真机用 `--autoshot` 截图钩子实测后定稿。
2. **坐标数字**:左缘红刻度扩展为上 / 左双缘刻度;编辑器全显,
   游戏内仅边缘显示。
3. **量尺模式**(编辑器):拖动组件显示与邻近组件的格距,按规范变色
   ——合规纸白 / 触线黄 / 违规红(≤1.6 普通跳 / 2.6 二段跳 / 3.5 冲刺跳
   / 7.5 需圆)。
4. **视差解耦**:背景装饰(Backdrop)scroll_scale 与网格不同频
   (现状已满足),远景档校验装饰不与残留网格线产生摩尔纹。
