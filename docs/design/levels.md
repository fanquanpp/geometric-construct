## 1. 关卡写作流程(从 TWA 学到的)

1. 先定教学段名(像 TWA 作者给段落命名 "Jump Up" / "Jump Gap with Rise"),
   写进 `intro` 字段:第一行教操作,第二行教原理。
2. 跳距公式化:满跳高度 h = v²/2g → 普通跳缺口 1.2–1.9 格,二段跳缺口 2.6 格,
   冲刺+二段跳 3.5+ 格;上升台阶 ≤1.9 格(2.0 格跳高 − 0.1 余量)。
3. **节奏三段式**:热身(安全,纯走)→ 教学点(安全网)→ 考验(失败惩罚轻,
   重生点近)→ 出口前缓冲(让玩家喘口气再看结算)。
4. 视线引导:用红色刻度块、门牌、曲面亮线把玩家视线"排"向前进方向;
   死路只用一次,且必须给视觉补偿(大号数字或装饰巨面)。

## 3. 动态地图原则(v0.8 起,"地图也可以是动态的")

1. **运动构件只做两件事**:连接(transport)与 变奏(variation)。
   连接 = 移动平台补断路;变奏 = 让静态谜题多一个时间维度。
2. **教学关的运动必须可等待**:移动平台慢速(≥3s/程)且不会把玩家推向死区。
3. **背景是活的,前景是稳的**:视差层缓慢漂移 / 呼吸(增量 ≤10%),
   平台本体保持预测性(踩上去之前就能算出落点)。
4. TWA 式动态平台参数:相对路径点 + 缓动 + `pause` 停顿 + 循环;
   本作简化为单轴往返(offset 向量 + period + phase),够用且可 JSON 化。

## 4. 配色与章节化(借鉴 TWA:平台色由背景推导)

- 平台基色 `#262B34` / 亮面 `#313845` 保持全局统一(可读性优先);
  章节感交给**背景巨面**与**门牌 / 刻度**的角色色密度表达:
  疾关红刻度密,跃关黄点缀多,逆关蓝,圆关橙。
- 背景亮度红线:任何背景元素 ≤ PAPER·8% 亮度(见 art-style.md §4)。

## 6. 巨构关卡规范(在 §0–§4 基础上的增量)

1. **尺度基准**:长 ≥90 格、结构高 ≥25 格;相机四锁仍即世界。
2. **安全网原则**:至少一条全程贯通的地面(或接驳网),`kill_y` 随之下移;
   巨构里"坠落"是绕路而不是死亡(失败惩罚 = 重爬,重生点近的自然等价物)。
3. **双线法则**:每段大结构至少两条能力路线——跳跃系快路 + 电梯 / 隧道
   慢路;慢路必须可等待、可恢复。
4. **巨构档构件**:教学关 mover 规范(§3)之外新增 Express 档——
   行程 10–20 格、周期 = 行程(格)×1s(峰值速度 ≈3.1 格/秒),
   只用于长距垂直连接,轨道线必须全程可见。
5. **门位叙事**:终点门位置讲角色的话(逆门悬空、圆门在速度尽头、
   跃门在最高处);门即奖赏风景位。

## 7. 组件语义 v4(现行契约;v0.44.0 起层概念已整体退役)

- **组件 = {id, faces, who 集合, tags}**:
  - `faces ∈ full | top | bottom | none`:四面实心 / 仅顶面单向(上行自由、
    下行承接)/ 仅底面(逆的重力天花板,底缘蓝线标记)/ 无碰撞纯装饰。
  - `who` 集合:组件对哪些几何体生效;空 = 全员共享。
  - `id`:关内唯一,显式优先,缺省 401 起自动编(root meta "items" 可查)。
- **实体化谓词(唯一函数)**:`Comp.solid_for = faces ≠ none ∧ who 适用`;
  渲染与碰撞共用,所见即所碰。装饰件(faces=none)画装饰容器,自由穿行。
- **碰撞签名**:实体组件按 who 集合编译共享碰撞位(位 3..29,bit30 = 磁界
  特权位,位上限由压测守卫);玩家 mask = 适用签名并集,出生算定一次。
  动态构件(开关门 / 限时桥)逐实例独占位,运行时切位。
- **画序带(引擎原生)**:装饰容器 z0 < 实体容器 z1 < 机关 3/4 < 玩家 z5
  < 调试叠加 z20;容器内大块先画(面积降序)。石板 = `TerrainKit.slab_node`
  (Polygon2D 面 / 亮肩 / 顶缘亮线 / 底缘蓝线 / 红刻度 / 裙角,零 _draw)。
- **高亮三档(机关物,FocusDriver)**:专属(who 含受控者)色描边呼吸 /
  共享常亮 / 无关幽灵暗度 0.35。
- **伍门区三件套**(双体关卡门位范式):双台同高(顶 680,底缘嵌地 930)+
  门楣挂点(底 590,界)+ 门区 ±86 双落点;伍出生 `a` 点 y ≥ 270(防嵌天花)。
- **作关纪律(reach_check 建模实锤)**:逆 / 圆 `can_jump=false`——其地面
  必须连续;上行踏步 dy≤150、平缝≤250(疾 400);出口位 = 平台顶 −50;
  落地竖直件底缘嵌地 ≥50(§8.4 接缝纪律)。

### 8.1 坐标量尺表(Dimensions 表 · 定稿)

| 量 | 值(格) | 推导 |
|---|---|---|
| 格单位 | 1 格 = 100 px = 1.0 属性单位 | Geometries.UNIT_PX |
| 体高 | 疾 0.5 / 逆·伍 0.3 / 圆 0.52 / 跃 0.8 | 名册尺寸 |
| 跳高 | 2.0(疾/跃),二段跳 4.0,顶弹 4.0 | jump_units / 跃特性 |
| 伍跳高 | 1.0 | characters.md §5 |
| **行走净空(头顶)** | **≥ 1.0** | 最高体高 0.8 + 0.2 余量 |
| **通行走道(水平)** | **≥ 1.2** | 圆 0.52 直径 + 滚动余量 |
| 跨坑宽 | ≤ 2.6 普通跳 / 4.6 二段跳 / 5.5 冲刺跳 | 跳距 × 速度 |
| 可行走/滚行坡度 | ≤ 37° | glossary §3 |
| 台阶高(无需跳) | ≤ 0.9 | < 最低跳高 1.0 |

### 8.2 分区坐标系 zones(v0.20.0 实装)

关卡声明命名分区,网格从"均匀线阵"升级为"带行政区划的地图":

- 数据:`def.zones: [{rect, name, layer?}]`——rect 吸附整格;name
  关内唯一(如 "Z1 出生");分区标注渲染在定位网格
  (缺省随 L4)。与分层体系强关联:**分区也是组件,同样挂层**。
- 呈现:分区名以低亮度纸白标注在分区左上格点(近景 LOD 显示);
  HUD 坐标读数扩展为 `分区名 · x,y`(跨界防抖 0.5s,防进出闪跳)。
- 引用:tours / hints / 调试日志 / 存档可记分区名而非裸坐标——
  v3→v4 重设计时 节拍全部手工重标的教训:
  坐标引用失配是布局迭代的最大摩擦,分区名是稳定引用键。

### 8.3 组件 id × 坐标标注(v0.20.0 实装)

v3 组件编号(§7.10,按层分段)是坐标化的索引半边:

- 调试叠加层(默认关;PC 端 `--debug-grid` 或 设置面板 → 调试 DEBUG
  开关,双端一致):组件左上格点标注 `id·层` 小字(如 `403·L4`);
  who 非空的语义组件附加首位几何体色点与 who 名单(如 `501·L5·{疾}`)。
- HUD 坐标读数扩展为 `几何体 · 分区名 · x,y · 层签名`(如
  `疾 · Z1 出生 · x23.5, y17.75 · 共享`)——分区与归属
  常驻可读;判定用角色脚底点(外扩 2px 吸收落地边界)。

### 8.4 吸附纪律与 --gridcheck(v0.20.0 实装)

- **吸附规范**(Tiled "Snap to Grid" 的数据版;纪律由校验器执行):
  全部数值为**整数像素**(硬性);对齐 0.1 格为建议级(落地缓冲类
  5px 悬停——出生点 / 门心 / 坡末端——允许并计 WARN)。
- **`--gridcheck`(headless 校验器)**:装载关卡数据逐项检查:
  1. 吸附违规(按上表);
  2. **净空检查**:faces=full/top 可站立顶面上方 1.0 格内不得有实体
	 (按 §7.10 谓词对 who 内每个几何体分别裁定);
  3. 行程检查:mover / 电梯扫掠体与实体相交(placement 纪律机器化);
  4. 越界检查:组件出关卡边界、侵入 kill 区;
  5. 伍门可达启发式:双体门 ±50 区内同时存在界(天花底)与
	 边(地/台)落点(防死局复发);
  6. **共面接缝检查**:实体竖直侧壁的底缘不得与可行走面齐平
	 (须嵌入承载面 ≥0.5 格)——高速贴地移动撞上零高度差接缝会
	 转角穿模卡死(v4 实测:疾冲刺嵌入气闸门板下缝)。
  违规输出 `GRIDCHECK FAIL: <id> <规则> <坐标>`,**退出码非零**,
  接入发版钩子。运行:`godot --headless --path . --script
  res://tests/grid_check.gd`(可加 `-- --level=N` 单关)。六类检查
  已全部实装,v4 试炼场为首个全绿关卡(12 条落地缓冲 WARN)。

### 8.5 渲染与 LOD(已实装,v0.13)

1. **三级 LOD**(密度随视距自适应):近景 = 次格 1 格细线 + 5 格
   主线;中景 = 仅 5 格主线;远景 = 10 格点阵 + 缘坐标数字。
2. **坐标数字**:上 / 左双缘刻度,远景档边缘显示。
3. **视差解耦**:背景装饰 scroll_scale 与网格不同频,无摩尔纹。
