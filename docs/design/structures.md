# 特殊建筑物设计 · STRUCTURES

> 状态:现行(v0.8) · 数据源:`scripts/entities/*`、`scripts/world/level_builder.gd`
> 关卡里除地面平台外的一切可交互构件,统一在本文登记;新构件先立项再实现。

## 0. 构件设计原则

1. **一眼读懂**:构件的形状必须暗示功能 —— 门是取景框,加速门是雪佛龙箭头。
2. **单一职责**:一个构件只改一个属性 / 触发一个事件;组合交给关卡设计。
3. **构成主义外观**:全部直角折线 + 硬投影 + 角色色 / 构成红点缀,无柔光。

## 1. 终点门 ExitDoor(`scripts/entities/exit_door.gd`)

| 项 | 内容 |
|---|---|
| 外观 | 几何体专属取景框门:门框 = 目标角色色的双线取景框 + 顶部红色编号刻度 |
| 归属 | 只接受 `geo_index` 对应的几何体;他人可穿过不收取 |
| 状态机 | 待命(角色到站站立)→ 到站(arrived,可撤销)→ 全员到齐 sealed(封印)→ 吸入 |
| 演出 | 到站:角色 0.22s 滑入门中线;激活:依次 0.18s 间隔吸入,缩小至 8% + 粒子 |

## 2. 加速门 SpeedGate(`scripts/entities/speed_gate.gd`)

| 项 | 内容 |
|---|---|
| 外观 | 雪佛龙折角通道(双排箭头指向行进方向),穿越时箭头亮起 |
| 效果 | 速度上限立即抬升至 `buff_sprint_speed`(永久,死亡重生失效);只加速不影响重量 |
| 演出 | 首次触发:HUD 旁白 + buff 音效;速度线残影自然出现(>1.2×) |

## 3. 曲面跳跃板 Ramp(`scripts/world/level_builder.gd` Ramp)

| 项 | 内容 |
|---|---|
| 外观 | 折线曲面(折角步进 ≤7°)+ 硬投影 + 红色刻度块;顶缘亮线 |
| 物理 | 逐段实心凸四边形碰撞;圆球贴坡时速度对齐切线,滑出沿切线飞出 |
| buff | 踩上:速度上限 ×1.5 + 等效重量减半;离开后残留 1.5s;与加速门/冲刺叠乘(取最高再 ×1.5) |

## 4. 移动构件 Mover(v0.8 新增,`level_builder.gd`)

| 项 | 内容 |
|---|---|
| 外观 | 与普通平台同语言的石板条,侧缘带角色色/构成红方向刻度(向哪动刻度在哪侧) |
| 物理 | `AnimatableBody2D`(sync_to_physics)在两点间直线往返:水平或垂直 |
| 参数 | `rect` 尺寸、`offset` 往返向量(px,沿单轴)、`period` 秒、`phase` 相位 |
| 设计值 | 慢速 3.0–4.0s/程(踩着思考)、中速 2.0–2.5s/程(踩着赶路);振幅 100–240px(1–2.4 格) |
| 承载 | 站立者随平台移动(CharacterBody2D 平台速度继承);驮人链条照常工作 |

## 5. 规划中(立项待实现,按优先级)

| 构件 | 概念 | 立项理由 | 依赖 |
|---|---|---|---|
| 弹射板 Launcher | 踩上瞬弹到固定高度,方向固定向上 | 补足"不可跳角色的垂直移动" | 无 |
| 传送对 Portal | 成对直角门,进 A 出 B,保留速度矢量 | 置换关卡的捷径语言 | 无 |
| 单向闸 OneWay | 仅单侧可穿的平台薄板 | 竖直关卡防回头 | 无 |
| 计时环 TimeRing | 穿过加分 / 加时(肉鸽计时模式) | 肉鸽模式竞速层 | 肉鸽框架 |
| 脆弱块 Crumble | 踩上 0.6s 后碎裂重生 | 高压迫感 | 无 |

## 6. 命名与登记规则

- 新构件:实体脚本进 `scripts/entities/`,纯绘制辅助留在 `level_builder.gd` 内部类。
- LevelDef 新字段必须可被分享码 JSON 同构表达(见 ROADMAP 编辑器章节)。
- 本文档同步追加"外观 / 物理 / 演出"三行,缺一不收。
