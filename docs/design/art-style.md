# 美术风格规范 · ART STYLE

> 状态:现行(v0.8 起) · 构成主义 Constructivism + 极简主义 Minimalism + 动态感
> 本文是视觉决策的唯一权威;`scripts/ui/ui.gd` 是调色板与组件的唯一代码来源。

## 1. 调色板

| 名称 | 色值 | 用途 |
|---|---|---|
| INK `#101216` | 墨色 | 全局背景 |
| INK_2 `#16191F` / INK_3 `#1E222B` | 面板墨 | 面板 / 提亮层 |
| PAPER `#EDEAE0` | 纸白 | 主文本、线条、图标主色 |
| DIM `#8E8D85` | 灰 | 次要文本 |
| RED `#E0492F` | 构成红 | **全局唯一强调色**(编号块、强调条、焦点、刻度) |
| 角色四色 `#E0492F / #E8B33A / #4E86D8 / #E07E2E` | | 仅作功能性点缀(角色徽标、属性条、chips) |
| 石板 `#262B34` / 亮面板 `#313845` | 平台基色 | 关卡静态平台(§4;瓦片素材同源,见 §6) |
| 动板 `#2B3140` / 亮面板 `#3A4254` | 移动板基色 | 与静态石板区分(瓦片素材同源,见 §6) |

用色纪律:一屏只允许一个红色主角(强调条、编号块、或焦点框,不叠加);
角色色永远不作为大面积底色;灰阶层次 ≥ 3 级(INK / INK_2 / DIM)保空间感。

## 2. 形状语言

- **禁止**:圆角(rx > 0)、渐变、投影模糊(高斯/阴影 blur)、贝塞尔曲线、发光贴图。
- **必须**:直角矩形、直线段 / 折线、`stroke-linecap="square"`、`stroke-linejoin="miter"`。
- 柔影一律替换为**硬投影**(整体位移的实心暗块,偏移 7–10px)。
- 允许的圆:几何圆环"太阳"、圆球角色、圆点刻度 —— 圆必须是"完整的几何圆",
  不允许椭圆装饰、圆弧飘带。
- 构成主义母题库:红色小方块标记、细线分隔条(rule)、大号数字编号(01/02…)、
  角部刻度、雪佛龙折角、几何圆环、取景框角标、斜切三角 / 梯形巨面。
- 字体:NotoSansSC 可变字重;标题 900(+2 字距)、正文 400、注释 330。
- SVG 素材:仅 flat 单样式;由 `tools/gen_svgs.py` 生成,禁手改;
  ThorVG 不支持 `<text>`,字母用折线字形。

## 3. 动效法则(MOTION RULES)

> 一切动画服务于"构成主义的机械感":像印刷机、像起重机、像节拍器 ——
> 不像果冻、不像水面。动效是让静止海报"通电",而不是把它变成卡通。

| 法则 | 规定 |
|---|---|
| M1 缓动白名单 | 入场 `TRANS_CUBIC/QUINT + EASE_OUT`(硬减速停)、回弹 `TRANS_BACK`、
节奏件 `TRANS_SINE` 往返;**禁** `TRANS_ELASTIC`(果冻感)、`TRANS_BOUNCE`(皮球感,圆球角色物理除外) |
| M2 时长档位 | 微交互 0.10–0.16s;面板出入 0.25–0.45s;场景转场 0.5–0.8s;只允许 0.05s 步进 |
| M3 直线优先 | 位移沿水平 / 垂直轴;斜向入场统一 45° 折线感(先斜插再归位) |
| M4 硬投影同步 | 元素带硬投影的,投影随本体一起动(整体 tween),不允许投影滞留 |
| M5 呼吸与脉冲 | 常驻动效(呼吸角块、脉冲刻度)周期 1.5–2.5s,幅度 ≤ 10%,永不居中抢焦点 |
| M6 打点音效 | UI 动效 landing 瞬间配 `ui_click / ui_open / ui_page` 等打点音;无声动效不得超过 0.4s |
| M7 逐字 / 逐项入场 | 列表与标题逐项 stagger 0.04–0.07s;方向统一(自上而下或自左而右) |
| M8 屏幕震动 | 仅死亡 / 通关大事件;幅度 ≤ 8px,衰减指数 ≥ 14/s;
M8b 补充档 ≤12px 限巨构大落差坠落 / 复合事件(实机手感回写,见 motion.md §7) |
| M9 帧率独立 | 全部 tween 用秒;常驻脉冲用 `Time.get_ticks_msec()`,禁止帧计数驱动 |

## 4. 关卡视觉层次

1. 背景层(视差 0.06–0.6):巨面 / 山脊 / 星阵,亮度 ≤ PAPER·8% 不与平台争夺注意。
2. 平台层:石板 `#262B34` + 亮面板 `#313845` + 顶缘线 PAPER·30% + 红色刻度块。
3. 实体层:角色 / 门 / 门牌(高饱和)。
4. UI 层:细线 + 色块 + 大字。

## 5. 风格审计清单(每次大改后过一遍)

- [ ] 全部 StyleBoxFlat `corner_radius == 0`
- [ ] 无 `Gradient` / `GradientTexture2D` 用于装饰(UI 的 radial_tex 仅限历史兼容,新代码禁用)
- [ ] 阴影只有硬投影(纯色位移色块)
- [ ] SVG 素材全部 flat 单色、直角折线
- [ ] 动效缓动在 M1 白名单内;时长符合 M2 档位
- [ ] 红色使用点每屏 ≤ 3 处角色(强调、刻度、焦点各一)
- [ ] 图标含 `<text>` 的为 0(ThorVG 限制)
- [ ] 瓦片素材新片沿用 §6 规格(100px = 1 格、1:1、锁调色板、源 .aseprite 唯一权威)

## 6. 瓦片素材管线 · TILESET PIPELINE(v0.12 起绘制;v0.13 定稿**双管线混合**)

> 状态:**`_draw()` 程序化渲染与瓦片长期共存**(分工定稿见 §6.7)。
> 瓦片承担地形外观"皮"(砌缝 / 暴露位边缘 / 变体质感),编辑器(M2)产物
> 强制走瓦片路径;官方 10 关维持 `_draw()`,统一替换为单次发版决策
> (全关 A/B 截图对比后定夺)。语义、动态、投影永远在引擎侧。

### 6.1 源文件唯一权威

- **源**:`assets/art/tiles/*.aseprite` —— 唯一修改入口(引擎不导入);
- **存档**:`assets/tiles/*.png` —— 由源导出的生成物,只读不改,当前无代码引用。
- Godot **不能**原生读取 .aseprite;后续接入二选一:
  1. **AsepriteWizard 类插件**(推荐):导入时自动调 Aseprite CLI 重导出,
	 PNG 退化为纯构建产物;
  2. 手动 / 脚本导出(命令见 `assets/art/README.md`)。

### 6.2 规格

| 项 | 值 |
|---|---|
| 瓦片 | **1 tile = 100×100 px = 1 格**,1:1 零缩放(与"一米一格"对齐) |
| 图集 | tileset 1000×400(10 列 × 4 行);Aseprite 内分 5 层:terrain / ramps / decor / mover / guides(隐藏参考网格) |
| 调色板 | §1 锁定:石板 `#262B34`、亮面板 `#313845`、动板 `#2B3140 / #3A4254`;顶缘线 = PAPER·30%、动板顶缘线 = PAPER·42%、砌缝 = 石板暗档 |
| 画法 | 同 §2 禁则:无圆角 / 无渐变 / 无模糊;砌缝横线全图集对齐(r 片内 y38 / y76,相邻片自动连缝) |

### 6.3 图集映射(tileset;列 c、行 r 从 0 起,x = c×100, y = r×100)

**地形石板 16 片**(c0–3 × r0–3):暴露位公式 **`c = N + 2S`(列),`r = W + 2E`(行)**
(bit = 1 表示该边是外边界):N 暴露 → 顶缘亮线 2px + 亮面板 20px;
S 暴露 → 底部暗档 4px;W / E 暴露 → 侧缘暗档 2px;均不暴露 = 中间片。

| 片位 | 内容 |
|---|---|
| (0,0) | 中间片(无暴露) |
| (0–3, 0–3) 按 r/c 公式 | 其余 15 片(N / S / W / E 单边、四角、三边、(3,3) 孤立浮块) |
| (4,0) | 顶缘 + 红刻度(居中 x43) |
| (5,0) | 顶缘 + 红刻度(左位 x40,与现平台 480px 节奏对齐) |
| (6,0) | 素面板(无砌缝,巨构大片用) |
| (7,0) (8,0) (9,0) | 缓上坡 A / 缓上坡 B / 45° 上坡 |
| (4,1) | 出生标记(四角取景框 PAPER·40%) |
| (5,1) | 虚空斜纹(编辑器禁放 / 危险区标注) |
| (6,1) | 原点十字 RED·55%(网格 gizmo) |
| (7,1) | 左缘网格刻度(与 GridLayer 同语言) |
| (8,1) (9,1) | 缓下坡 A / 缓下坡 B |
| (4,2) | 教学牌锚点(红块 + 基线,HintMarker 同语言) |
| (5,2) | 横轨道线 PAPER·16% |
| (6,2) | 竖轨道线 PAPER·16% |
| (7,2) | 轨道端点刻度(红 5×5 上下各一) |
| (8,2) | 45° 下坡 |
| (4–6,3) | 移动板条:左帽 / 中段 / 右帽(横向九宫,浅色系 + 双红刻度) |
| (7,3) | 移动板独岛(1 格宽) |

坡面片约定:片内表面自左缘高度 yl 到右缘高度 yr(0 = 片顶);**缓坡 = 每片
升 / 降半格,两片合成一格升**;45° = 一片一格;坡片上方透明、下方实体砌到片底,
可纵向叠在地形片上补厚。红色刻度**沿坡向嵌入表层亮带**(横向 14px 居中
x43–56,每列自表面下 6px 起、竖向 3px,随曲面下移)——不做水平刻度,
避免在斜面上半截悬空、半截嵌板。

### 6.5 编辑器适配要点(后续统一替换时执行)

1. 地形走 TileMapLayer terrain 模式:peering bits 按 §6.3 的 r/c 公式映射 16 片;
2. **像素图不承担碰撞**:坡面碰撞仍由 Ramp 折线凸四边形、平台仍由 Rect2 负责,
   瓦片只做外观;瓦片笔刷自带语义默认值(lane / faces / who,
   定义见 levels.md §7)由编辑器写进组件属性;
3. 移动板 = L/M/R 三片横向九宫 + 独岛片;本体仍是 Mover(AnimatableBody2D);
4. 门 / 加速门以场景实体挂 Sprite2D(取雪碧图帧),雪佛龙滚动、核心呼吸等
   动画在引擎层做(源图只存首末态);
5. **硬投影不入瓦片**:投影是"平台整体对背景"的关系(M4 同步位移),
   保持引擎侧实心暗块绘制;
6. **图集五层 ↔ 编辑器托盘一一对应**(editor.md §1):
   terrain → 地形笔刷 / ramps → 曲面组件 / decor → 装饰组件 /
   mover → 移动构件 / guides → 编辑器辅助线(不入游戏);
   美术在 Aseprite 内新增一层分类,编辑器托盘自动多一组笔刷。

### 6.6 图层渲染变体(v0.13 图层系统配套,**不重画瓦片**)

lane 层级(levels.md §7.7)的全部视觉变体由**引擎侧实现**,美术零增量:

| lane | 引擎处理 |
|---|---|
| back | modulate 压亮度至背景红线内(≤ PAPER·8%,§4.1);无需新瓦片 |
| mid | 原样(现状渲染) |
| front | 常态原样;玩家在组件背后时 modulate 降至 ≈55% 透明度(数值待调) |
| who 不适用 | 该几何体视野内常驻降透明度("视觉即机制",levels.md §7.4) |

faces 语义预览同理:`top` 薄板减薄显示、`bottom` 面加底缘角色色细线
(逆=蓝)——编辑器画布预览与游戏内渲染同一路径(editor.md §9)。

**新增绘制需求**(动态构件,编辑器首版配套):
开关门门板(实心 / 虚线框两态)+ 踩踏开关(凸 / 凹两态)、
限时桥板条(实心 / 8% 亮度线框两态)——均为单帧两态,无需动画序列;
入 tileset 新分层 `dynamic` 或独立实体源文件,立项时定。

### 6.7 双管线职责分工 · HYBRID PIPELINE(2026-09-09 定稿)

> 决策:`_draw()` 程序化渲染与 Aseprite 瓦片**长期共存**,不是谁取代谁。
> 一份 Comp 语义数据(levels.md §7.2)喂两个渲染后端;**语义、动态、投影
> 永远在引擎侧,地形外观质感归瓦片**。任何一边不得私自实现对方职责。

**A. 引擎侧永久负责**(任何渲染后端不变;`_draw()` / Node2D):

| 项 | 内容 | 不可入瓦片的原因 |
|---|---|---|
| 语义视觉 | lane 三档 modulate(back 压亮 ≤PAPER·8% / front 遮挡 55% / who 不适用渐隐 0.30、0.16s 过渡)+ faces 语义线(top 顶缘增强 / bottom 底缘角色色) | 运行时随操控几何体连续变化(§6.6,不重画瓦片) |
| 硬投影与裙角 | 整体位移实心暗块(M4 同步)、投影分组、`_rests_on` 横向偏移、45° 接触裙角 | 投影是"组块对背景"的关系(定稿:硬投影不入瓦片) |
| 曲面 Ramp 全部 | 任意折线渲染(3°–50° 逐段)+ 碰撞同源 | 瓦片坡片只有半格 / 45° 离散档,表达不了连续折角;坡片仅编辑器画布预览近似 |
| 动态构件状态演出 | LeverGate 凸凹 / 门板切换、TimedBridge 实虚切换、PianoTile 脉冲与音符粒子(切换时机 / 碰撞位 / 音效) | 动态的是状态不是规则;瓦片只供两态静帧,切换合成在引擎 |
| 系统级绘制 | GridLayer 网格与坐标刻度、MoverTrack 轨道线、HintMarker 教学牌、出生标记、实体(玩家 / 门 / 加速门) | 全部运行时几何或与引擎实体绑定 |
| 任意几何容错 | 非整格矩形直接渲染(官方关大量 120px 板厚等) | 瓦片以格为单元 |
| 调试兜底 | 线框 / 调试渲染模式 | 瓦片缺失或加载失败时的后备 |

**B. 瓦片负责**(Aseprite 源 → PNG → 纹理外观;美术可独立迭代,改图不动码):

| 项 | 图集来源 |
|---|---|
| 地形石板"皮":填充 + 砌缝 + 暴露位边缘(16 片 autotile,`c = N+2S` / `r = W+2E`) | terrain 层(§6.3) |
| 石板变体:红刻度嵌入 / 素面板 | terrain 层 |
| 装饰:背景巨面、大号数字、幕主题结构母题(挂 lane=back;章节感仍按 levels.md §4 交给背景与刻度) | decor 层 |
| 移动板条九宫(L/M/R 帽 + 中段 + 独岛;本体仍是 Mover 实体) | mover 层 |
| 动态构件两态静帧:门板实心 / 虚线框、开关凸 / 凹、桥板实心 / 虚化(切换合成在引擎) | dynamic 分层(上文新增绘制需求) |
| 坡片 6 片:**仅编辑器画布预览近似**,游戏内 Ramp 永远引擎画 | ramps 层 |

**C. 两侧同源,禁止各自实现**:

- Comp 四元组 + `LevelDef` 全字段(JSON 同构)——唯一数据入口;
- **碰撞永不入瓦片**(Rect2 / 折线碰撞与渲染后端无关,定稿纪律);
- 调色板:`ui.gd` 常量与图集锁色(§1)同一套值;
- lane / who / faces 的透明度与语义线计算:两个后端调同一函数。

**D. 接线与切换策略**:

- `LaneRenderer`(现行 `_draw`)与 `TileRenderer`(M2 起实现,ROADMAP §1)
  并列消费同一 Comp。瓦片渲染 = 按 Rect2 暴露位取片 + 内部平铺 +
  边缘裁切:格对齐画布(编辑器产物)天然无缝;官方关非整格矩形
  边缘裁切可接受,碰撞零变化。TileMapLayer 仅编辑器画布使用,
  游戏内瓦片渲染走纹理区域绘制,与 lane / who modulate 语义共用引擎代码。
- 三条内容路径:**官方 10 关** = M2 前维持 `_draw()`,M2 后做"统一替换
  适配"**单次发版决策**(`--tourshot` 全关 A/B 截图对比后定夺;逐像素
  对齐是瓦片绘制的规格要求,切换点应几乎无感,此后美术增量逐步显形);
  **编辑器产物** = 强制瓦片路径;**新增内容**(第二幕起)= TileRenderer
  落地后瓦片优先,此前与官方关同路。
- 回归验收:`--tourshot` / `--autoshot` 双后端同关对比 + `--autotest`
  全关回归(碰撞行为与渲染后端无关,必须零差异)。
