# 美术风格规范 · ART STYLE

> 状态:现行(v0.8 起) · 构成主义 Constructivism + 极简主义 Minimalism + 动态感
> 本文是视觉决策的唯一权威;`scripts/ui/ui.gd` 是调色板与组件的唯一代码来源。

## 1. 调色板

| 名称 | 色值 | 用途 |
|---|---|---|
| INK `#101216` | 墨色 | 全局背景 |
| INK_2 `#16191F` / INK_3 `#1E222B` | 面板墨 | 面板 / 提亮层 |
| PAPER `#EDEAE0` | 纸白 | 主文本、线条、图标主色 |
| DIM `#8E8D85` | 灰 | 次要文本 |
| RED `#E0492F` | 构成红 | **全局唯一强调色**(编号块、强调条、焦点、刻度) |
| 角色四色 `#E0492F / #E8B33A / #4E86D8 / #E07E2E` | | 仅作功能性点缀(角色徽标、属性条、chips) |
| 石板 `#262B34` / 亮面板 `#313845` | 平台基色 | 关卡静态平台(§4;瓦片素材同源,见 §6) |
| 动板 `#2B3140` / 亮面板 `#3A4254` | 移动板基色 | 与静态石板区分(瓦片素材同源,见 §6) |

用色纪律:一屏只允许一个红色主角(强调条、编号块、或焦点框,不叠加);
角色色永远不作为大面积底色;灰阶层次 ≥ 3 级(INK / INK_2 / DIM)保空间感。

## 2. 形状语言

- **禁止**:圆角(rx > 0)、渐变、投影模糊(高斯/阴影 blur)、贝塞尔曲线、发光贴图。
- **必须**:直角矩形、直线段 / 折线、`stroke-linecap="square"`、`stroke-linejoin="miter"`。
- 柔影一律替换为**硬投影**(整体位移的实心暗块,偏移 7–10px)。
- 允许的圆:几何圆环"太阳"、圆球角色、圆点刻度 —— 圆必须是"完整的几何圆",
  不允许椭圆装饰、圆弧飘带。
- 构成主义母题库:红色小方块标记、细线分隔条(rule)、大号数字编号(01/02…)、
  角部刻度、雪佛龙折角、几何圆环、取景框角标、斜切三角 / 梯形巨面。
- 字体:NotoSansSC 可变字重;标题 900(+2 字距)、正文 400、注释 330。
- SVG 素材:仅 flat 单样式;由 `tools/gen_svgs.py` 生成,禁手改;
  ThorVG 不支持 `<text>`,字母用折线字形。

## 3. 动效法则(MOTION RULES)

> 一切动画服务于"构成主义的机械感":像印刷机、像起重机、像节拍器 ——
> 不像果冻、不像水面。动效是让静止海报"通电",而不是把它变成卡通。

| 法则 | 规定 |
|---|---|
| M1 缓动白名单 | 入场 `TRANS_CUBIC/QUINT + EASE_OUT`(硬减速停)、回弹 `TRANS_BACK`、
节奏件 `TRANS_SINE` 往返;**禁** `TRANS_ELASTIC`(果冻感)、`TRANS_BOUNCE`(皮球感,圆球角色物理除外) |
| M2 时长档位 | 微交互 0.10–0.16s;面板出入 0.25–0.45s;场景转场 0.5–0.8s;只允许 0.05s 步进 |
| M3 直线优先 | 位移沿水平 / 垂直轴;斜向入场统一 45° 折线感(先斜插再归位) |
| M4 硬投影同步 | 元素带硬投影的,投影随本体一起动(整体 tween),不允许投影滞留 |
| M5 呼吸与脉冲 | 常驻动效(呼吸角块、脉冲刻度)周期 1.5–2.5s,幅度 ≤ 10%,永不居中抢焦点 |
| M6 打点音效 | UI 动效 landing 瞬间配 `ui_click / ui_open / ui_page` 等打点音;无声动效不得超过 0.4s |
| M7 逐字 / 逐项入场 | 列表与标题逐项 stagger 0.04–0.07s;方向统一(自上而下或自左而右) |
| M8 屏幕震动 | 仅死亡 / 通关大事件;幅度 ≤ 8px,衰减指数 ≥ 14/s;
M8b 补充档 ≤12px 限巨构大落差坠落 / 复合事件(实机手感回写,见 motion.md §7) |
| M9 帧率独立 | 全部 tween 用秒;常驻脉冲用 `Time.get_ticks_msec()`,禁止帧计数驱动 |

## 4. 关卡视觉层次

1. 背景层(视差 0.06–0.6):巨面 / 山脊 / 星阵,亮度 ≤ PAPER·8% 不与平台争夺注意。
2. 平台层:石板 `#262B34` + 亮面板 `#313845` + 顶缘线 PAPER·30% + 红色刻度块。
3. 实体层:角色 / 门 / 门牌(高饱和)。
4. UI 层:细线 + 色块 + 大字。

## 5. 风格审计清单(每次大改后过一遍)

- [ ] 全部 StyleBoxFlat `corner_radius == 0`
- [ ] 无 `Gradient` / `GradientTexture2D` 用于装饰(UI 的 radial_tex 仅限历史兼容,新代码禁用)
- [ ] 阴影只有硬投影(纯色位移色块)
- [ ] SVG 素材全部 flat 单色、直角折线
- [ ] 动效缓动在 M1 白名单内;时长符合 M2 档位
- [ ] 红色使用点每屏 ≤ 3 处角色(强调、刻度、焦点各一)
- [ ] 图标含 `<text>` 的为 0(ThorVG 限制)
- [ ] 地图零贴图:全部 `_draw()` 程序化绘制;aseprite 瓦片管线已废止(§6),无游离的像素素材引用

- **地图渲染 = 引擎侧 `_draw()`(唯一管线)**:平台 / 曲面 / 移动构件 /

  顶缘线 PAPER·30%(动板 PAPER·42%)、左缘红刻度块每 480px 一处;
  硬投影 offset(7,8)、承接立块只横向投影 + 45° 裙角(见
  `level_builder.gd` LaneRenderer,规则本节不再重复)。
- **语义视觉变体(v0.13 图层系统 / v0.14 远景沉降)**:
  lane back 压亮度至背景红线内 / front 玩家躲入其后降至 55% /
  who 不适用沉入远景两档(far1 z=-1 冷色幽灵渗雾 66%、far2 z=-2 渗雾 74%

  按距离波次级联、交叉淡化升降(近先远后 ≤0.3s);
  faces=top 顶缘亮线加亮、bottom 底缘蓝色细线(逆 = 蓝)、none 8% 线框;
  动态构件虚化态 8% 亮度线框 + 虚线段。全部引擎 modulate / 色彩实现,
  无任何贴图。

  `tools/gen_svgs.py` 生成)继续用于 UI 图标与角色徽标。
- **形状与调色板纪律(§1/§2)照旧全局适用**,包括程序化绘制:
  无圆角、无渐变、无模糊投影、直角折线。

## 7. 剧幕主题差分与统一(v0.16 定稿,治理"多页面不统一太杂乱")

> 大主题锚定不变:**构成主义 + 几何棱角分明 + 极简主义**。差分不碰地基——
> 调色板(§1)、形状语言(§2)、动效法则(§3)全章适用每一幕。

- **差分只许动三样**(关卡世界层):
  1. 背景巨面构图与亮度节奏(视差层的"海报排版");
  2. 刻度 / 点缀的角色色密度(疾关红密、跃关黄点缀,levels.md §4 既有);
  3. 结构尺度与排布密度(巨构 = 3× 尺度;极简 = 减法留白)。
- **统一纪律**:UI 层(菜单 / 面板 / HUD / 档案)全局一套,**不随幕变**——
  页面越多的系统越要一张脸;幕差分只发生在关卡世界层。
- **各幕主题表**(叙事对位见 story.md §1.5):

| 幕 | 主题 | 关键词 |
|---|---|---|
| 序幕 | 构成主义(基调) | 红色刻度、细线、星阵 |
| 第一幕 | 巨构主义 | 3× 巨面、门厅桥柱梁、分位 |
| 第二幕 | 极简主义 | 减法、留白即道路、磁力线独色 |
| 第三幕 | 梦核主义(例外章) | 唯一允许柔光与微曲线的幕(例外清单显式登记) |
| 第四幕 | 构成 + 角色色强化 | 蜕变:每人一个色面高潮 |
| 第五幕 | 巨构主义 · 终演 | 全主题要素回收同屏 |
| 落幕 | 极简回白 | 回到序幕的白 |

- **梦核幕例外清单**(进幕前登记,退幕即失效):允许柔光边、微曲线装饰;
  仍禁止:渐变大面积底、圆角控件、模糊投影。例外清单外的违例照常审计。

## 8. 光影与阴影 · Godot 内建能力评估(v0.16)

- **现状**:实体系脚下投影(`_draw` 椭圆,宽度随离地高度收敛)= **游玩信息**
  (落点预判);建筑/机关硬投影 = 整体位移实心暗块(art-style §2"硬投影")。
- **Godot 内建方案**:PointLight2D / DirectionalLight2D + CanvasItem
  occluder(2D 阴影天然硬边,符合"禁模糊"纪律,引擎原生零贴图)。
- **评估结论**(分三类,不一刀切):
  1. **实体脚下投影保留手绘**——它承载"离地多高"的玩法可读性,
	 光影系统给不了这个信息;
  2. **建筑硬投影 → Light2D 迁移**:视觉等价、维护更省(不用逐对象画投影),
	 但引入全屏光照 pass——移动端开销按 ROADMAP"测量先行"纪律,
	 profile 说话,不凭直觉迁移;
  3. **立项条件**:第三幕「梦核」需要动态光效时一并做(那时才真的需要光)。
	 在此之前维持 P2 观望。
- **Light2D 立项时备查参数**(2026-09 外部调研预存,立项时以当版引擎复核):
  小型/次要遮挡物 `cast_shadow = OFF` 省性能;灯具用 Distance Fade 剔远处;
  阴影过滤优先 ESM;低端设备可开 `update_every_2_frames`(阴影轻微延迟换帧);
  保持 Slope-Scale 0 + 小 Z-Offset。
- **阴影优化承诺(现行即可做)**:全屏投影方向恒定 (7,8) 不逐对象异向(M4);
  落地投影宽度随高度收敛(已实现);实体硬投影随本体动(M4 已定)。
