一、项目核心锚定
================================================================================

1.1 设计哲学
- 形状即性格,属性即命运 —— 每个几何体的玩法能力、叙事性格、视觉形态三位一体。
- 动态设计:所有元素应具备动态感,符合构成主义机械美学。

1.2 名词统一
- 几何体:自机可控角色。
- 建筑物:构成地图的地面、墙壁、普通三角斜坡、梯形坡道、下凹坎等静态结构。
- 机关物:地图内嵌的各种机关或道具,包括移动平台、电梯平台、光电门、加速坡道、音符地板、跃迁门、压力感应器、反重力门等。

2.2 通用属性系统(标尺)
- 属性值范围:-1.0 ~ 3.0(可局内动态变化)。
- 基准值:2.0 = 标准基准,其他数值以此同步迭代。
- -1.0 表示该能力关闭;肉鸽模式可为某些几何体赋予原本不具备的能力(作为buff)。
- 正常模式属性上限为 5.0;肉鸽模式不设限。
- 跳高(格)= jump_units,与弹性解耦。
- 可跳台阶高度必须比 jump_units 低 0.1(留10%手感余量)。

2.3 通用能力维度
- 跳跃、加速、重量、负载等(具体数值待定)。

2.4 各几何体特殊特性
- 壹(疾):(原文未明确,待定)
- 贰(跃):当其他几何体在它顶部跳跃时,跳跃高度强化翻倍。
- 叁(逆):跳跃能力替换为置换能力,维持原特性设计并迭代优化;可任意穿过几何体伍产生的磁力边界。
- 肆(圆):可以被其他几何体推动滚动。
- 伍(界/边):两者必定同时存在,顶部由磁力线条链接形成磁力边界,阻隔其他几何体行动,一般不可穿过;磁力线随几何体移动而伸缩变化;其中一个在上、一个在下,可跳跃,不具备置换特性。
- 陆、柒:待定。

三、地图与坐标系统
================================================================================

3.1 单位与基准
- 1 格 = 100px。
- 坐标显示以物体左下角为基准点。

3.2 坡度限制
- 地图中的机关与建筑物,其可行走/滚行坡度全部控制在 37° 以内。

3.3 地图绘制生成
- 以关卡为单位,采用最新的分层地图逻辑进行整体性绘制。
- 不再使用将地图组件拆散到地图拼接的方式,而是分层绘制,保证视觉统一。

================================================================================
四、游戏音效设计
================================================================================

4.1 七音符体系
- 七个几何体对应七种音符音效,每个几何体使用一种音符作为其跳跃、落地等动作的主题音效。

4.2 钢琴地板砖
- 采用钢琴音色。
- 需优化触发逻辑:目前存在"圆压在琴键地板上会不断重复声音,如同机关枪般响应"的 bug,需修复触发机制(例如改为接触沿触发或冷却时间)。

================================================================================
八、模拟手感迭代
================================================================================

8.1 数学与物理演算
- 强化与迭代数学演算及物理模拟算法。
- 完善数值记录与信息管理。

8.2 几何体接触逻辑
- 优化几何体与几何体之间的接触互动手感。
- 头顶堆叠问题:目前存在奇怪的吸附感,需去除。
- 头顶滑动问题:几何体在头顶会产生滑动,应消除。
- 堆叠时非主控惯性滑动:堆叠状态下,非主动操控的几何体不应因载体运动而产生惯性滑动。

8.3 跳跃手感
- 保留轻点跳得低、长按跳得高的设计。
- 优化灵敏度与判定流程,确保操作响应清晰流畅。

================================================================================
九、剧情与关卡驱动
================================================================================

9.1 七幕结构
- 序幕 → 第一幕 → 第二幕 → 第三幕 → 第四幕 → 第五幕 → 落幕
- 各幕内容:
  - 序幕:基础新手教程,伏笔埋入,基础世界观铺垫。
  - 第一幕:由单几何体逐步过渡到多几何体协同,后续几何体教程递进。
  - 第二幕:主线展开,过往铺垫,机关铺垫,性格强化与塑造。
  - 第三幕:个人幕间融入,轻度引入肉鸽系统,引入娱乐性机关与地图,剧情分支处理。
  - 第四幕:部分个人幕间性格蜕变与升华,回归主线。
  - 第五幕:各种设定初步表明,继续主线。
  - 落幕:开放式结局,悬念铺垫,留白。

9.2 其他要求
- 地图内增加与 Godot 相关的彩蛋。
- 肉鸽模式与地图为独立模式,不与主线强关联,注重单几何体特性与颠覆玩法,强调无限疾速爽感节奏类设计。

十一、美术与视觉设计
================================================================================

11.1 大主题

- 不同剧幕应采用不同的美术风格主题:
  - 构成主义(基调)
  - 巨构主义(第一幕)
  - 极简主义(第二幕)
  - 梦核主义(第三幕)
  - …(后续幕次可延续)

11.4 几何体阴影优化
- 优化几何体的影子阴影效果。

11.5 Godot 自带功能重构
- 尽可能采用 Godot 引擎自带功能实现特效与光影,若性能与内存表现优秀,则进行重构迭代,替换为 Godot 原生实现。

11.6 分辨率调节
