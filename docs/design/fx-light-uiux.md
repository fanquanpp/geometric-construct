## 卷〇 · 三纪律(所有表现的准入判据)

1. **语义优先**:一个表现必须回答"它让玩家知道了什么"——光/粒子/
   动效都是信息,不是装饰;
2. **硬边**:一切边缘清晰——阴影 SHADOW_FILTER_NONE、光斑用**阶跃
   贴图**(3–4 档硬边,不用径向渐变)、粒子用矩形/折线不用圆点柔化;
3. **预算**:同屏动态光 ≤4、并发 shader 材质 ≤6、粒子发射器 ≤6、
   单次演出 ≤0.6s(M5 档);超预算 = 欠优化,立项驳回。

## 卷二 · 动态光效系统

正典地基:CanvasModulate 压暗 + DirectionalLight2D 抬亮 + 平台遮挡体,
硬边投影(shadow_filter NONE)。扩展原则:**光=空间语义,光不是装饰**。

### 2.1 语义光源目录(PointLight2D,阶跃硬边贴图)

| 光源 | 触发 | 语义 |
|---|---|---|
| **归门光** | 门框三档就绪态逐档抬亮(空/半/满) | "这扇门还差谁"——可读 |
| **开关光** | 踩踏开关按下,对应门板内缘亮起连线同色 | 归属连线从"画的"变"亮的" |
| **危险光** | kill_y 边缘/深坑上沿常驻冷光带 | 边界语义(和 HUD 读数同源) |
| **异常光(冻结)** | 两套刻度墙=双色叠光(红+蓝各亮一半) | 世界规则冲突的可见化 |
| **章节光色** | atmosphere.md 正典(章节光色/天光带)动效化:换幕时色温**阶跃切换**(3 档,硬切不渐变) | 幕的更替 |

### 2.2 光的纪律

- 光斑贴图 = 3 档阶跃矩形(无径向渐变);光强变化 = **档位跳变**
  (0.34→0.55→0.8),不做连续渐亮;
- 光脉冲沿用 M5 呼吸规则(周期 2s,幅度 ≤10%);
- 动态光**不新增遮挡体**(遮挡仍由平台 Occluder 承担),语义光不投影;
- 预算:同屏 PointLight ≤4,Directional ×1 恒定。

## 卷三 · Shader 白名单(canvas_item,首批六枚)

shader 准入制:新 shader = 立项登记,禁止"试试看"。

| shader | 用途 | 规格 |
|---|---|---|
| **阶跃溶解** | 场景转场/重拼演出:4×4 块状硬边擦除 | threshold 步进,无平滑;**实装 v0.37**(`assets/fx/block_dissolve.gdshader`,24×14 格 + 前沿红块波,TransitionFX BLOCKS_RED) |
| **双刻度墙** | 异常语义(卷一异常族) | 同几何双色错位一像素 |
| **斜向扫掠** | 幕转场:45° 硬边扫入扫出 | 直线沿,无羽化;**实装 v0.37**(`assets/fx/sweep_diagonal.gdshader`,对角 progress + 红缘细线,TransitionFX SWEEP) |
| **刻度流动** | 红色刻度带的方向性流动(L4 真相演出) | 每格硬跳,不滚动 |
| **硬边光罩** | 全屏压暗/区域提亮(档位式) | 3 档,无 vignette 渐变 |
| **错位抖动** | 冲击(已有镜头 kick 的画面级版本) | 整帧像素位移,≤2px |

禁:glitch 彩偏 / 高斯模糊 / 折射 / 噪声柔化 / 辉光溢出(无柔影纪律)。

## 卷四 · UI/UX 动画总表

### 4.1 页面级(ui-flow 三型 × 正典转场)

| 页面型 | 入场 | 退场 |
|---|---|---|
| Overlay(档案/设置/暂停) | 压暗 0.25s → 面板盒体自底升入 0.3s CUBIC_OUT(正典) | 反向,盒体不做位移(阅读稳定正典) |
| Flow(剧目二级/回廊) | 列表**stagger 入场**:每项步进 0.03s,直线缓动 | 整列硬切 |
| Screen(标题) | 分层入场(正典 menu_layer)| 幕转场:斜向扫掠 shader |

### 4.2 组件微交互(新增定型)

| 组件 | 动效 | 规格 |
|---|---|---|
| 按钮 | 按下=整体缩放 0.92 **硬停顿**(无回弹),音效同步 | 0.06s,直线 |
| 名册 chips | 选中=白框脉冲(正典)+ **位置硬跳一格**(不滑动) | 跳变 1 帧 |
| 滑杆 | 刻度音(正典)+ 手柄光标档位跳变 | 值变化=档位跳 |
| 数值/读数 | 变化=**按格跳变**(构成主义:数字一格一格走,不滚动) | 每格 0.04s |
| toast | 底缘升入 0.2s,停 2s,硬消失 | 无缓出 |
| 焦点环 | 键盘/手柄导航=白色取景框瞬移(角标闪一帧) | 1 帧 |

### 4.3 全屏演出(剧情/世界事件)

| 事件 | 演出 | 纪律 |
|---|---|---|
| 死亡 | 压暗 0.25s + 碎块散场 + 重拼:阶跃溶解反向 | 碎块=本体色 |
| 重拼 | 空白处缩放入场(正典)+ 刻度扣减**跳格** | 代价可读 |
| 通关 | 门序吸入(正典)→ 尾声 | — |
| 异常 | 语义异常(卷一)+ **异常光** | 永不用故障滤镜 |
| 幕更替 | 章节光色阶跃 + 斜向扫掠 + 题词 | 题词格言体(声线表) |

### 4.4 无障碍与手感

- 全部动效挂 motion.md 档位;**新增"减动效"设置项**(设置面板):
  关闭 stagger/脉冲/抖动,保留硬切——晕动友好,零成本开关;
- 触屏:所有微交互同时服务手指遮挡场景(反馈在触点对侧呈现)。

## 卷六 · 禁止清单(补充进正典审计)

视觉:辉光溢出 / 径向渐变光斑 / 柔影 / 圆角 / 有机粒子 / 故障彩偏 /
弹性回弹缓动 / 连续渐亮渐暗(一律档位跳变)。
性能:同屏动态光 >4 / 粒子 >6 发射器 / 常驻 shader >6 / 单演出 >0.6s。
流程:无登记的 shader 与粒子(白名单外)= 不合入。
