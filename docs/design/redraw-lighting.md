# 法相适配说明 · LIGHT / NORMAL ALIGNMENT

> 「法相适配」在本项目中的定义: **整批素材的受光方向、自阴影方向、高光位置统一, 且与引擎内光照设置同向**。
> 本项目为 2D 构成主义平台跳跃, 无 3D 法线贴图管线(无 Mesh/无 NormalMap 资源),
> 因此"法相"落点为 **2.5D 面角色(face-role)光照约定**, 与 `art-style.md` §8 引擎实算光影共用同一光向量。

---

## 1. 与引擎的对齐依据(observed)

来源: `docs/design/art-style.md` §8
- 引擎 rig = `CanvasModulate(环境冷色压暗)` + `DirectionalLight2D(rotation ≈ -40°, 光来自左上 → 影子投向右下)`
- `shadow_filter = NONE`(硬边阴影, 全项目禁模糊)
- 亮度模型: `最终色 = 本体色 × (环境档 + 光照档)`; 受光区 ≈ 1.0, 阴影区只剩环境档(压暗约 30%)
- 原始约定: 旧硬投影 offset `(7, 8)` = 右下方向

→ 本批素材采用同一方向的**左上光**。屏幕坐标下光向量单位方向约为 `(0.766, 0.643)`(即向右下)。

## 2. 生成侧实现(模型)

对任意实体形状 `S`, 取同一平移量 `d`:

| 区域 | 定义 | 颜色角色 | 含义 |
|---|---|---|---|
| 受光面 | `S − (S 平移 +d)` | `panel` | 贴住轮廓的**上缘与左缘**内带 |
| 自阴影 | `(S ∩ S₊) − S₋` | `shadow` | 贴住轮廓的**右缘与下缘**内带 |
| 本体 | `S ∩ S₊ ∩ S₋` | `body` | 中间基色 |

其中 `S₊ = S 平移(+d,+d)`, `S₋ = S 平移(−d,−d)`, `d = (5,5) px`(档案, 200 画布) / `(2.2,2.2) px`(图标)。
三区并集恒等于 `S` —— **阴影永远收在轮廓内部, 不产生外投硬影**, 符合 `art-style.md` §6.1
("几何肖像不画硬投影、不加底部暗带; 墨影错位一律收在形体轮廓内")。

由于三个区域由**同一个 `d` 与同一套角色色**推导, 批量一致性是**构造保证**, 而非逐张手工调平。

### 全局常量(唯一落点: `tools/kit.py` 文件头)

| 常量 | 值 | 说明 |
|---|---|---|
| `LIGHT_AZIMUTH_DEG` | 315° | 光来自左上 |
| `LIGHT_ELEV_DEG` | 40° | 与 `DirectionalLight2D rotation ≈ -40°` 对应 |
| `LIT_T` | 0.24 | 受光面 = 本体色向白插值 24% |
| `SHADOW_T` | 0.58 | 自阴影 = 本体色 × 0.58(压暗 42%) |
| 档案 `d` | 5 px | 200×200 画布 |
| 图标 `d` | 2.2 px | 64×64 画布 |

## 4. 两轨作用域(重要)

| 轨道 | 范围 | 法相处理 | 依据 |
|---|---|---|---|
| **世界 / 插图层** | `assets/archive/**` 43 张 | 应用 §2 三面角色光照 | `art-style.md` §6.1 明确要求 body/panel/edge/motif 结构 |
| **UI 图标层** | `assets/ui/icons.png` 图集(v0.48 起;原 `assets/svg/**` 已退役) | **flat 单色, 法相中性** | `art-style.md` §2 / §5 规定图标 flat 单色、直角折线 |

即: 图标层**不**加受光/自阴影, 是遵守本项目美术规范的**有意决定**, 而非遗漏。
两轨各自内部完全一致 —— 世界层统一"左上受光", 图标层统一"中性平涂"。
图标层的法相一致性体现为: 全部直角折线、统一 `stroke-linecap=square` / `stroke-linejoin=miter`、
统一 4 px 栅格、统一笔宽档(主 4.5 / 次 3.5), 且全部文字用折线字形(ThorVG 不支持 `<text>`)。

## 5. 校验方法与结果(checkable evidence)

`tools/verify.py` 的两项法相校验:

- **V7/V8 逐像素模型比对**: 按同一模型在成品尺寸上重建期望颜色(受光面/自阴影带内缩 1 px 以避开抗锯齿),
  与实际成品逐像素比对。
  结果: **43 张档案共 211946 个严格内部像素, 一致率 99.902%**(不符 208 个, 集中于斜边与抗锯齿过渡带)。

- **模型常量单一来源**: `d` 与 `LIT_T`/`SHADOW_T` 全局唯一, 逐张素材不存在独立参数 → 不存在"单张跑偏"。

对照示意: [`preview/light-normal-sheet.png`](../preview/light-normal-sheet.png)
(A 光向量与面角色 · B 角色三元色 · C 同光照下的批量实例)。

## 6. 已知偏差与未确认项

1. **无人眼确认**: 本轮环境视觉模型不可用(配额耗尽), 全部结论来自确定性像素校验与几何构造;
   **美学判断仍需用户面看** `preview/*.png` 确认。此为明确标注的未闭环项。
2. **图标层法相中性**是规范驱动的取舍(见 §4); 若用户希望图标也带受光面, 可切换为世界层同款处理(需改 `tools/gen_icons.lua`)。
3. **斜边过渡带**: 99.902% 之外的 0.098% 像素位于斜边抗锯齿带, 属正常过渡, 非脏点(已由 V5/V9 孤点与针孔检查独立确认)。
