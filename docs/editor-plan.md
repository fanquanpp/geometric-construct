# 关卡编辑器外部项目 · 策划案(仅文档,未开工)

> 状态:**策划案 v0.1(2026-09-09 立项)**——本文件只做规划与决策登记,
> 不写代码;后续在**本仓库之外**另立文件夹独立开发(独立 git 仓库)。
> 关联:主项目数据契约 `docs/design/levels.md` §0(LevelDef JSON 同构)、
> 组件语义 levels.md §7、名词与标尺 `docs/design/glossary.md`。
> 背景:v0.13.2 曾撤下"游戏内编辑器 + 分享码"方向(创作主战场取消)——
> 本项目定位不同:**面向官方关卡生产的效率工具**,不是玩家创作 UGC。

## 1. 定位与目标

- **一句话**:把"手改 `level_data.gd` 常量 + 截图钩子验收"的官方关卡生产流,
  升级为"可视化排布 + 语义编辑 + 一键试玩"的桌面工具。
- **服务对象**:本项目的关卡策划(第一优先),不追求通用编辑器。
- **不做**:玩家分享码 / 创意工坊 / 游戏内嵌编辑(维持 v0.13.2 撤下决定);
  程序化生成(官方关是"排"出来的,roguelike.md §4 纪律)。

## 2. 技术选型评估(定稿:Godot 4.x 独立工具项目)

| 方案 | 评估 | 结论 |
|---|---|---|
| **Godot 4.x 独立工具**(推荐) | 直接复用 LevelDef 数据结构与 `_draw()` 构成主义渲染语言;JSON 读写零转换;与主项目同引擎同纪律;打包小(~50MB) | **采用** |
| gode 插件(JS/TS) | 主项目 v0.13 前曾引入并清除(apk 154MB .so、2.9GB 磁盘教训);其 JS/TS 桥在纯工具场景收益低、维护面大 | 不采用 |
| Web 技术栈(Tauri/Electron + PixiJS) | 生态好,但 LevelDef 契约需二次实现,双端漂移风险高 | 备选不立项 |

- **项目形态**:独立 Godot 项目(`level-editor/`,与主项目平级的兄弟文件夹、
  独立 git 仓库);主项目**不新增任何编辑器代码**。
- **数据交换**:只走 **LevelDef 同构 JSON**(levels.md §0:
  `platforms / ramps / gates / exits / spawns / movers / piano_tiles /
  lever_gates / timed_bridges …` 全部可 JSON 化)——编辑器读写 JSON,
  主项目加载器读同一格式;**禁止编辑器直读 .gd**。
  前置依赖(登记到主项目):`LevelData` 增加 JSON 导入路径(小改,另批)。

## 3. 功能范围

### M1 · 核心排布(最小可用)
- 网格画布(1 格 = 100 px,定位网格三档 LOD 对齐 levels.md §8):
  平台 / 斜坡 / 机关物拖放摆布,Rect2 数值面板(格为单位输入)。
- **语义四元组编辑**(lane / faces / who / tags,levels.md §7.2):
  每个组件的检查器面板;who 选择器从 `Geometries` 名册读取(含伍的双体特例)。
- 坡度校验:可行走/滚行面 > 37° 即红标(glossary.md §3 纪律的机器化)。
- 保存 / 加载 LevelDef JSON(含版本号字段)。

### M2 · 生产加速
- 试玩直连:一键调起主项目 exe `--level <json>`(主项目需补 JSON 直载钩子);
  或导出后由主项目 `--tourshot` 自动出验收图。
- 组件预设库(序章/第一幕惯用组合一键摆放:垫脚台 / 气闸 / 接驳台…)。
- 钢琴砖音级编辑(y 反向映射预览 + 逐砖覆写,调外音级拒绝)。

### M3 · 打磨
- 关卡统计面板(长度/高差/缺口表 ↔ 射程矩阵核对,characters.md §3)。
- 多关卡幕管理(按 ACTS 组织文件树)。

## 4. UI / UX 与素材纪律

- **UI 素材全部 aseprite 绘制**(唯一允许像素素材的场景——编辑器是工具,
  不受主项目"零贴图"纪律约束;主项目纪律维持不变):
  图标 / 按钮三态(normal / hover / pressed)/ 面板九宫格切片,
  导出 PNG @1x/2x,禁抗锯齿(构成主义硬边一致)。
- **分辨率适配**:1280×720 设计稿基准 + fit 缩放居中(与主项目 fit_design
  同一套纪律);canvas_items + expand;最小窗口 1024×576 以下锁缩放下限。
- 图像差分精度:像素素材导入关 mipmap 关闭、nearest 采样;
  缩放只取整数倍(1x/2x),避免半像素模糊(Godot 图像精度处理惯例:
  `texture_filter = nearest` + 整数缩放 + 设计稿对齐)。
