## 速查:角色四维表

| 角色 | 大小(px) | 速度/冲刺/加速门 | 弹性 | 跳高 | 重量/负重力 | 特性 |
|---|---|---|---|---|---|---|
| 疾 · 红正方 | 56×56 | 1.0 / 1.5 / 1.5 | 0.5 | 2.0 | 1.0 / 1.0 | 冲刺、二段跳、爬墙 |
| 跃 · 黄竖长方 | 48×100 | 1.0 / — / — | **2.0** | 2.0 | **1.5 / 1.5** | 强反弹、二段跳、承载 |
| 逆 · 蓝镜像方 | 36×40 | 0.5 / 1.2 / 2.0 | 0.5 | 置换 | 0.2 / 0.5 | 重力翻转 |
| 圆 · 橙圆球 | 52×52 | **1.5** / — / 2.5 | 0.5 | — | 0.5 / 0.0 | 惯性滚动、切线飞跃 |

标尺:全部属性 0.0–2.0,1.0 = 标准;1 格 = 100 px;可跳台阶 ≤ jump_units − 0.1。
承载:头顶总重 > 负重力 → 跳高减半(不禁止);驮人者落地收力站稳。

## 速查:操作

| 操作 | 输入 |
|---|---|
| 移动 | A/D · ←/→(触屏:轮盘) |
| 跳跃 / 二段跳 | Space / W / ↑ / 手柄 A(触屏:点屏) |
| 置换(逆) | 同跳跃键 |
| 冲刺 | Shift / 手柄 X(触屏:轮盘拉满) |
| 爬墙(疾) | 贴墙 + 朝墙方向;按住跳 = 攀升 |
| 切换 | Tab / Q·E / 1-4 / 手柄 LB·RB |
| 重来 / 暂停 | R / Esc / 手柄 Back·Start |

手感细则与曲面/加速门叠乘规则见 `design/characters.md` §2、`design/structures.md`。
