# 设计文档 · DESIGN

> 游戏定位:**构成主义方块肉鸽游戏**(Roguelike 系统后续加入,当前为初期 Demo,
> 现阶段内容为几何体平台跳跃机制的奠基)。
> 美术锚定:**极简主义 + 构成主义 + 几何图形 + 棱角分明锐利**
> 本文涵盖:视觉规范 / 角色属性规范 / 操作手感 / 关卡规划(占位)。

## 1. 视觉规范(全部 UI 与实体必须遵守)

### 形状语言

- **禁止**:圆角(rx>0)、渐变、投影模糊、贝塞尔曲线、发光贴图。
- **必须**:直角矩形、直线段/折线、`stroke-linecap="square"`、`stroke-linejoin="miter"`。
- 柔影一律替换为**硬投影**(整体位移的实心暗块)。
- 构成主义母题:红色小方块标记、细线分隔条(rule)、大号数字编号(01/02…)、
  角部刻度、雪佛龙折角、几何圆环"太阳"、取景框角标。
- 字体:NotoSansSC 可变字重;标题 900、正文 400、注释 330;字距加宽用于大标题。
- SVG 素材:仅 flat 单样式;由 `tools/gen_svgs.py` 生成,禁手改;
  ThorVG 不支持 `<text>`,字母用折线字形。

## 2. 角色属性规范

全部属性使用 **0.0 – 2.0 标尺**:1.0 = 标准基准,0.0 = 不具备,2.0 = 特性上限。
未特殊化的属性记标准值;档案页用红色刻度线标出 1.0 基准。

### 标尺换算(关卡搭建铁律)

- **1 格 = 100 px**:一切 0.0–2.0 数值按格换算(例:障碍高 2 格 = 200 px)。
- **跳高(格) = jump_units(独立于弹性)**:起跳速度由 `jump_v = √(2·g·跳高·100)`
  自动换算;二段跳角色统一 **2.0 格/跳**,二连跳可达 4.0 格。
- **可跳跃高度必须比 jump_units 低 0.1**:二段跳角色可跳台阶最高 1.9 格;
  超出则必须借助二段跳接力 / 同伴 / 攀爬。
- **速度 ↔ 跳远**:跳跃水平距离与速度成正比(2.0 格跳滞空 ≈0.84 s,
  1.0× 单跳约 2.5 格,二段跳约 5 格)。
- **几何体大小**:底部长度 疾(0.56)> 跃(0.48)> 逆(0.36);
  高度 跃(1.00)> 疾(0.56)> 逆(0.40)。

### 属性定义

| 属性 | 字段 | 引擎含义 |
|---|---|---|
| 速度 | `base_speed` | 移动速度倍率(1.0 = 300 px/s) |
| 冲刺 | `sprint_speed` | 按住 Shift 的速度上限倍率 |
| 加速门 | `buff_sprint_speed` | 加速门后的速度上限倍率(立即加速,永久生效);**只提供加速,不影响重量** |
| 弹性 | `bounce` | 落地反弹系数;**全员固定 0.5,跃固定 2.0**(不再随速度浮动)(未按键落地 ×0.8 自然收敛;按住跳发力 +0.18) |
| 重量 | `weight` | 缩放加速度与摩擦力:越重起步越慢、滑行越远 |
| 负重力 | `carry` | 头顶可承载的来者重量上限 |
| 跳跃 | `can_jump` / `jump_units` | 跳高 = jump_units × 1 格(与弹性解耦);**二段跳:主动跳跃上限 2 次**(地面 1 次 + 空中 1 次,`MAX_JUMPS = 2`),二段跳角色统一 2.0 格/跳 |
| 置换 | `can_swap` | 跳跃键改为在上下平台间翻转(重力翻转,惯性保留) |
| 背负超载 | `OVERLOAD_JUMP_RATIO` | 头顶来者总重 > 负重力时,**跳跃高度减半(仍可跳,不禁止)** |

### 四角色数据

| 角色 | 形态 | 大小(px) | 速度 | 冲刺 | 加速门 | 弹性 | 跳高 | 重量 | 负重力 | 特性 |
|---|---|---|---|---|---|---|---|---|---|---|
| 疾 | 红色正方形 | 56×56 | 1.0 | 1.5 | 1.5 | **0.5** | **2.0** | 1.0 | 1.0 | 冲刺加速,速度越快跳得越远;二段跳;**爬墙**(单次 2.0 格) |
| 跃 | 黄色竖长方形 | 48×100 | 1.0 | —(不可加速) | — | **2.0(固定)** | **2.0** | **1.5** | **1.5** | 反弹全场最强,按跳发力更高;二段跳 2.0 格/次(达 4.0 格)、最重、最佳承载 |
| 逆 | 蓝色镜像正方形 | 36×40 | **0.5** | 1.2 | **2.0** | **0.5** | —(置换) | 0.2 | 0.5 | **置换**:翻转天地,不可跳跃 |
| 圆 | 橙色圆球形 | 52×52 | **1.5(固定)** | — | **2.5** | **0.5(固定)** | —(不可跳) | 0.5 | 0.0 | 不可跳跃、惯性滚动;弹性不再随速度浮动 |

- **重量关系**:跃 1.5 > 疾 1.0 > 圆 0.5 > 逆 0.2(符合"黄>红>橙>蓝")。
- **承载判定**:任何几何体都可站上同伴头顶(落脚不设限);当头顶来者总重
  **超过**承载者的负重力时,承载者**跳跃高度减半**(超载仍可跳)。
  例:跃(负重 1.5)驮疾(1.0)正常跳;疾(负重 1.0)驮跃(1.5)为超载,跳高减半;
  圆(负重 0.0)头顶站人即超载。
- **叠叠乐**:站在同伴头顶时,无输入则完全继承载体的速度——
  底部几何体移动/跳跃,上面的几何体一起走。驮人时落地收力站稳(做稳定平台)。

## 3. 操作与手感

| 操作 | 按键 | 说明 |
|---|---|---|
| 移动 | A/D 或 ←/→ | 加速度起步,松开后摩擦滑行(惯性) |
| 跳跃 | Space / W / ↑ / 手柄 A | 土狼时间 0.09s + 输入缓冲 0.12s + 松键截断;**空中可再按一次 = 二段跳**;对"逆"为**置换** |
| 曲面强化 | 踩上曲面跳跃板 | 速度上限临时 ×1.5 + 等效重量减半;**离开曲面后残留 1.5 秒**;与加速门/冲刺叠加(取最高再 ×1.5) |
| 爬墙 | 贴墙 + 按住朝墙方向(疾) | 按住方向 = 缓降滑壁;再按住跳跃键 = 向上爬(单次 2.0 格,落地重置);点按跳跃 = 沿墙上蹭;爬到墙顶水平动量自然带上台阶 |
| 置换 | Space(逆) | 重力翻转,射向另一侧平台;空中惯性(水平速度)完整保留 |
| 冲刺 | Shift(按住)/ 手柄 X | 目标速度抬升到冲刺上限,靠加速度自然攀升 |
| 切换 | Tab / Q/E / 1-4 / 手柄 LB·RB | 多几何体关卡可用;已到站几何体也可切换;Shift+Tab 反向 |
| 重来 / 暂停 | R / Esc / 手柄 Back·Start | Esc 在暂停面板中继续;触屏设备另有虚拟按键层(TouchControls) |

手感细则:
- 加速度 = 基准 2400 px/s² × 重量因子(0.55–1.15);空中加速度 ×0.62。
- 摩擦(松开输入的减速度)= 基准 1900 × 重量因子;圆球固定 0.34 倍(强调惯性滚动)。
- **圆球坡面切线**:贴坡(>4°)时速度对齐坡面切线并保持水平分量 = 目标速度,
  滑到坡端沿切线飞出——过山车飞跃的来源(速度越大,飞得越远)。
- 落地瞬间按住跳跃 = 主动发力,反弹更高;松键落地反弹 ×0.8 自然收敛,
  置换落地 ×0.55 额外缓冲;驮着同伴时收力站稳(做稳定平台)。
- 承载同步:骑手无输入时完全继承载体速度,另有头顶弹簧做位置对齐
  (死区 4px),叠叠乐高速移动不散架。
- **爬墙(疾)**:贴墙按住朝墙方向吸附,缓降 55 px/s;按住跳跃键以 150 px/s
  攀升,单次离地至多 2.0 格(落地重置);贴墙点按跳跃 = 沿墙上蹭(消耗空中跳);
  爬过墙顶后水平动量自然把身体带上台面。
- 冲刺超 1.2× 速度时出现高速残影;落地/反弹有轻/重两档音效,死亡有碎片爆裂与镜头微震。
- **圆球视觉规范**(形象重构):双色调半球(本体色 + 加深 24% 下半球)随滚动翻转、
  4 枚轮辐刻度(高速自动减淡防频闪)、单根指针辐条、纸白轮毂 + 墨色轴心。
  滚动按 **v/r 纯滚动**逐帧推进(地面 ω=v/r;空中保留角动量,轻微空气阻尼),
  从曲面飞出后姿态连续;挤压/拉伸在**屏幕空间**进行、与旋转解耦(先转后压),
  落地压扁不扭曲转动特征。配套滚动轰鸣循环音(音量/音高随速度)。
- 表现:起跳/落地挤压拉伸、硬投影随高度缩放、活跃角色白色取景框 + 呼吸角块。

## 4. 关卡规划(Demo:四个教学关)

> 每关围绕一个几何体的核心特性设计;数值均按"标尺换算"铁律搭建。

| # | 关名 | 主角 | 教学重点 | 布局 |
|---|---|---|---|---|
| 01 | 疾 · 跳跃 | 疾 | 跳跃;速度越快跳得越远(正比) | 平面 + 三个渐宽断崖(1.2 / 1.9 / 2.6 格),末缺口必须冲刺 |
| 02 | 跃 · 攀高 | 疾+跃 | 几何体切换、踩头合作、双重跳 | 台地 A(1.6 格,二段跳/爬墙可登)+ 高台 B(3.2 格,二段跳/爬墙接力/踩头合作) |
| 03 | 逆 · 突破 | 逆 | 置换特性 + 加速门 | 上下双平台 + 矮墙 + 双侧断口;加速门后大弧线飞跃断崖 |
| 04 | 圆 · 过山车 | 圆 | 曲面滑行、切线飞跃、加速门极速 | 两座曲面跳跃板 + 双断路;2.5× 飞跃 7.8 格大缺口 |
