## 速查:几何体属性总表(基础读数)

> 完整版(门后 / 攀墙 / 摩擦 / 惯性等全列)见 `design/characters.md` §1;
> 不一致时以代码 `scripts/data/geometries.gd` 为准。

| 编号 | 几何体 | 形态 | 大小(高×宽) | 速度/冲刺/门后 | 弹性 | 跳高 | 重量/负载 | 动词 |
|---|---|---|---|---|---|---|---|---|
| 壹 | 疾 · 红正方 | 红色正方形 | 50×50 | 2.0 / 2.5 / 2.5 | 1.5 | 2.0 | 2.0 / 2.0 | 冲(副:爬) |
| 贰 | 跃 · 黄竖长方 | 黄色长方形 | 80×40 | 2.0 / — / — | **3.0** | 2.0 | **2.5 / 2.5** | 弹 / 承载 / 顶弹 |
| 叁 | 逆 · 蓝镜像方 | 蓝色正方形 | 30×30 | 1.5 / 2.2 / 3.0 | 1.5 | 置换 | 1.2 / 1.5 | 翻(穿磁界) |
| 肆 | 圆 · 橙圆球 | 橙色圆球形 | 52×52 | **2.5 固定** / — / 3.5 | 1.5 | —(不可跳) | 1.5 / -1 | 滚(可推动) |
| 伍 | 界/边 · 紫三角双子 | 倒三角(顶)/ 正三角(地) | 30×30 | **3.0** / — / — | 1.5 | 1.0 | 1.5 / -1 | 隔(磁力边界) |

属性**加成数值条 v3**(glossary.md §4):基础值属于几何体自己(上表 =
基础读数,读数 = 物理 + 1.0,-1 = 天生没有即"状态-1");局内加成条从
0 起,+1..+4 每档 = 基础 × 1.25,−1 = 锁定;实际读数硬顶 5.0。
1 格 = 100 px;可跳台阶 ≤ jump_units − 0.1。
承载:头顶总重(物理)> 负重力 → 跳高减半(不禁止);驮人者落地收力站稳。

## 速查:操作

| 操作 | 输入 |
|---|---|
| 移动 | A/D · ←/→(触屏:轮盘) |
| 跳跃 / 二段跳 | Space / W / ↑ / 手柄 A(触屏:点屏) |
| 置换(逆) | 同跳跃键 |
| 冲刺 | Shift / 手柄 X(触屏:轮盘拉满) |
| 爬墙(疾) | 贴墙 + 朝墙方向;按住跳 = 攀升 |
| 切换 | Tab / Q·E / 1-5 / 手柄 LB·RB(双子同键连按轮换) |
| 召回(回最近检查点) | R / 手柄 Back / 右上按钮 |
| 档案几何 | C / 菜单入口(面板内 Q·E 切页签 / A·D 切条目 / 手柄十字键·LB·RB / B 返回) |
| 暂停 / 逐级返回 | Esc / 手柄 Start |
| 重新开始关卡 | 暂停页「重 新 开 始」按钮 |

手感细则与曲面/加速门叠乘规则见 `design/characters.md` §2、`design/structures.md`。
