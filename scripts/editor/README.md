# 关卡编辑器 · scripts/editor(预留)

自主地图编辑与分享功能,规划中:

- **编辑器**:网格画布(1 格 = 100 px,与关卡坐标系一致)+ 元素托盘
  (平台 / 曲面板 / 加速门 / 终点门 / 几何体出生点),产出 `LevelDef` 同构 JSON。
- **校验**:可通关性试探(复用 `--autotest` 的走跳 AI)+ 数值规范检查。
- **分享**:JSON → 压缩 + Base64url 编码为"分享码"(二维码 / 剪贴板),
  导入时校验版本号与结构;后续可加社区中心(见 ROADMAP)。

数据规范:编辑产物是**纯数据**(data 层),运行时与手写关卡同一条
`LevelBuilder.build` 装配路径。规划详见 `docs/ROADMAP.md`。
