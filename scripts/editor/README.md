# 关卡编辑器 · scripts/editor(预留)

自主地图编辑与分享功能,**设计定稿(2026-09-09)**:

- **设计权威**:`docs/design/editor.md`(双层内容模型 / 组件 schema /
  验证器三件套 / 试玩一体化 / 界面布局);技术里程碑 `docs/ROADMAP.md` §1。
- **前置**:组件化图层系统(ROADMAP §1 M0)——编辑器要编辑的
  `lane / faces / who` 语义必须先有运行时实现(levels.md §7)。
- **平台策略(定稿)**:桌面键鼠先行开发测试;移动端只保留
  「玩他人关卡」+ 极简触屏画笔,完整触屏编辑后置、真机反复测试优化。
- **编辑器**:网格画布(1 格 = 100 px,与关卡坐标系一致)+
  瓦片层(terrain 笔刷)+ 组件层(建筑 prefab 拖放,属性面板按
  schema 自动生成),产出 `LevelDef` 同构 JSON。
- **校验**:数值医生(台阶 / 缺口规范)+ 路径医生(可通关试探,复用
  `--autotest` 的走跳 AI)+ 配对医生(出生 / 归门 / 动态构件成对)。
- **分享**:JSON → 压缩 + Base64url 编码为"分享码"(二维码 / 剪贴板),
  导入时校验版本号与结构;后续可加社区中心(见 ROADMAP)。

数据规范:编辑产物是**纯数据**(data 层),运行时与手写关卡同一条
`LevelBuilder.build` 装配路径。
